## What We Offer

### GTFS Data

> [!note] GTFS Standard
> We provide both Scheduled and Realtime GTFS data following the General Transit Feed Specification standard.

Our GTFS implementation includes:
- **Scheduled data**: Complete route, stop, and schedule information
- **Real-time data**: Live vehicle positions and arrival predictions
- **TML extensions**: Custom fields designed to augment standard GTFS data

### JSON API

> [!tip] RESTful API
> Our REST API provides easy access to vehicle positions, arrival estimates, and scheduled data in JSON format.

Build interactive experiences using our REST API:
- Fetch upcoming trips and live wait times
- Query vehicle positions in real-time
- Access stop information and schedules
- Subscribe to webhooks for real-time updates

### Datasets

We share datasets on our [GitHub repository](https://github.com/carrismetropolitana/datasets) that are useful to us, and perhaps to you too. They are updated regularly and we're always expanding the collection.

### Open Source Projects

> [!success] Open Source Commitment
> We are committed to open-source principles, and our public repositories include projects such as our website, mobile apps, API implementations, and experimental tools.

These projects are available for you to explore, use, or contribute to.
