## Nenhum tratamento especial

Todas as rotas aqui documentadas são as mesmas que utilizamos para suportar as aplicações da TML, como o website e app da Carris Metropolitana e inúmeras ferramentas internas. Não aplicamos qualquer "tratamento especial" às nossas APIs — todos têm acesso à mesma informação ao mesmo tempo, garantindo equidade e transparência na partilha dos dados.

## Versões

A API é versioanda para permitir o desenvolvimento de novas funcionalidades sem comprometer a compatibilidade com sistemas que dependem das estruturas de dados de versões anteriores.

Uma vez que esta é uma API JSON, adicionar novas propriedades aos endpoints não é considerado uma alteração significativa, pois estas propriedades podem ser ignoradas com segurança pelos consumidores da API. Portanto, nesses casos, a versão da API pode não ser alterada.
Esta abordagem permite-nos introduzir melhorias enquanto minimizamos o impacto nas integrações existentes.


## Estrutura Uniforme de Respostas

Todas as respostas da API são concebidas para seguir a especificação JSend. Esta estrutura padronizada garante consistência em todos os endpoints
e fornece um framework para incluir informações adicionais de debugging quando necessário.

Em caso de erros, o formato JSend oferece uma forma clara e estruturada de descrever o que correu mal e, quando possível,
como o problema poderia ser resolvido. Esta abordagem simplifica o tratamento de erros para consumidores da API e melhora a experiência geral do programador.

```json title="Success Response"
{
	status: "success",
	timestamp: 1721023200,
	data: [ ... ] or { ... } // The requested data
}
```

```json title="Error Response"
{
	status: "error",
	timestamp: 1721023200,
	message: "Unable to communicate with database"
}
```


## TypeScript

Para facilitar o trabalho com as respostas da nossa API, fornecemos um [pacote NPM](https://www.npmjs.com/package/@carrismetropolitana/api-types)
que inclui definições TypeScript para todas as respostas de API. Este pacote ajuda a garantir segurança de tipos e melhora a eficiência do desenvolvimento
ao integrar com a nossa API em projetos JavaScript ou TypeScript.

Temos planos para expandir este pacote com funcionalidades adicionais no futuro, e acolhemos contribuições! Se quiseres ajudar,
sinta-se à vontade para submeter um pull request ao repositório.

Todos os endpoints JSON ao longo das coleções seguem a mesma estrutura padronizada, garantindo consistência e simplicidade.
