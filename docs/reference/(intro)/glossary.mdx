## Circulação
O API é versionado para permitir o desenvolvimento de novas funcionalidades sem comprometer a compatibilidade com sistemas que dependem das estruturas de dados de versões anteriores.

## Alerta
Um **alerta** é uma mensagem de serviço que informa passageiros e sistemas externos sobre situações que afectam a operação — acidentes, obras, greves, alterações de rede, entre outras.
