## Monitorização automática

Dispomos de uma [página de estado](https://status.carrismetropolitana.pt) para monitorização automática do estado dos vários serviços oferecidos. No entanto, há situações que não são detetadas pelos sistemas automáticos e por isso pedimos a tua ajuda para nos alertares do problema.

## Erros de software

Se detetares um bug no nosso software, abre um issue no repositório Github relevante. Passos claros de reprodução são cruciais para garantir uma resolução rápida. Se conseguires abrir um PR melhor ainda.

Agradecemos o teu feedback, tanto para reportar bugs como para pedidos de novas funcionalidades.
