## Erros na rede de transportes

Se encontrares erros na nossa rede — como paragens deslocadas, nomes de linhas incorretos, ou outras imprecisões — agradecemos imenso o teu feedback. Aqui está a melhor forma de reportar estes problemas:

- [**Reclamação formal**](https://www.carrismetropolitana.pt/contacts) — Pode parecer excessivo, mas estamos otimizados para lidar com este tipo de feedback. Enviar o teu feedback através dos canais oficiais de reclamação garante que o vosso reporte é direcionado para a equipa apropriada para revisão e resolução. Esta é a forma mais fiável de ter as vossas preocupações tratadas eficazmente.
- [**Github Issues**](https://github.com/carrismetropolitana/gtfs/issues) — Abrir uma Issue no nosso repositório gtfs é uma ótima forma de acompanhar o estado de resolução e requer menos esforço do que uma reclamação formal. Este tipo de problemas são regularmente monitorizados pelas equipas relevantes.

Apesar de termos grande cuidado para garantir que a nossa rede está livre de erros, temos uma rede _grande_. Agradecemos a vossa paciência enquanto resolvemos os problemas reportados, já que mesmo que pareçam simples de corrigir, normalmente não o são. Obrigado pela vossa cooperação em manter a rede da Carris Metropolitana em bom estado.


## Erros de software

Se detetares um bug no nosso software, abre um issue no repositório Github relevante. Passos claros de reprodução são cruciais para garantir uma resolução rápida. Se conseguires abrir um PR melhor ainda.

Agradecemos o teu feedback, tanto para reportar bugs como para pedidos de novas funcionalidades.

[Entra em contacto](/contact-us) se quiseres juntar-te à nossa equipa para construir o futuro dos transportes.
