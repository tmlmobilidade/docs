## Comunicação aberta

A nossa forma preferida de comunicar é em aberto. Se quiseres só dizer Olá! ou alertar-nos sobre um novo projeto interessante, abrir um issue no GitHub em qualquer repo é a melhor forma.

Mas se preferires algo mais direto, podes utilizar os contactos no perfil do GitHub de cada membro da equipa. Fala connosco a partir da tua plataforma preferida! 🙂


## Reclamações

Por favor envia o teu feedback através dos [canais oficiais](https://www.carrismetropolitana.pt/contacts). Apenas desta forma conseguimos garantir que o teu pedido chega à equipa certa para avaliação e resolução. É a forma mais eficiente e eficaz para resolver a tua situação.
