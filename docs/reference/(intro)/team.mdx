## Comunicação aberta

A nossa forma preferida de comunicar é em aberto. Se quiseres só dizer Olá! ou alertar-nos sobre um novo projeto interessante, podes abrir um issue no GitHub em qualquer repo ou enviar-nos um email para iso@tmlmobilidade.pt

Também podes utilizar os contactos no perfil do GitHub de cada membro da equipa. Fala connosco a partir da tua plataforma preferida! 🙂

## Junta-te a nós

Para todo o tipo de posições podes utilizar a [página de recrutamento da TML](https://www.tmlmobilidade.pt/0/recrutamento-tml) ou o método descrito acima. Para posições de desenvolvimento de software faz um PR no repo [work-with-us](https://github.com/carrismetropolitana/work-with-us) da Carris Metropolitana.

## Reclamações

Por favor envia o teu feedback através dos [canais oficiais](https://www.carrismetropolitana.pt/contacts). Apenas desta forma conseguimos garantir que o teu pedido chega à equipa certa para avaliação e resolução. É a forma mais eficaz de resolveres a tua questão.
