Esta plataforma reflete o nosso compromisso com a transparência, inovação e colaboração em matéria de transportes públicos. Quer estejas a desenvolver uma nova aplicação, a desenvolver sistemas para um operador de transportes, a investigar padrões de mobilidade ou a explorar dados de transportes, estamos aqui para suportar os teus esforços.

**Vamos trabalhar juntos para melhorar o sistema de transportes públicos para todos.**
