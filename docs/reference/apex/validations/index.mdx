# O que são as transações de validação ?

Correspondem a um dos tipos de transações utilizadas no sistema APEX, e são geradas pelos equipamentos embarcados dos veículos sempre que um passageiro efetua a validação do seu título de transporte (passe/zapping) ou compra de bilhete de bordo (quando aplicável).

Estas transações permitem registar e validar cada entrada/saída de um passageiro do sistema, e a estrutura de dados simplificada utilizada no GO encontra-se descrita nesta secção.

# A estrutura

Por forma a serem corretamente contabilizadas/utilizadas, são essenciais para este tipo de transações os seguintes campos:


| Nome do Campo         | Tipo de dado | Descrição                                                                                                                                                                           |
| --------------------- | ------------ | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| id                    |              | identificador único da transação                                                                                                                                                    |
| agency_id             |              | código do Operador de transporte                                                                                                                                                    |
| apex_version          |              | versão da APEX em utilização                                                                                                                                                        |
| card_serial_number    |              | número de série do título de transporte do passageiro (codificado)                                                                                                                  |
| category              |              | categoria do tipo de título de transporte utilizado:<br>ocasional a bordo - on_board_sale<br>ocasional pré-pago - prepaid<br>passe mensal - subscription                            |
| created_at            |              | _timestamp_ (data+hora) da geração da transação                                                                                                                                     |
| device_id             |              | identificador do equipamento embarcado que gerou a transação                                                                                                                        |
| event_type            |              | tipo de validação (entrada/saída/reentrada/entrada com recuperação)                                                                                                                 |
| is_passenger          |              | verificação de que 1) a validação é válida e 2) não tem uma anulação associada (para aferição do número de passageiros transportados)                                               |
| line_id               |              | código identifiador da linha                                                                                                                                                        |
| pattern_id            |              | código identificador do percurso                                                                                                                                                    |
| trip_id               |              | código identificador da circulação                                                                                                                                                  |
| stop_id               |              | código identificador da paragem                                                                                                                                                     |
| vehicle_id            |              | identificador do veículo                                                                                                                                                            |
| updated_at            |              | _timestamp_ (data+hora) da integração da transação nos sistemas da TML                                                                                                              |
| mac_sam_serial_number |              | identificador do número de série do cartão SAM que gerou a transação                                                                                                                |
| mac_ase_counter_value |              | número de contador incremental associado à transação, atribuído pelo equipamento embarcado, que permite a avaliação da sequencialidade das transações geradas por aquele cartão SAM |
| on_board_refund_id    |              | identificador único do reembolso a que a validação está associada, quando aplicável                                                                                                 |
| on_board_sale_id      |              | identificador único da venda do título de bordo a que a validação está associada, quando aplicável                                                                                  |
| product_id            |              | identificador do tipo de título utilizado                                                                                                                                           |
| units_qty             |              | valor descontado do cartão (apenas aplicável quando o título utilizado é ocasional pré-pago)                                                                                        |
| validation_status     |              |                                                                                                                                                                                     |
