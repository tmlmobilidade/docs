# O que é a APEX?

A APEX é o sistema de bilhética utilizado pela Carris Metropolitana, e que está a ser implementado em todos os operadores da AML. É o que suporta todas as funcionalidades do cartão navegante® — compra e carregamentos de títulos em cartões físicos e digitais, gestão de perfis de cliente e ativação de descontos validações com o mobile.
