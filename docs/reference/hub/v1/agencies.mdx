---
title: Operadores
description: Como identificar operadores de transporte e utilizar os seus dados operacionais.
---

O GO define um ID único para cada operador de transporte, que é utilizado em todas as outras estruturas de dados. Este endpoint devolve a informação pública de cada operador, assim como as funcionalidades que estão ativadas para cada um. Com esta informação é possível perceber quais são os operadores que estão incluídos na exportação combinada de GTFS ou que estão a utilizar o serviço de ETAs do GO.

Os IDs de cada operador são acompanhados também com um código (agency\_code) que identifica cada operador noutros sistemas de informação, como por exemplo no sistema de bilhética APEX.

### Estrutura de dados

No Hub, um plano é representado por um objeto JSON com as seguintes propriedades:

| Propriedades                    |            Tipo            | Descrição                                                                                                                               |
| ------------------------------- | :------------------------: | --------------------------------------------------------------------------------------------------------------------------------------- |
| `_id`                           |           String           | ID único do plano.                                                                                                                      |
| `active_from`                   |  OperationalDate (Integer) | Data de início do plano (inclusive).                                                                                                    |
| `active_until`                  |  OperationalDate (Integer) | Data de fim do plano (inclusive).                                                                                                       |
| `agency_code`                   |           String           | Código do operador associado ao plano.                                                                                                  |
| `agency_id`                     |           String           | ID único do operador associado ao plano.                                                                                                |
| `agency_name`                   |           String           | Nome do operador associado ao plano.                                                                                                    |
| `hash`                          |           String           | Hash do plano, que identifica inequívocamente a versão deste plano. Este hash depende dos ficheiros GTFS em si e das datas de ativação. |
| `is_active`                     |           Boolean          | Indica se o plano está ativo no momento do pedido HTTP.                                                                                 |
| `operation_gtfs_original_id`    |           String           | ID do ficheiro GTFS original tal como submetido pelo operador.                                                                          |
| `operation_gtfs_original_url`   |        URL (String)        | URL para descarregar o ficheiro GTFS original.                                                                                          |
| `operation_gtfs_normalized_id`  |           String           | ID do ficheiro GTFS normalizado gerado pelo GO.                                                                                         |
| `operation_gtfs_normalized_url` |        URL (String)        | URL para descarregar o ficheiro GTFS normalizado.                                                                                       |
| `created_at`                    | UnixMilliseconds (Integer) | Data de publicação do plano.                                                                                                            |
| `updated_at`                    | UnixMilliseconds (Integer) | Data da última atualização do plano.                                                                                                    |


### Endpoints disponíveis

Base path: `https://go.tmlmobilidade.pt/hub/api`

| Path                                                                        | Tipo           | Descrição                                                                                                                                                         |
| --------------------------------------------------------------------------- | -------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| [`/v1/plans`](https://go.tmlmobilidade.pt/hub/api/v1/plans)                 | `HubV1ApiPlan` | Todos os planos de operação publicados no GO.                                                                                                                     |
| [`/v1/plans/gtfs`](https://go.tmlmobilidade.pt/hub/api/v1/plans/gtfs)       | File Download  | Ficheiro GTFS unificado de todos os planos de operação ativos, para todos os operadores de transporte. Nem todos os planos são incluídos nesta geração unificada. |
| [`/v1/plans/gtfs/cm`](https://go.tmlmobilidade.pt/hub/api/v1/plans/gtfs/cm) | File Download  | Ficheiro GTFS unificado de todos os planos de operação ativos, para os operadores da Carris Metropolitana.                                                        |
