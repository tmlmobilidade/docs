## Estrutura de dados

Cada elemento de `DemandByAgencyByOperationalDate[]` contém:

| Propriedade | Tipo | Descrição |
| --- | --- | --- |
| `agency_id` | String | ID do operador. |
| `operational_date` | OperationalDateInt (Integer) | Data operacional no formato `AAAAMMDD`. |
| `qty` | Number | Quantidade de procura agregada. |
| `updated_at` | UnixMilliseconds (Integer) | Instante da última atualização. |

```typescript
export const DemandByAgencyByOperationalDateSchema = z.object({
	agency_id: z.string(),
	operational_date: OperationalDateIntSchema,
	qty: z.number(),
	updated_at: UnixMillisecondsSchema,
});
```
