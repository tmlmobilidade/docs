---
title: Estimativas de Chegada
description: Estimativas de chegada (ETA - Estimated Time of Arrival) para todas as viagens/paragens em operação.
---

As estimativas são calculadas a partir de uma análise histórica e de condições calculadas em tempo real.

### Estrutura de uma estimativa de chegada

O tipo `HubV1ApiTripStopEta` representa cada estimativa. No Hub, o ETA é representado por um objeto JSON com as seguintes propriedades:

| Propriedade          | Tipo                   | Descrição                                           |
| ---------------------| ---------------------- | --------------------------------------------------- |
| `eta_at`             | Integer                | Timestamp do ETA em milissegundos (Unix timestamp). |
| `eta_seconds`        | Integer                | Tempo de espera em segundos.                        |
| `stop_id`            | String                 | ID da paragem.                                      |
| `stop_name`          | String                 | Nome da paragem.                                    |
| `stop_sequence`      | Integer                | Sequência da paragem.                               |
| `trip_id`             | String                 | ID da viagem.                                       |
| `vehicle_id`          | String                 | ID do veículo.                                      |

## Endpoints disponíveis

| Método | Path                                      | Tipo de resposta                  | Descrição                                                         |
| ---    | ---                                       | ---                               | ---                                                               |
| GET    | [`/v1/:organizationId/eta`                 ](https://go.tmlmobilidade.pt/hub/api/v1/0XJC9/eta)| `HubV1ApiTripStopEta[]` em `data` | Estimativas disponíveis para a organização, em JSON simplificado. |
| GET    | `/v1/:organizationId/eta/by-trip/:tripId`| `HubV1ApiTripStopEta[]` em `data` | Estimativas de uma viagem.                                        |
| GET    | [`/v1/:organizationId/eta/by-stop/:stopId` ](https://go.tmlmobilidade.pt/hub/api/v1/0XJC9/eta/by-stop/370514)| `HubV1ApiTripStopEta[]` em `data` | Estimativas de uma paragem.                                       |
| GET    | [`/v1/:organizationId/eta/gtfs`            ](https://go.tmlmobilidade.pt/hub/api/v1/0XJC9/eta/gtfs)| `HubV1ApiEtaGtfsFeed` em `data`   | Feed GTFS-RT TripUpdates em JSON.                                 |
| GET    | [`/v1/:organizationId/eta/gtfs.pb`         ](https://go.tmlmobilidade.pt/hub/api/v1/0XJC9/eta/gtfs.pb)| Protobuf                          | Feed GTFS-RT TripUpdates binário.                                 |

Obtém `:organizationId` na [lista de organizações](/reference/hub/v1/organizations). `:tripId` e `:stopId` identificam a viagem e a paragem, respetivamente. Os IDs devem ser codificados para utilização num segmento de URL.

As respostas de sucesso usam HTTP `200` e cache pública de 3 segundos. As respostas JSON usam o [formato comum do Hub](/reference/hub/responses); o Protobuf é devolvido diretamente com `Content-Type: application/octet-stream`.

Sem estimativas publicadas, os endpoints de JSON simplificado devolvem `data: []`, incluindo as consultas por viagem ou paragem. Uma organização inexistente ou sem dados abertos devolve HTTP `404`. Os feeds GTFS-RT seguem as [regras de combinação por organização](/reference/hub/v1/organizations).
