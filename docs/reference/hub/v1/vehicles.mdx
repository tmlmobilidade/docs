### Tempo Real
Informação em tempo real da rede de transportes, como posições de veículos e estimativas de chegada. O estimador de horários ainda está em fase experimental, pelo que deve ser utilizado com algum cuidado.

| Path                                                                                                                    | Descrição                                                                                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`/v1/realtime/vehicles/metadata`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/vehicles/metadata)                   | Metadados da maior parte dos veículos em operação, como modelo, matrícula, lugares disponíveis, entre outros.                                                |
| [`/v1/realtime/vehicles/positions`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/vehicles/positions)                 | Todos os veículos de todos os operadores em operação num determinado momento, em JSON. Sugerimos uma atualização a cada 3 segundos para melhores resultados. |
| [`/v1/realtime/vehicles/positions/gtfs`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/vehicles/positions/gtfs)       | Todos os veículos de todos os operadores em operação num determinado momento, em JSON mas no formato standard GTFS-RT Vehicle Positions.                     |
| [`/v1/realtime/vehicles/positions/gtfs.pb`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/vehicles/positions/gtfs.pb) | Todos os veículos de todos os operadores em operação num determinado momento, em Protobuf e no formato standard GTFS-RT Vehicle Positions.                   |
| [`/v1/realtime/eta/gtfs.pb`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/eta/gtfs.pb)                               | Estimativas de chegada (ETA) para todas as viagens/paragens em operação, no formato GTFS-RT TripUpdates (Protobuf).                                          |
| [`/v1/realtime/eta/gtfs`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/eta/gtfs)                                     | Estimativas de chegada (ETA) para todas as viagens/paragens em operação, no formato GTFS-RT TripUpdates (JSON).                                              |
| [`/v1/realtime/eta`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/eta)                                               | Estimativas de chegada (ETA) para todas as viagens/paragens em operação, em JSON simplificado.                                                               |
| [`/v1/realtime/eta/by-trip/:id/gtfs.pb`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/eta/by-trip/:id/gtfs.pb)       | Estimativas de chegada (ETA) para uma viagem específica (`:id`), em formato GTFS-RT TripUpdates (Protobuf).                                                  |
| [`/v1/realtime/eta/by-trip/:id/gtfs`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/eta/by-trip/:id/gtfs)             | Estimativas de chegada (ETA) para uma viagem específica (`:id`), em formato GTFS-RT TripUpdates (JSON).                                                      |
| [`/v1/realtime/eta/by-trip/:id`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/eta/by-trip/:id)                       | Estimativas de chegada (ETA) para uma viagem específica (`:id`), em JSON simplificado.                                                                       |
| [`/v1/realtime/eta/by-stop/:id/gtfs.pb`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/eta/by-stop/:id/gtfs.pb)       | Estimativas de chegada (ETA) para uma paragem específica (`:id`), em formato GTFS-RT TripUpdates (Protobuf).                                                 |
| [`/v1/realtime/eta/by-stop/:id/gtfs`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/eta/by-stop/:id/gtfs)             | Estimativas de chegada (ETA) para uma paragem específica (`:id`), em formato GTFS-RT TripUpdates (JSON).                                                     |
| [`/v1/realtime/eta/by-stop/:id`](https://go.tmlmobilidade.pt/hub/api/v1/realtime/eta/by-stop/:id)                       | Estimativas de chegada (ETA) para uma paragem específica (`:id`), em JSON simplificado.                                                                      |
