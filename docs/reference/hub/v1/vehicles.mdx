Informação em tempo real da rede de transportes, como posições de veículos e estimativas de chegada. O estimador de horários ainda está em fase experimental, pelo que deve ser utilizado com algum cuidado.

| Path                                                                                                                    | Descrição                                                                                                                                                    |
| ----------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| [`/v1/vehicles/metadata`](https://go.tmlmobilidade.pt/hub/api/v1/vehicles/metadata)                   | Metadados da maior parte dos veículos em operação, como modelo, matrícula, lugares disponíveis, entre outros.                                                |
| [`/v1/vehicles/positions`](https://go.tmlmobilidade.pt/hub/api/v1/vehicles/positions)                 | Todos os veículos de todos os operadores em operação num determinado momento, em JSON. Sugerimos uma atualização a cada 3 segundos para melhores resultados. |
| [`/v1/vehicles/positions/gtfs`](https://go.tmlmobilidade.pt/hub/api/v1/vehicles/positions/gtfs)       | Todos os veículos de todos os operadores em operação num determinado momento, em JSON mas no formato standard GTFS-RT Vehicle Positions.                     |
| [`/v1/vehicles/positions/gtfs.pb`](https://go.tmlmobilidade.pt/hub/api/v1/vehicles/positions/gtfs.pb) | Todos os veículos de todos os operadores em operação num determinado momento, em Protobuf e no formato standard GTFS-RT Vehicle Positions.                   |
