Endpoints para debugging do sistema. Uma vez que utilizamos estes endpoints nos suportes de informação ao público, como o [site](https://carrismetropolitana.pt) e [app da Carris Metropolitana](https://carrismetropolitana.pt/app) e [app navegante®](https://carrismetropolitana.pt/app-navegante), é importante garantir que o sistema está online e a funcionar.

| Path                                                                  | Descrição                                                                                                       |
| --------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------- |
| [`/v1/debug/time`](https://go.tmlmobilidade.pt/hub/api/v1/debug/time) | Timestamps internos dos sistema. Útil para despistar problemas de stale data causados por caching, por exemplo. |
