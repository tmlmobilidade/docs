Este ficheiro vehicles.txt não existe no GTFS standart mas nós TML utilizamos e precisamos

**Presença**: Obrigatório<br/>
**Chave primária**: `vehicle_id`
### Campos GTFS TML

| Nome do Campo        | Tipo                                         | Presença    | Descrição                                                                                                                                                                                                                                                                                                                                                                                     |
| -------------------- | -------------------------------------------- | ----------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vehicle_id`         | ID único                                     | obrigatório | ID de identificação do veículo.                                                                                                                                                                                                                                                                                                                                                               |
| `agency_id`          | ID externo que faz referência a `agency.txt` | obrigatório | ID da entidade responsável pelo veículo, usado para associar cada veículo à respetiva agência no sistema.                                                                                                                                                                                                                                                                                     |
| `license_plate`      | ID único                                     | obrigatório | Matrícula atribuído ao veículo para efeitos de registo e identificação.                                                                                                                                                                                                                                                                                                                       |
| `make`               | Texto                                        | obrigatório | Fabricante ou marca do veículo.                                                                                                                                                                                                                                                                                                                                                               |
| `model`              | Texto                                        | obrigatório | Modelo específico do veículo dentro da marca.                                                                                                                                                                                                                                                                                                                                                 |
| `owner`              | Texto                                        | obrigatório | Entidade que é a proprietária legal do veículo.                                                                                                                                                                                                                                                                                                                                               |
| `registration_date`  | Data                                         | obrigatório | Data em que o veículo foi registado pela primeira vez.A estrutura devida para a `registration_date` é AAAAMMDD.                                                                                                                                                                                                                                                                               |
| `available_seats`    | Número inteiro                               | obrigatório | Indica o número total de lugares disponíveis para passageiros no veículo.                                                                                                                                                                                                                                                                                                                     |
| `available_standing` | Número inteiro                               | obrigatório | Indica o número máximo de passageiros que podem viajar em pé no veículo.                                                                                                                                                                                                                                                                                                                      |
| `typology`           | Enum                                         | obrigatório | Indica a categoria do veículo, representada por um código numérico.**Valores:**- **0** – Elétrico- **1** – Metro- **2** – Comboio- **3** – Autocarro- **4** – Barco**Nota:**  Este campo ainda não esta completo e por norma vai devolver um aviso mas continua a ser aceite até a nova lista estar completa.                                                                                 |
| `propulsion`         | Enum                                         | obrigatório | Indica o tipo de energia ou combustível utilizado pelo veículo para se movimentar.<br/><br/>**Opções válidas:**<ul><li>`1` - Gasolina.</li><li>`2` - Diesel.</li><li>`3` - GPL automóvel.</li><li>`4` - Mistura.</li><li>`5` - Biodiesel.</li><li>`6` - Elétrico.</li><li>`7` - Híbrido.</li><li>`8` - Gás Natural.</li></ul>                                                                 |
| `emission`           | Enum                                         | obrigatório | Classe de emissões.<br/><br/>**Opções válidas:**<ul><li>`0` - Sem classificação de emissões (exceção).</li><li>`1` - EURO I.</li><li>`2` - EURO II.</li><li>`3` - EURO III.</li><li>`4` - EURO IV.</li><li>`5` - EURO V.</li><li>`6` - EURO VI.</li></ul> Este campo indica a norma de emissões do veículo. O valor **0** é usado em casos excecionais para veículos sem classificação de emissões. |
| `climatization`      | Enum                                         | obrigatório | Indica se o veículo dispõe de sistema de climatização.<br/><br/>**Opções válidas:**<ul><li>`0` - Não.</li><li>`1` - Sim.</li></ul>                                                                                                                                                                                                                                                            |
| `wheelchair`         | Enum                                         | obrigatório |                                                                                                                                                                                                                                                                                                                                                                                               |
| `lowered_floor`      | Enum                                         | obrigatório |                                                                                                                                                                                                                                                                                                                                                                                               |
| `ramp`               | Enum                                         | obrigatório |                                                                                                                                                                                                                                                                                                                                                                                               |

| `static_information` | Enum                                         | obrigatório |                                                                                                                                                                                                                                                                                                                                                                                               |

| `front_display`      | Enum                                         | obrigatório |                                                                                                                                                                                                                                                                                                                                                                                               |
| `rear_display`       | Enum                                         | obrigatório |                                                                                                                                                                                                                                                                                                                                                                                               |
| `side_display`       | Enum                                         | obrigatório |                                                                                                                                                                                                                                                                                                                                                                                               |
