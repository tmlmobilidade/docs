**Presença**: Obrigatório<br/>
**Chave primária**: `vehicle_id`
### Campos GTFS TML

Este campo não existe no GTFS standart mas nos TML exigimos este ficheiro nos GTFS

| Nome do Campo       | Tipo                                         | Presença    | Descrição                               |
| ------------------- | -------------------------------------------- | ----------- | --------------------------------------- |
| `vehicle_id`        | ID único                                     | Obrigatório | ID para identifica o veículo            |
| `agency_id`         | ID externo que faz referência a `agency.txt` | Obrigatório | Agência responsável pelo uso do veículo |
| `license_plate`     | ID único                                     | Obrigatório | Identifica legal do veículo             |
| `make`              | Text                                         | Obrigatório | Fabricante do veículo                   |
| `model`             | Text                                         | Obrigatório | Modelo especifico do veículo            |
| `owner`             | Text                                         | Obrigatório | Atual dono do veículo                   |
| `registration_date` | Date                                         | Obrigatório | data de registro                        |
|                     |                                              |             |                                         |
