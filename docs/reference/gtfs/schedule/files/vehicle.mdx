**Presença**: Obrigatório<br/>
**Chave primária**: `vehicle_id`
### Campos GTFS TML

Este campo não existe no GTFS standart mas nos TML exigimos este ficheiro nos GTFS

| Nome do Campo        | Tipo                                         | Presença    | Descrição                                                                                                                                                                             |
| -------------------- | -------------------------------------------- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vehicle_id`         | ID único                                     | Obrigatório | ID para identifica o veículo                                                                                                                                                          |
| `agency_id`          | ID externo que faz referência a `agency.txt` | Obrigatório | Agência responsável pelo uso do veículo                                                                                                                                               |
| `license_plate`      | ID único                                     | Obrigatório | Identifica legal do veículo                                                                                                                                                           |
| `make`               | Texto                                        | Obrigatório | Fabricante do veículo                                                                                                                                                                 |
| `model`              | Texto                                        | Obrigatório | Modelo especifico do veículo                                                                                                                                                          |
| `owner`              | Texto                                        | Obrigatório | Atual dono do veículo                                                                                                                                                                 |
| `registration_date`  | Data                                         | Obrigatório | Data do primeiro registro do veículo                                                                                                                                                  |
| `available_seats`    | Número inteiro                               | Obrigatório | Quantidade de lugares sentados                                                                                                                                                        |
| `available_standing` | Número inteiro                               | Obrigatório | Quantidade de lugares em pé                                                                                                                                                           |
| `propulsion`         | Enum                                         | Obrigatório | Tecnologia de propulsão:<br><br>* 1 - Gasolina<br>* 2 - Diesel<br>* 3 - GLP automotivo<br>* 4 - Misto<br>* 5 - Biodiesel<br>* 6 - Eletricidade<br>* 7 - Híbrido<br>* *8 - Gás Natural |
| `emission`           | Enum                                         | Obrigatório | Tipo de emissão:<br><br>* 1 - Gasolina<br>* 2 - Diesel<br>* 3 - GLP automotivo<br>* 4 - Misto<br>* 5 - Biodiesel<br>* 6 - Eletrici<br><br><br>                                        |
|                      |                                              |             |                                                                                                                                                                                       |
