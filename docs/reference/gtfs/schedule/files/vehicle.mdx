| Nome do Campo | Tipo                                         | Presença    | Descrição                         |
| ------------- | -------------------------------------------- | ----------- | --------------------------------- |

| `agency_id`   | ID externo que faz referência a `agency.txt` | obrigatório | Agência da qual utiliza o veículo |
