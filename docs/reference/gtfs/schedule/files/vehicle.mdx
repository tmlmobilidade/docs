Este ficheiro vehicles.txt não existe no GTFS standart mas nós TML utilizamos e precisamos

**Presença**: Obrigatório<br/>
**Chave primária**: `vehicle_id`
### Campos GTFS TML

| Nome do Campo        | Tipo                                         | Presença    | Descrição                                                                                                                                                                                                                                                               |
| -------------------- | -------------------------------------------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `vehicle_id`         | ID único                                     | obrigatório | ID de identificação do veículo                                                                                                                                                                                                                                          |
| `agency_id`          | ID externo que faz referência a `agency.txt` | obrigatório | ID da entidade responsável pelo veículo, usado para associar cada veículo à respetiva agência no sistema.                                                                                                                                                               |
| `license_plate`      | ID único                                     | obrigatório | Matrícula atribuído ao veículo para efeitos de registo e identificação.                                                                                                                                                                                                 |
| `make`               | Texto                                        | obrigatório | Fabricante ou marca do veículo                                                                                                                                                                                                                                          |
| `model`              | Texto                                        | obrigatório | Modelo específico do veículo dentro da marca                                                                                                                                                                                                                            |
| `owner`              | Texto                                        | obrigatório | Entidade que é a proprietária legal do veículo.                                                                                                                                                                                                                         |
| `registration_date`  | Data                                         | obrigatório | Data em que o veículo foi registado pela primeira vez.<br><br>A estrutura devida para a `registration_date` é AAAAMMDD                                                                                                                                                  |
| `available_seats`    | Número inteiro                               | obrigatório | Indica o número total de lugares disponíveis para passageiros no veículo.                                                                                                                                                                                               |
| `available_standing` | Número inteiro                               | obrigatório | Indica o número máximo de passageiros que podem viajar em pé no veículo.                                                                                                                                                                                                |
| `typology`           | Enum                                         | obrigatório | Indica a categoria do veículo, representada por um código numérico.<br><br>* 0 - Elétrico<br>* 1 - Metro<br>* 2 - Comboio<br>* 3 - Autocarro<br>* 4 - Barco<br><br>Aviso este campo ainda não esta completo e por norma vai devolver um aviso mas continua a ser aceite |
| `propulsion`         | Enum                                         | obrigatório |                                                                                                                                                                                                                                                                         |
| `emission`           | Enum                                         | obrigatório |                                                                                                                                                                                                                                                                         |
| `climatization`      | Enum                                         | obrigatório |                                                                                                                                                                                                                                                                         |

| `side_display`       | Enum                                         | obrigatório |                                                                                                                                                                                                                                                                         |
