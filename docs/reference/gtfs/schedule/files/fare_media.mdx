title: rider_categories
description: Descrever os diferentes meios de pagamento que podem ser utilizados para a utilização de produtos tarifários. Os meios de pagamento são suportes físicos ou virtuais utilizados para a representação e/ou validação de um produto tarifário.

**Presença**: Opcional<br/>
**Chave primária**: rider_category_id
### Campos GTFS Standard

| Nome do Campo              | Tipo     | Presença    | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| -------------------------- | -------- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `rider_category_id`        | ID único | Obrigatório | Identifica uma categoria de utente                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `rider_category_name`      | Texto    | Obrigatório | Nome da categoria de utente tal como é apresentado ao utente                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| `is_default_fare_category` | Enum     | Obrigatório | Indica se a linha em `rider_categories.txt` deve ser tratada como categoria por omissão (a categoria principal a mostrar aos utentes).<br/><br/>Exemplos de rotulagem adulto, tarifa normal, etc.<br/><br/>Opções válidas (GTFS)<br/><br/> `0` ou vazio — A categoria não é considerada a omissão.<br/> `1` — A categoria é considerada a omissão.<br/><br/>Quando várias categorias de utente são elegíveis para o mesmo produto tarifário (`fare_product_id`), tem de existir exactamente uma entre essas elegíveis marcada como omissão (`is_default_fare_category` igual a 1). |
| `eligibility_url`          | Texto    | Opcional    | URL de uma página Web, em geral do operador, com informação pormenorizada sobre a categoria de utente ou sobre os critérios de elegibilidade a essa categoria.                                                                                                                                                                                                                                                                                                                                                                                                                     |
