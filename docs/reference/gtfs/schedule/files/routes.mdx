---
title: routes
description: Percursos de transporte público. Uma rota é um grupo de viagens que são apresentadas aos passageiros como um único serviço.
---
**Presença**: Obrigatório<br/>
**Chave primária**: `route_id`
### Campos GTFS Standard 

| Nome do Campo         | Tipo                                         | Presença                     | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| --------------------- | -------------------------------------------- | ---------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `route_id`            | ID único                                     | Obrigatório                  | Identifica uma rota.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `agency_id`           | ID externo que faz referência a `agency.txt` | Condicionalmente obrigatório | Agência da rota especificada.<br/><br/>**Condicionalmente obrigatório**:<ul><li>**Obrigatório** se várias agências estiverem definidas em agency.txt.</li><li>Recomendado caso contrário.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                 |
| `route_short_name`    | Texto                                        | Condicionalmente obrigatório | Nome abreviado de uma rota. Geralmente, um identificador curto e abstrato (por exemplo, "32", "100X", "Verde") que os passageiros utilizam para identificar uma rota. Tanto `route_short_name` como `route_long_name` podem ser definidos. <br/><br/>**Condicionalmente Obrigatório**:<ul><li>**Obrigatório** se routes.`route_long_name` estiver vazio. </li><li>Recomendado se houver uma breve designação de serviço. Este deve ser o nome pelo qual os passageiros geralmente conhecem o serviço e não deve ter mais de 12 caracteres.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `route_long_name`     | Texto                                        | Condicionalmente Obrigatório | Nome completo de uma rota. Este nome é geralmente mais descritivo do que o `route_short_name` e geralmente inclui o destino ou a paragem da rota. Tanto `route_short_name` como `route_long_name` podem ser definidos. <br/><br/>**Condicionalmente Obrigatório**:<ul><li>**Obrigatório** se routes.`route_short_name` estiver vazio. </li><li>Opcional caso contrário. </li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `route_desc`          | Texto                                        | Opcional                     | Descrição de uma rota que fornece informação útil e de qualidade. Não deve ser um duplicado de `route_short_name` ou `route_long_name`. <br/><br/>Exemplo: Os comboios da linha "A" operam entre Inwood-207 St, Manhattan e Far Rockaway-Mott Avenue, Queens, em todos os horários. Além disso, das 6h da manhã até aproximadamente à meia-noite, os comboios adicionais da linha "A" operam entre Inwood-207 St e Lefferts Boulevard (os comboios alternam normalmente entre Lefferts Blvd e Far Rockaway).                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `route_type`          | Enum                                         | Obrigatório                  | Indica o tipo de transporte utilizado numa rota. <br/>Opções válidas:<br/><br/>`0` - Eléctrico, LRT, Comboio Ligeiro. Qualquer sistema de comboio ligeiro ou de superfície numa área metropolitana.<br/>`1` - Metro. Qualquer sistema de metro subterrâneo numa área metropolitana.<br/>`2` - Comboio. Utilizado para viagens interurbanas ou de longa distância. <br/>`3` - Autocarro. Utilizado para percursos de autocarros de curta e longa distância.<br/>`4` - Ferry. Utilizado para serviços de barco de curta e longa distância. <br/>`5` - Eléctrico por cabo. Utilizado para elétricos de superfície em que o cabo corre por baixo do veículo (por exemplo, o elétrico por cabo em São Francisco). <br/>`6` - Teleférico, teleférico suspenso (por exemplo, teleférico de gôndola, teleférico aéreo). Transporte por cabo onde as cabines, carros, gôndolas ou cadeiras abertas são suspensas por meio de um ou mais cabos. <br/>`7` - Funicular. Qualquer sistema ferroviário concebido para inclinações acentuadas. <br/>`11` - Trólebus. Autocarros elétricos que obtêm energia de fios aéreos utilizando postes. <br/>`12` - Monocarril. Ferrovia na qual o carril consiste num único carril ou viga. |
| `route_url`           | URL                                          | Opcional                     | URL de uma página web sobre a rota específica. Deve ser diferente do valor de agency.`agency_url`.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| `route_color`         | Cor                                          | Opcional                     | Designação da cor da rota que corresponde ao material orientado para o público. O predefinido é branco (`FFFFFF`) quando omitido ou deixado em branco. A diferença de cor entre `route_color` e `route_text_color` deve proporcionar contraste suficiente quando visualizado num ecrã a preto e branco.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `route_text_color`    | Cor                                          | Opcional                     | Cor legível a utilizar para texto desenhado sobre um fundo de `route_color`. O predefinido é preto (000000) quando omitido ou deixado em branco. A diferença de cor entre `route_color` e `route_text_color` deve proporcionar contraste suficiente quando visualizada num ecrã a preto e branco.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `route_sort_order`    | Número inteiro não negativo                  | Opcional                     | Ordena as rotas de uma forma ideal para apresentação aos clientes. As rotas com valores mais baixos de `route_sort_order` devem ser apresentadas primeiro.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `continuous_pickup`   | Enum                                         | Proibido Condicionalmente    | Indica que o passageiro pode embarcar no veículo de transporte público em qualquer ponto ao longo do percurso do veículo, conforme descrito em shapes.txt, em todas as viagens da rota. <br/>Opções válidas:<br/><br/>`0` - Paragens contínuas para embarque. <br/>`1` ou vazio - Sem paragens contínuas para embarque. <br/>`2` - É necessário ligar para a agência para agendar paragens contínuas para embarque.<br/>`3` - É necessário coordenar com o motorista para agendar paragens contínuas para embarque.<br/><br/>Os valores para routes.`continuous_pickup` podem ser substituídos definindo valores em `stop_times.continuous_pickup` para `stop_times` específicos ao longo da rota. <br/><br/>**Proibido Condicionalmente**:<ul><li>**Proibido** se `stop_times.start_pickup_drop_off_window` ou `stop_times.end_pickup_drop_off_window` estiverem definidos para qualquer viagem desta rota. </li><li>Opcional.</li></ul>                                                                                                                                                                                                                                                                           |
| `continuous_drop_off` | Enum                                         | Proibido condicionalmente    | Indica que o passageiro pode desembarcar do veículo de transporte em qualquer ponto ao longo do percurso do veículo, conforme descrito em shapes.txt, em todas as viagens da rota. <br/><br/>As opções válidas são:<br/><br/>`0` - Desembarque com paragens contínuas. <br/>`1` ou vazio - Sem paradas contínuas para desembarque. <br/> `2` - É necessário ligar para a agência para combinar paradas contínuas para desembarque.<br/> `3` - É necessário coordenar com o motorista para combinar paradas contínuas para desembarque.<br/><br/>Os valores para routes.continuous_drop_off podem ser substituídos definindo valores em stop_times.continuous_drop_off para horários de parada específicos ao longo da rota. <br/><br/>**Proibido Condicionalmente**:<ul><li>**Proibido** se stop_times.start_pickup_drop_off_window ou stop_times.end_pickup_drop_off_window estiverem definidos para qualquer viagem desta rota. </li><li>Opcional.</li></ul>                                                                                                                                                                                                                                                      |
| `network_id`          | ID                                           | Proibido condicionalmente    | Identifica um grupo de rotas. Várias linhas em routes.txt podem ter o mesmo network_id.<br/><br/>**Proibido Condicionalmente**:<ul><li>**Proibido** se o arquivo route_networks.txt ou networks.txt existir. </li><li>Opcional.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
