---
title: trips
description: Define as viagens realizadas numa determinada rota e associa cada viagem ao respetivo horário de funcionamento.
---
**Presença**: Obrigatório

**Chave primária**: `trip_id`

---
### Campos GTFS Standard 

| Nome do Campo           | Tipo                                                                                 | Presença    | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| ----------------------- | ------------------------------------------------------------------------------------ | ----------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `route_id`              | ID externo que faz referência a `routes.route_id`                                    | Obrigatório | Identifica uma rota.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| `service_id`            | ID externo que faz referência a `calendar.service_id` ou `calendar_dates.service_id` | Obrigatório | Identifica um conjunto de datas em que o serviço está disponível para uma ou mais rotas.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| `trip_id`               | ID único                                                                             | Obrigatório | Identifica uma viagem.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| `trip_headsign`         | Texto                                                                                | Obrigatório | Texto que aparece na sinalização identificando o destino da viagem para os passageiros. Este campo é recomendado para todos os serviços com texto de sinalização apresentado no veículo, que pode ser utilizado para distinguir entre viagens numa rota. Se a sinalização mudar durante uma viagem, os valores de `trip_headsign` podem ser substituídos definindo valores em `stop_times.stop_headsign` para `stop_times` específicos ao longo viagem.                                                                                                                                                                                                                                                                                                                          |
| `direction_id`          | Enum                                                                                 | Obrigatório | Indica o sentido da viagem. Este campo não deve ser utilizado no cálculo de percursos; fornece uma forma de separar as viagens por sentido ao publicar tabelas de horários. <br><p><strong>Opções válidas:</strong></p><ul><li><code>0</code> - Viagem num sentido (por exemplo, viagem de ida).</li><li><code>1</code> - Viagem no sentido oposto (por exemplo, viagem de regresso).</li></ul><p><strong>Exemplo:</strong> Os campos `trip_headsign` e `direction_id` podem ser utilizados em conjunto para atribuir um nome à viagem em cada sentido para um conjunto de viagens. Um ficheiro `trips.txt` poderia conter estes registos para utilização em tabelas de horários: `trip_id`,...,`trip_headsign`,`direction_id`<br>1234,...,Airport,0 <br>1505,...,Downtown,1</p> |
| `block_id`              | ID                                                                                   | Opcional    | Identifica o bloco a que pertence a viagem. Um bloco consiste numa única viagem ou em várias viagens sequenciais realizadas com o mesmo veículo, definidas por dias de serviço partilhado e `block_id`. Um `block_id` pode ter viagens com dias de serviço diferentes, formando blocos distintos.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                |
| `shape_id`              | ID externo que referencia `shapes.shape_id`                                          | Obrigatório | Identifica uma forma geoespacial que descreve o trajeto do veículo para uma viagem.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                              |
| `wheelchair_accessible` | Enum                                                                                 | Opcional    | Indica acessibilidade para utilizadores de cadeira de rodas. <br><p><strong>Opções válidas:</strong></p><ul><li><code>0</code> ou vazio - Sem informação de acessibilidade para a viagem.</li><li><code>1</code> - O veículo utilizado nesta viagem específica pode acomodar pelo menos um passageiro em cadeira de rodas.</li><li><code>2</code> - Nenhum passageiro em cadeira de rodas pode ser acomodado nesta viagem.</li></ul>                                                                                                                                                                                                                                                                                                                                             |
| `bikes_allowed`         | Enum                                                                                 | Opcional    | Indica se as bicicletas são permitidas. <br><p><strong>Opções válidas:</strong></p><ul><li><code>0</code> ou vazio - Sem informação sobre bicicletas para a viagem.</li><li><code>1</code> - O veículo utilizado nesta viagem específica pode acomodar pelo menos uma bicicleta.</li><li><code>2</code> - As bicicletas não são permitidas nesta viagem.</li></ul>                                                                                                                                                                                                                                                                                                                                                                                                               |


#### Exemplo: Blocos e dia de serviço
O exemplo abaixo é válido, com blocos distintos para cada dia da semana.

| route_id | trip_id  | service_id                  | block_id | (primeira paragem) | (última paragem) |
| -------- | -------- | --------------------------- | -------- | ------------------ | ---------------- |
| vermelho | viagem_1 | seg-ter-qua-qui-sex-sáb-dom | red_loop | 22:00:00           | 22:55:00         |
| vermelho | viagem_2 | sex-sáb-dom                 | red_loop | 23:00:00           | 23:55:00         |
| vermelho | viagem_3 | sex-sáb                     | red_loop | 24:00:00           | 24:55:00         |
| vermelho | viagem_4 | seg-ter-qua-qui             | red_loop | 20:00:00           | 20:50:00         |
| vermelho | viagem_5 | seg-ter-qua-qui             | red_loop | 21:00:00           | 21:50:00         |

<p><strong>Observações sobre a tabela acima:</strong></p>
- Por exemplo, de sexta-feira para sábado de manhã, um único veículo opera as viagens 1, 2 e 3 (das 22h00 às 00h55). Note que a última viagem ocorre no sábado, das 00h00 às 00h55, mas faz parte do "dia de serviço" de sexta-feira, uma vez que os horários são das 24h00 às 24h55.
- De segunda a quinta-feira, um único veículo opera as viagens 1, 4 e 5 em bloco das 20h00 às 22h55.
