---
title: trips
description: Viagens para cada percurso. Uma viagem é uma sequência de duas ou mais paragens que ocorrem durante um período de tempo específico.
---
**Presença**: Obrigatório<br/>
**Chave primária**: `trip_id`
### Campos GTFS Standard 

| Nome do Campo           | Tipo                                                                                 | Presença                     | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                     |
| ----------------------- | ------------------------------------------------------------------------------------ | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `route_id`              | ID externo que faz referência a `routes.route_id`                                    | Obrigatório                  | Identifica uma rota.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| `service_id`            | ID externo que faz referência a `calendar.service_id` ou `calendar_dates.service_id` | Obrigatório                  | Identifica um conjunto de datas em que o serviço está disponível para uma ou mais rotas.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| `trip_id`               | ID único                                                                             | Obrigatório                  | Identifica uma viagem.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                        |
| `trip_headsign`         | Texto                                                                                | Opcional                     | Texto que aparece na sinalização identificando o destino da viagem para os passageiros. <br/>Este campo é recomendado para todos os serviços com texto de sinalização apresentado no veículo, que pode ser utilizado para distinguir entre viagens numa rota. <br/><br/>Se a sinalização mudar durante uma viagem, os valores de `trip_headsign` podem ser substituídos definindo valores em `stop_times.stop_headsign` para `stop_times` específicos ao longo viagem.                                                                                                                                                                                                                        |
| `trip_short_name`       | Texto                                                                                | Opcional                     | Texto visível ao público utilizado para identificar a viagem para os passageiros, por exemplo, para identificar os números dos comboios nas viagens de comboio suburbano. <br/>Se os passageiros não utilizam frequentemente os nomes das viagens, `trip_short_name` deve estar vazio. <br/><br/>Um valor de `trip_short_name`, se fornecido, deve identificar exclusivamente uma viagem num dia de serviço; não deve ser utilizado para nomes de destino ou designações limitadas/expressas.                                                                                                                                                                                                 |
| `direction_id`          | Enum                                                                                 | Opcional                     | Indica o sentido da viagem. Este campo não deve ser utilizado no encaminhamento; fornece uma forma de separar as viagens por sentido ao publicar tabelas de horários. <br/><br/>Opções válidas:<br/>`0` - Viagem num sentido (por exemplo, viagem de ida).<br/>`1` - Viagem no sentido oposto (por exemplo, viagem de regresso). <br/><br/>Exemplo: Os campos `trip_headsign` e `direction_id` podem ser utilizados em conjunto para atribuir um nome à viagem em cada sentido para um conjunto de viagens. Um ficheiro `trips.txt` poderia conter estes registos para utilização em tabelas de horários: `trip_id`,...,`trip_headsign`,`direction_id` 1234,...,Airport,0 1505,...,Downtown,1 |
| `block_id`              | ID                                                                                   | Opcional                     | Identifica o bloco a que pertence a viagem. Um bloco consiste numa única viagem ou em várias viagens sequenciais realizadas com o mesmo veículo, definidas por dias de serviço partilhado e `block_id`. Um `block_id` pode ter viagens com dias de serviço diferentes, formando blocos distintos. <br/><br/>Veja o exemplo abaixo. Para fornecer informações sobre as transferências no assento, devem ser fornecidas as transferências do tipo `transfer_type` 4.                                                                                                                                                                                                                            |
| `shape_id`              | ID externo que referencia `shapes.shape_id`                                          | Condicionalmente obrigatório | Identifica uma forma geoespacial que descreve o trajeto do veículo para uma viagem. <br/><br/>**Condicionalmente obrigatório**:<ul><li>Obrigatório se a viagem tiver um comportamento contínuo de embarque ou desembarque definido em `routes.txt` ou em `stop_times.txt`.</li><li>Opcional caso contrário.</li></ul>                                                                                                                                                                                                                                                                                                                                                                         |
| `wheelchair_accessible` | Enum                                                                                 | Opcional                     | Indica acessibilidade para utilizadores de cadeira de rodas. <br/><br/>Opções válidas:<br/>`0` ou vazio - Sem informação de acessibilidade para a viagem. <br/>`1` - O veículo utilizado nesta viagem específica pode acomodar pelo menos um passageiro em cadeira de rodas. <br/>`2` - Nenhum passageiro em cadeira de rodas pode ser acomodado nesta viagem.                                                                                                                                                                                                                                                                                                                                |
| `bikes_allowed`         | Enum                                                                                 | Opcional                     | Indica se as bicicletas são permitidas. <br/><br/>Opções válidas:<br/>`0` ou vazio - Sem informação sobre bicicletas para a viagem. <br/>`1` - O veículo utilizado nesta viagem específica pode acomodar pelo menos uma bicicleta. <br/>`2` - As bicicletas não são permitidas nesta viagem.                                                                                                                                                                                                                                                                                                                                                                                                  |

#### Exemplo: Blocos e dia de serviço
O exemplo abaixo é válido, com blocos distintos para cada dia da semana.

| route_id | trip_id  | service_id                  | block_id | (primeira paragem) | (última paragem) |
| -------- | -------- | --------------------------- | -------- | ------------------ | ---------------- |
| vermelho | viagem_1 | seg-ter-qua-qui-sex-sáb-dom | red_loop | 22:00:00           | 22:55:00         |
| vermelho | viagem_2 | sex-sáb-dom                 | red_loop | 23:00:00           | 23:55:00         |
| vermelho | viagem_3 | sex-sáb                     | red_loop | 24:00:00           | 24:55:00         |
| vermelho | viagem_4 | seg-ter-qua-qui             | red_loop | 20:00:00           | 20:50:00         |
| vermelho | viagem_5 | seg-ter-qua-qui             | red_loop | 21:00:00           | 21:50:00         |

**Observações sobre a tabela acima**:

- Por exemplo, de sexta-feira para sábado de manhã, um único veículo opera as viagens 1, 2 e 3 (das 22h00 às 00h55). Note que a última viagem ocorre no sábado, das 00h00 às 00h55, mas faz parte do "dia de serviço" de sexta-feira, uma vez que os horários são das 24h00 às 24h55.
- De segunda a quinta-feira, um único veículo opera as viagens 1, 4 e 5 em bloco das 20h00 às 22h55.
