title: Regras do validador
description: Regras utilizadas pela TML para a validação dos gtfs

**Presença**: Obrigatório<br/>
**Chave primária**: agency_id
### Campos GTFS Standard

| Nome do Campo   | Tipo               | Presença                     | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                             |
| --------------- | ------------------ | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| agency_id       | ID Único           | Condicionalmente obrigatório | Identifica uma marca de transporte, que é geralmente sinónimo de agência de transporte. Note que, em alguns casos, como quando uma única agência opera vários serviços separados, as agências e as marcas são distintas. Este documento utiliza o termo "agência" em vez de "marca". Um conjunto de dados pode conter dados de várias agências. Condicionalmente obrigatório: - Obrigatório quando o conjunto de dados contém dados para várias agências de transporte. - Recomendado caso contrário. |
| nome_agency     | Texto              | Obrigatório                  | Nome completo da agência de transporte.                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| agency_url      | URL                | Obrigatório                  | URL da agência de transporte.                                                                                                                                                                                                                                                                                                                                                                                                                                                                         |
| agency_timezone | Fuso horário       | Obrigatório                  | Fuso horário onde se encontra a agência de transporte. Se forem especificadas várias agências no conjunto de dados, cada uma deverá ter o mesmo agency_timezone.                                                                                                                                                                                                                                                                                                                                      |
| agency_lang     | Código do idioma   | Opcional                     | Idioma principal utilizado por esta agência de transporte. Deve ser fornecido para ajudar os utilizadores do GTFS a escolher regras de capitalização e outras definições específicas de idioma para o conjunto de dados.                                                                                                                                                                                                                                                                              |
| agency_phone    | Número de telefone | Opcional                     | Um número de telefone para a agência especificada. Este campo é um valor de string que apresenta o número de telefone como típico para a área de serviço da agência. Pode conter sinais de pontuação para agrupar os dígitos do número. O texto discável (por exemplo, "503-238-RIDE" da TriMet) é permitido, mas o campo não deve conter qualquer outro texto descritivo.                                                                                                                            |
| agency_fare_url | URL                | Opcional                     | URL de uma página web onde um passageiro pode comprar bilhetes ou outros instrumentos de tarifa para essa agência, ou uma página web contendo informações sobre as tarifas dessa agência.                                                                                                                                                                                                                                                                                                             |
| agency_email    | E-mail             | Opcional                     | Endereço de e-mail monitorizado ativamente pelo departamento de apoio ao cliente da agência. Este endereço de e-mail deve ser um ponto de contacto direto onde os utilizadores dos transportes públicos podem contactar um representante do serviço de apoio ao cliente da agência.                                                                                                                                                                                                                   |
