---
title: agency.txt
description: Contém informações sobre o operador (ou operadores) que fornecem os serviços de transporte descritos no arquivo GTFS.
---

| Versão                                                                        | Presença             |
| ----------------------------------------------------------------------------- | -------------------- |
| [GTFS Standard](https://gtfs.org/documentation/schedule/reference/#agencytxt) | Ficheiro obrigatório |
| GTFS v30 (GO)                                                                 | Ficheiro obrigatório |

## Chave Primária

O conteúdo deste ficheiro é identificado pelos valores da coluna `agency_id`.

## Estrutura

| Coluna            |        Tipo        | GTFS Standard |     GTFS v30    | Descrição                                                                                                                                                                                                                                            |
| ----------------- | :----------------: | :-----------: | :-------------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `agency_id`       |  Texto (ID único)  |  Recomendado  | **Obrigatório** | Representa o código único do operador de transporte. Um arquivo GTFS pode conter vários operadores, mas no GO só são aceites arquivos mono-operador.                                                                                                 |
| `agency_name`     |        Texto       |  Obrigatório  | **Obrigatório** | Nome da marca do operador.                                                                                                                                                                                                                           |
| `agency_url`      |         URL        |  Obrigatório  |     Opcional    | URL do website do operador.                                                                                                                                                                                                                          |
| `agency_timezone` |    Fuso horário    |  Obrigatório  |     Opcional    | Fuso horário que deve ser considerado para a informação presente no arquivo GTFS, de acordo com a [base de dados da IANA](https://www.iana.org/time-zones).                                                                                          |
| `agency_lang`     |  Código de idioma  |    Opcional   |     Opcional    | Idioma principal do operador, de acordo com a [base de dados da IANA](https://www.w3.org/International/articles/language-tags). É utilizado para definir regras de capitalização e outras definições específicas de idioma para o conjunto de dados. |
| `agency_phone`    | Número de telefone |    Opcional   |     Opcional    | Número de telefone para o canal de atendimento ao público do operador.                                                                                                                                                                               |
| `agency_fare_url` |         URL        |    Opcional   |     Opcional    | URL do website onde é possível consultar informações sobre tarifas ou comprar bilhetes de bordo.                                                                                                                                                     |
| `agency_email`    |       E-mail       |    Opcional   |     Opcional    | Endereço de email do canal de atendimento ao público do operador.                                                                                                                                                                                    |
| `cemv_support`    |        Enum        |    Opcional   |     Opcional    | Indica se o pagamento bancário a bordo está disponível para os serviços deste operador.                                                                                                                                                              |
