---
title: calendar
description: Datas de serviço especificadas utilizando um horário semanal com datas de início e de fim.
---
**Presença**: Condicionalmente Obrigatório<br/>
- **Obrigatório**: a menos que todas as datas de serviço estejam definidas em `calendar_dates.txt`.<br/>
- **Opcional**: caso contrário.
**Chave primária**: service_id
### Campos GTFS Standard

| Nome do Campo  | Tipo     | Presença do standard | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                       |
| -------------- | -------- | -------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `service_id`   | ID Único | Obrigatório          | Identifica um conjunto de datas em que o serviço está disponível para uma ou mais rotas.                                                                                                                                                                                                                                                                                                                                                        |
| `monday`       | Enum     | Obrigatório          | Indica se o serviço opera em todas as segundas-feiras no intervalo de datas especificado pelos campos start_date e end_date. Note que as exceções para datas específicas podem estar listadas em calendar_dates.txt.<br/><br/>**Opções válidas:**<ul><li>`1` - O serviço está disponível para todas as segundas-feiras no intervalo de datas.</li><li>`0` - O serviço não está disponível para segundas-feiras no intervalo de datas.</li></ul> |
| `terça-feira`  | Enum     | Obrigatório          | Funciona da mesma forma que segunda-feira, exceto que se aplica às terças-feiras                                                                                                                                                                                                                                                                                                                                                                |
| `quarta-feira` | Enum     | Obrigatório          | Funciona da mesma forma que segunda-feira, exceto que se aplica às quartas-feiras                                                                                                                                                                                                                                                                                                                                                               |
| `quinta-feira` | Enum     | Obrigatório          | Funciona da mesma forma que a segunda-feira, exceto que se aplica às quintas-feiras                                                                                                                                                                                                                                                                                                                                                             |
| `sexta-feira`  | Enum     | Obrigatório          | Funciona da mesma forma que segunda-feira, só que se aplica às sextas-feiras                                                                                                                                                                                                                                                                                                                                                                    |
| `sábado`       | Enum     | Obrigatório          | Funciona da mesma forma que segunda-feira, só que se aplica aos sábados.                                                                                                                                                                                                                                                                                                                                                                        |
| `domingo`      | Enum     | Obrigatório          | Funciona da mesma forma que segunda-feira, só que se aplica aos domingos.                                                                                                                                                                                                                                                                                                                                                                       |
| `data_inicial` | Data     | Obrigatório          | Dia de início do serviço para o intervalo de serviço.                                                                                                                                                                                                                                                                                                                                                                                           |
| `data_fim`     | Data     | Obrigatório          | Dia de fim do serviço para o intervalo de serviço. Este dia de serviço está incluído no intervalo.                                                                                                                                                                                                                                                                                                                                              |
