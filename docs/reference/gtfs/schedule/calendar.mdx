---
title: calendar
description: Define os dias da semana e o período em que os serviços estão disponíveis.
---
**Presença**: Condicionalmente Obrigatório
- **Obrigatório**, exceto quando todas as datas de serviço estão definidas em `calendar_dates.txt`.

**Chave primária**: `service_id`

---
### Campos GTFS Standard

| Nome do Campo | Tipo     | Presença    | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                           |
| ------------- | -------- | ----------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `service_id`  | ID Único | Obrigatório | Identifica um conjunto de datas em que o serviço está disponível para uma ou mais rotas.                                                                                                                                                                                                                                                                                                                                                                                            |
| `monday`      | Enum     | Obrigatório | Indica se o serviço opera em todas as segundas-feiras no intervalo de datas especificado pelos campos `start_date` e `end_date`. Note que as exceções para datas específicas podem estar listadas em `calendar_dates.txt`. Opções válidas: 1 - O serviço está disponível para todas as segundas-feiras no intervalo de datas. 0 - O serviço não está disponível para segundas-feiras no intervalo de datas.                                                                         |
| `tuesday`     | Enum     | Obrigatório | Funciona da mesma forma que segunda-feira, aplicando-se às terças-feiras                                                                                                                                                                                                                                                                                                                                                                                                            |
| `wednesday`   | Enum     | Obrigatório | Funciona da mesma forma que segunda-feira, aplicando-se às quartas-feiras                                                                                                                                                                                                                                                                                                                                                                                                           |
| `thursday`    | Enum     | Obrigatório | Funciona da mesma forma que a segunda-feira, aplicando-se às quintas-feiras                                                                                                                                                                                                                                                                                                                                                                                                         |
| `friday`      | Enum     | Obrigatório | Funciona da mesma forma que segunda-feira, aplicando-se às sextas-feiras                                                                                                                                                                                                                                                                                                                                                                                                            |
| `saturday`    | Enum     | Obrigatório | Funciona da mesma forma que segunda-feira, aplicando-se aos sábados.                                                                                                                                                                                                                                                                                                                                                                                                                |
| `sunday`      | Enum     | Obrigatório | Funciona da mesma forma que segunda-feira, aplicando-se aos domingos.                                                                                                                                                                                                                                                                                                                                                                                                               |
| `start_date`  | Data     | Obrigatório | Dia de início do serviço para o intervalo de serviço.                                                                                                                                                                                                                                                                                                                                                                                                                               |
| `end_date`    | Data     | Obrigatório | Dia de fim do serviço para o intervalo de serviço. Este dia de serviço está incluído no intervalo.                                                                                                                                                                                                                                                                                                                                                                                  |
