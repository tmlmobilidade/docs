| Versão                                                                          | Presença                        |
| ------------------------------------------------------------------------------- | ------------------------------- |
| [GTFS Standard](https://gtfs.org/documentation/schedule/reference/#calendartxt) | Ficheiro condicionalobrigatório |
| GTFS v30 (GO)                                                                   | Ficheiro obrigatório            |

## Chave Primária

O conteúdo deste ficheiro é identificado pelos valores da coluna `service_id`.

## Estrutura

| Nome do Campo |   Tipo   | GTFS Standard |    GTFS v30     | Descrição                                                                                                                                                                                                                                                                                                                                                                                                   |
| ------------- | :------: | :-----------: | :-------------: | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `service_id`  | ID Único |  Obrigatório  | **Obrigatório** | Identifica um conjunto de datas em que o serviço está disponível para uma ou mais rotas.                                                                                                                                                                                                                                                                                                                    |
| `monday`      |   Enum   |  Obrigatório  | **Obrigatório** | Indica se o serviço opera em todas as segundas-feiras no intervalo de datas especificado pelos campos `start_date` e `end_date`. Note que as exceções para datas específicas podem estar listadas em `calendar_dates.txt`. Opções válidas: 1 - O serviço está disponível para todas as segundas-feiras no intervalo de datas. 0 - O serviço não está disponível para segundas-feiras no intervalo de datas. |
| `tuesday`     |   Enum   |  Obrigatório  | **Obrigatório** | Funciona da mesma forma que segunda-feira, aplicando-se às terças-feiras                                                                                                                                                                                                                                                                                                                                    |
| `wednesday`   |   Enum   |  Obrigatório  | **Obrigatório** | Funciona da mesma forma que segunda-feira, aplicando-se às quartas-feiras                                                                                                                                                                                                                                                                                                                                   |
| `thursday`    |   Enum   |  Obrigatório  | **Obrigatório** | Funciona da mesma forma que a segunda-feira, aplicando-se às quintas-feiras                                                                                                                                                                                                                                                                                                                                 |
| `friday`      |   Enum   |  Obrigatório  | **Obrigatório** | Funciona da mesma forma que segunda-feira, aplicando-se às sextas-feiras                                                                                                                                                                                                                                                                                                                                    |
| `saturday`    |   Enum   |  Obrigatório  | **Obrigatório** | Funciona da mesma forma que segunda-feira, aplicando-se aos sábados.                                                                                                                                                                                                                                                                                                                                        |
| `sunday`      |   Enum   |  Obrigatório  | **Obrigatório** | Funciona da mesma forma que segunda-feira, aplicando-se aos domingos.                                                                                                                                                                                                                                                                                                                                       |
| `start_date`  |   Data   |  Obrigatório  | **Obrigatório** | Dia de início do serviço para o intervalo de serviço.                                                                                                                                                                                                                                                                                                                                                       |
| `end_date`    |   Data   |  Obrigatório  | **Obrigatório** | Dia de fim do serviço para o intervalo de serviço. Este dia de serviço está incluído no intervalo.                                                                                                                                                                                                                                                                                                          |
