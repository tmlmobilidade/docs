| Versão                                                                       | Presença             |
| ---------------------------------------------------------------------------- | -------------------- |
| [GTFS Standard](https://gtfs.org/documentation/schedule/reference/#stopstxt) | Ficheiro obrigatório |
| GTFS v30 (GO)                                                                | Ficheiro obrigatório |

## Chave Primária

O conteúdo deste ficheiro é identificado pelos valores da coluna `stop_id`.

## Estrutura

| Coluna                |    Tipo    |         GTFS Standard        |             GTFS v30             | Descrição                                                                                                                                                                                                                                                                                                                                                                                              |
| --------------------- | :--------: | :--------------------------: | :------------------------------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `stop_id`             |  ID Único  |          Obrigatório         |          **Obrigatório**         | Identificador único para um ponto de paragem na rede.                                                                                                                                                                                                                                                                                                                                                  |
| `stop_code`           |    Texto   |           Opcional           |          **Obrigatório**         | Identificador público para um ponto de paragem na rede. No GTFS v30 deve ser igual ao valor do `stop_id`.                                                                                                                                                                                                                                                                                              |
| `stop_name`           |    Texto   | Condicionalmente obrigatório |          **Obrigatório**         | Nome do ponto de paragem tal como apresentado ao público.                                                                                                                                                                                                                                                                                                                                              |
| `stop_lat`            |  Latitude  | Condicionalmente obrigatório |          **Obrigatório**         | Latitude com 6 casas decimais. As coordenadas devem representar o ponto exato do local (ex: ponto exato do abrigo/poste no passeio), e não uma localização aproximada (ex: eixo central da via).                                                                                                                                                                                                       |
| `stop_lon`            |  Longitude | Condicionalmente obrigatório |          **Obrigatório**         | Longitude com 6 casas decimais. As coordenadas devem representar o ponto exato do local (ex: ponto exato do abrigo/poste no passeio), e não uma localização aproximada (ex: eixo central da via).                                                                                                                                                                                                      |
| `location_type`       |    Enum    |           Optional           |          **Obrigatório**         | Indica se é um ponto de paragem (embarque/desembarque de veículo — paragem, cais, plataforma), uma estação com vários pontos de paragem (ex: terminal) ou um acesso a um edifício (ex: entrada do metro). Valores possíveis estão disponíveis na [documentação oficial do GTFS](https://gtfs.org/documentation/schedule/reference/#stopstxt:~\:text=route_url%20field%20values.-,location_type,-Enum). |
| `parent_station`      | ID externo | Condicionalmente obrigatório | **Condicionalmente obrigatório** | Define o ponto de paragem ao qual este ponto pertence. É com este campo que se estrutura a hierarquia entre os diferentes locais definidos neste ficheiro. Em função do location\_type, este campo deve estar preenchido com o valor do ponto principal, ou então vazio se este ponto for uma paragem individual.                                                                                      |
| `wheelchair_boarding` |    Enum    |           Opcional           |          **Obrigatório**         | Indica se é possível o embarque de utilizadores de cadeira de rodas neste local. Valores possíveis estão disponíveis na [documentação oficial do GTFS](https://gtfs.org/documentation/schedule/reference/#stopstxt:~\:text=the%20trip%20crosses.-,wheelchair_boarding,-Enum).                                                                                                                          |
| `platform_code`       |    Texto   |           Opcional           |             Opcional             | Identificador da plataforma para um ponto que pertence a uma estação. Deve ser apenas o identificador da plataforma (por exemplo, "G" ou "3"). Palavras como "plataforma" ou "via" não devem ser incluídas.                                                                                                                                                                                            |
