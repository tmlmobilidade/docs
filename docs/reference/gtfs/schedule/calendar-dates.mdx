| Versão                                                                          | Presença                              |
| ------------------------------------------------------------------------------- | ------------------------------------- |
| [GTFS Standard](https://gtfs.org/documentation/schedule/reference/#calendartxt) | Ficheiro condicionalmente obrigatório |
| GTFS v30 (GO)                                                                   | Ficheiro obrigatório                  |

A tabela `calendar_dates.txt` define explicitamente, para cada data, se um serviço está ativo ou inativo. Pode ser utilizada de duas formas:
Recomendado: Utilizar `calendar_dates.txt` em conjunto com `calendar.txt` para definir exceções aos padrões de funcionamento predefinidos em `calendar.txt`. Esta abordagem é adequada quando o serviço é geralmente regular, mas existem algumas alterações em datas específicas (por exemplo, para acomodar serviços especiais durante eventos ou horários escolares). Neste caso, `calendar_dates.service_id` é um ID externo que referencia `calendar.service_id`.

Alternativa: Omitir `calendar.txt` e especificar cada dia de funcionamento em `calendar_dates.txt`. Esta abordagem permite uma maior variação dos serviços e acomoda serviços que não seguem horários semanais regulares. Neste caso, service_id é um ID.

## Chave Primária

O conteúdo deste ficheiro é identificado pelos valores da coluna `service_id`.

## Estrutura

| Nome do Campo    |    Tipo    | GTFS Standard |    GTFS v30     | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                  |
| ---------------- | :--------: | :-----------: | :-------------: | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `service_id`     | ID externo |  Obrigatório  | **Obrigatório** | Identifica um conjunto de datas em que ocorre uma exceção de serviço para uma ou mais rotas. Cada par (`service_id`, `date`) só pode aparecer uma vez em `calendar_dates.txt` se `calendar.txt` e `calendar_dates.txt` forem utilizados em conjunto. Se um valor de `service_id` aparecer tanto em `calendar.txt` como em `calendar_dates.txt`, a informação em `calendar_dates.txt` modifica a informação de serviço especificada em `calendar.txt`.                                                                                                                                                                                                                                                      |
| `date`           |    Data    |  Obrigatório  | **Obrigatório** | Data em que ocorre a exceção de serviço.                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                   |
| `exception_type` |    Enum    |  Obrigatório  | **Obrigatório** | Indica se o serviço está disponível na data especificada no campo `date`. Opções válidas: 1 - O serviço foi adicionado para a data especificada. 2 - O serviço foi removido para a data especificada. Exemplo: Suponha que uma rota tem um conjunto de viagens disponíveis nos feriados e outro conjunto de viagens disponíveis em todos os outros dias. Um service_id pode corresponder ao horário de funcionamento regular e outro service_id pode corresponder ao horário de funcionamento nos feriados. Para um feriado específico, o ficheiro `calendar_dates.txt` pode ser utilizado para adicionar o feriado ao service_id de feriado e para remover o feriado do horário de funcionamento regular. |
