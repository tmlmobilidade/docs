## Campos que serão validados nesta regra

| Nome do Campo | Tipo | Presença    | Descrição                     |
| ------------- | ---- | ----------- | ----------------------------- |
| `agency_url`  | URL  | Obrigatório | URL da agência de transporte. |




## O que esta validação faz 

No ficheiro `agency.txt`,  o campo `agency_url` exige o endereço (URL) da página Web do operador de transportes. Esta verificação garante que o valor existe, que tem forma de URL aceite pelas regras.

---

### Passa

- O campo está preenchido com um URL válido e, se existir lista de valores permitidos na regra, o endereço está nessa lista.

---

### Falha

- O campo está em falta.
- O texto não é um URL aceite pelo formato verificado.
- O URL está preenchido mas não consta da lista admitida pela regra, quando essa lista é fechada.
