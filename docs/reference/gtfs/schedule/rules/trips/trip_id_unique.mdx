## Regras de validação do campo trip_id


### Campos que serão validados nesta regra

| Nome do Campo | Tipo     | Presença    | Descrição              |
| ------------- | -------- | ----------- | ---------------------- |
| `trip_id`     | ID único | Obrigatório | Identifica uma viagem. |



### O que esta validação faz 

 O campo identifica, de forma única no feed, cada viagem em `trips.txt`. No GTFS o campo é obrigatório e não pode repetir-se: cada identificador deve corresponder a no máximo um registo.

---

#### Passa

- O identificador da viagem vem preenchido.
- Esse identificador não se repete - não existe mais do que uma linha com o mesmo `trip_id` no conjunto de dados.

---

#### Falha

- Identificador em falta - o `trip_id` não vem fornecido.
- Duplicado - o mesmo `trip_id` aparece em mais do que um registo; deixa de ser possível referenciar a viagem de forma inequívoca.
