## Campos que serão validados nesta regra

| Nome do Campo | Tipo     | Presença    | Descrição              |
| ------------- | -------- | ----------- | ---------------------- |
| `trip_id`     | ID único | Obrigatório | Identifica uma viagem. |

## O que esta validação faz

No ficheiro `trips.txt`, a regra limita o comprimento do `trip_id` (regra especifica da TML)

---

### Passa

- Se o `trip_id` tiver 36 caracteres ou menos. Porquê: cumpre o limite máximo imposto pelo validador.
- Se `trip_id` for nulo - a função sai sem erro (não aplica o limite de comprimento neste passo; a obrigatoriedade do campo é outra validação). Porquê: só há verificação de tamanho quando existe valor para medir.

---

### Falha

- Se o `trip_id` tiver mais de 36 caracteres. Porquê: identificadores demasiado longos fogem ao limite acordado para integrações, chaves ou armazenamento.
