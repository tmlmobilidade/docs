## Regras de validação do campo shape_id

| Nome do Campo | Tipo                                        | Presença                     | Descrição                                                                                                                                                                                                                                                                                                             |
| ------------- | ------------------------------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `shape_id`    | ID externo que referencia `shapes.shape_id` | Condicionalmente obrigatório | Identifica uma forma geoespacial que descreve o trajeto do veículo para uma viagem. <br/><br/>**Condicionalmente obrigatório**:<ul><li>Obrigatório se a viagem tiver um comportamento contínuo de embarque ou desembarque definido em `routes.txt` ou em `stop_times.txt`.</li><li>Opcional caso contrário.</li></ul> |


### O que esta validação faz

Garante que `pattern_id` e `shape_id` andam aos pares de forma estável:  
Para cada `pattern_id` → uma `shape_id`; 

O que esta regra faz para a validação acontença corretamente: 
- Passa se: 
- Falha se: no mesmo `pattern_id` aparecem dois ou mais `shape_id` diferentes (entre viagens que têm `shape_id` preenchido).

Exemplo intuitivo:  
Padrão A não pode ter uma trip com shape S1 e outra com shape S2. Ou é S1 para todas (com `shape_id`), ou há mistura só com trips sem shape — aí a contagem de shapes distintas pode continuar ≤ 1.

Mensagem: indica o `pattern_id` problemático (`shape_id_group_validation.different_shape_id`).
