## Regras de validação do campo shape_id

| Nome do Campo | Tipo                                        | Presença                     | Descrição                                                                                                                                                                                                                                                                                                             |
| ------------- | ------------------------------------------- | ---------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `shape_id`    | ID externo que referencia `shapes.shape_id` | Condicionalmente obrigatório | Identifica uma forma geoespacial que descreve o trajeto do veículo para uma viagem. <br/><br/>**Condicionalmente obrigatório**:<ul><li>Obrigatório se a viagem tiver um comportamento contínuo de embarque ou desembarque definido em `routes.txt` ou em `stop_times.txt`.</li><li>Opcional caso contrário.</li></ul> |


### O que esta validação faz (agrupado por `pattern_id`)

Garante que, para um dado `shape_id`, todas as viagens com `pattern_id` preenchido referem o mesmo padrão: no máximo um `pattern_id` distinto nesse conjunto. Viagens com `pattern_id` vazio não entram nesse cálculo.

comportamento:

- Válido: zero ou um `pattern_id` distinto entre as que têm o campo definido.
- Inválido: dois ou mais `pattern_id` diferentes para o mesmo `shape_id` (mensagem alinhada com o i18n: o `shape_id` é usado em múltiplos `pattern_ids`).

Nota: Isto não exige que todas as viagens tenham `shape_id`; basta que, entre as que têm, não haja conflito (por exemplo, algumas a `NULL` e outras com o mesmo `shape_id` ainda passa).
