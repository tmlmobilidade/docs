## Campos que serão validados nesta regra

| Nome do Campo     | Tipo  | Presença | Descrição                                                                                                                                                      |
| ----------------- | ----- | -------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `eligibility_url` | Texto | Opcional | URL de uma página Web, em geral do operador, com informação pormenorizada sobre a categoria de utente ou sobre os critérios de elegibilidade a essa categoria. |

## O que esta validação faz 

No ficheiro `rider_categories`, o campo `eligibility_url` é o endereço de uma página Web (em geral do operador) com informação detalhada sobre a categoria de utente ou sobre os critérios de elegibilidade (quem pode usar tarifas ou títulos associados a essa categoria). No GTFS o campo é opcional. Se não for indicado, nada é verificado neste ponto. Se for indicado, o texto tem de ter forma de URL aceite pelas regras da aplicação. URLs inválidos são reportados como erro.

---

### Passa

- O campo está vazio ou omitido.
- O campo está preenchido com um URL válido segundo a verificação de formato usada.

---

### Falha

- O texto não é um URL aceite pelo formato verificado.
