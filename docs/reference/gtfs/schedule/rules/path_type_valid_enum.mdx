## Campos que serão validados nesta regra

| Nome do Campo | Tipo | Presença | Descrição                                                                                                                                                                                                                             |
| ------------- | ---- | -------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `path_type`   | Enum | Opcional | Indica o tipo de caminho de uma rota. <br/><br/> Opcções validas: <br/><br/> `1` - Primeiro tipo de caminho <br/> `2` - Segundo tipo de caminho <br/> `3` - Terceiro tipo de caminho <br/><br/> Nota: Esta regra é específica da TML  |




## O que esta validação faz 

No ficheiro `routes.txt`,  o campo `path_type` é uma regra da TML (não faz parte do GTFS standart), indica o tipo de percurso da rota para efeitos do operador. A documentação interna do feed associa normalmente aos valores 1, 2 e 3 a três tipos distintos de percurso.

A verificação trata o campo vazio como situação que pode merecer obrigatoriedade ou recomendação, conforme a severidade configurada - salvo quando essa verificação está em ignorar. Se o campo não é permitido no perfil de dados (proibido), qualquer valor preenchido incumpre.

---

### Passa

- `path_type` preenchido com valor admisível, sem incidir em proibição.
- Campo vazio quando a política não exige mensagem (por exemplo ignorar).
- Valor incluído nas opções permitidas para o feed, quando essa lista existe.

---

### Falha

- Campo proibido mas preenchido. 
- Valor fora da lista admitida. 
- Ausência sinalizada como obrigatória ou recomendada.
