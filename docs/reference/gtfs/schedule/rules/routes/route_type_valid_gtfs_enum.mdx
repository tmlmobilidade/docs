## O que esta validação faz 

O campo `route_type` indica o modo de transporte associado à rota, através de um código numérico obrigatório definido na referência GTFS (por exemplo elétrico ou metro ligeiro de superfície, metro ou comboio subterrâneo, comboio interurbano, autocarro, ferry, carro americano por cabo subterrâneo, teleférico ou gondola suspensa, funicular, trólei e monorail). Só são aceites os códigos que a especificação GTFS prevê para este campo. Se a regra limitar os modos admitidos, o código indicado tem de figurar nessa lista restrita (ou a regra tem de admitir explicitamente todos os valores válidos do GTFS).

---

### Passa

- O campo está preenchido com um código que o GTFS reconhece como tipo de rota válido.
- Quando existe lista de tipos permitidos na regra, o código pertence a essa lista (ou a regra não restringe além dos valores GTFS válidos).

---

### Falha

- O campo está em falta.
- O valor não corresponde a nenhum tipo de rota válido no GTFS.
- O código é válido no GTFS mas não consta dos tipos permitidos pela regra do AAAA, quando essa regra define uma lista fechada.
