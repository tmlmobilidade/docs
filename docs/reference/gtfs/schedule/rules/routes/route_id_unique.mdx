## Campos que serão validados nesta regra

| Nome do Campo | Tipo     | Presença    | Descrição            |
| ------------- | -------- | ----------- | -------------------- |
| `route_id`    | ID único | Obrigatório | Identifica uma rota. |




## O que esta validação faz 

Garante que cada linha de rotas tem uma referência de rota preenchida e que essa referência não coincide com a de nenhuma outra linha no mesmo ficheiro.

---

### Passa  
- A referência está definida e não há duas linhas com a mesma referência.

---

### Falha

- A referência está em falta ou aparece mais do que uma vez entre as rotas.
