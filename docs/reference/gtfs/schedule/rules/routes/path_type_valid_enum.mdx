## O que esta validação faz 

No `routes.txt`, o campo `path_type` é uma extensão TML (não faz parte do GTFS standart): indica o tipo de percurso da rota para efeitos do operador. A documentação interna do feed associa normalmente os valores 1, 2 e 3 a três tipos distintos de percurso.

A verficação trata o campo vazio como situação que pode merecer obrigatoriedade ou recomendação, conforme a severidade configurada — salvo quando essa verificação está em ignorar. Se o campo não é permitido no perfil de dados (proibido), qualquer valor preenchido incumpre. Quando existe lista de opções admitidas, o valor tem de pertencer a essa lista (ou a lista considerar “todas” as opções válidas).

---

### Passa

- `path_type` preenchido com valor admisível, sem incidir em proibição.
- Campo vazio quando a política não exige mensagem (por exemplo ignorar).
- Valor incluído nas opções permitidas para o feed, quando essa lista existe.

---

### Falha

- Campo proibido mas preenchido. _Correção:_ esvaziar `path_type` ou rever a política.
    
- Valor fora da lista admitida. _Correção:_ escolher 1, 2 ou 3 (ou outro valor explicitamente permitido no vosso perfil).
    
- Ausência sinalizada como obrigatória ou recomendada. _Correção:_ preencher `path_type` segundo a extensão TML ou ajustar a severidade.
