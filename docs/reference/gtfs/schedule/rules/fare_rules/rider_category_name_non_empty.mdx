## Campos que serão validados nesta regra

| Nome do Campo         | Tipo | Presença | Descrição |
| --------------------- | ---- | -------- | --------- |
| `rider_category_name` |      |          |           |

## O que esta validação faz 

No ficheiro `rider_categories`, o campo `rider_category_name` é a designação da categoria tal como o utente a vê em interfaces, horários ou comunicação do operador. O valor é obrigatório a nível desta verificação (tem de existir no registo). A severidade das mensagens pode ser afinada pela regra.

---

### Passa

- O nome da categoria está definido no registo.

---

### Falha

- O nome está em falta (campo não preenchido no modelo validado).
