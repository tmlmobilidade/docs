## Regras de validação do campo emission


### Campos que serão utilizados nesta regra

| Nome do Campo | Tipo | Presença    | Descrição                                                                                                                                                                                                                                                                                                                                                                                               |
| ------------- | ---- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `emission`    | Enum | obrigatório | Classe de emissões.<br/><br/>**Opções válidas:**<ul><li>`0` - Sem classificação de emissões (exceção).</li><li>`1` - EURO I.</li><li>`2` - EURO II.</li><li>`3` - EURO III.</li><li>`4` - EURO IV.</li><li>`5` - EURO V.</li><li>`6` - EURO VI.</li></ul><br/>Este campo indica a norma de emissões do veículo. O valor **0** é usado em casos excecionais para veículos sem classificação de emissões. |



### O que esta validação faz 

O campo indica, para cada veículo, se existe informação de som de exterior (no sentido de public address ou avisos acústicos para o exterior), na convenção: não (0) e sim (1).

A validação exige o valor preenchido e contido nesse par de opções. Se o projecto definir regras com uma lista de opções permitidas, o registo de cada veículo tem de caber nessa lista; quando a configuração aceita todas as opções válidas, qualquer um dos dois valores (0 ou 1) é aceite, desde que correcto. A gravidade do aviso depende das regras, ou erro por omissão.

---

#### Passa

- Campo preenchido, valor 0 ou 1 e, havendo lista restritiva, opção autorizada pelas regras (ou regras que abrangem todas as opções válidas).

---

#### Falha

- Campo em falta – não se declara se o veículo tem ou não som / PA de exterior.
- Valor inválido – não é 0 nem 1.
