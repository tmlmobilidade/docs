## Regras de validação do campo wheelchair


### Campos que serão validados nesta regra

| Nome do Campo | Tipo | Presença    | Descrição                                                                                                                                  |
| ------------- | ---- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------ |
| `wheelchair`  | Enum | obrigatório | Indica se o veículo é acessível a pessoas em cadeira de rodas.<br/><br/>**Opções válidas:**<ul><li>`0` - Não.</li><li>`1` - Sim.</li></ul> |



### O que esta validação faz 

Garantir que, para cada veículo, fica explícito se existe acessibilidade para cadeira de rodas, utilizando apenas os valores permitidos pelo formato. na convenção: não (0) e sim (1).

---

#### Passa

- O campo está preenchido com 0 ou 1.
- Se o projecto tiver regras que limitam quais valores são aceites para este campo, o valor indicado tem de estar entre os permitidos; se as regras indicarem que todas as opções válidas são aceites, qualquer 0 ou 1 continua a ser aceite.

---

#### Falha

- O campo está em falta (não há indicação se o veículo tem ou não acessibilidade para cadeira de rodas).
- O valor não é 0 nem 1.
- O valor escolhido não é permitido pelas regras do projecto, quando essa restrição existe.
