## Campos que serão validados nesta regra

| Nome do Campo   | Tipo | Presença    | Descrição                                                                                                                          |
| --------------- | ---- | ----------- | ---------------------------------------------------------------------------------------------------------------------------------- |
| `climatization` | Enum | obrigatório | Indica se o veículo dispõe de sistema de climatização.<br/><br/>**Opções válidas:**<ul><li>`0` - Não.</li><li>`1` - Sim.</li></ul> |



## O que esta validação faz 

O campo descreve, para cada veículo, se existe climatização (p. ex. ar condicionado) ao nível a divulgar nos sistemas, como enumeração simples: não (0) e sim (1).

---

### Passa

- O campo está preenchido, o valor é 0 ou 1 e, se existir lista restritiva, corresponde a uma opção autorizada pelas regras.

---

### Falha

- Campo em falta – o veículo não indica se tem ou não climatização, conforme a convenção 0/1.
- Valor inválido – não é 0 nem 1, logo não mapeia para “não / sim” previstos.
- Incoerência com as regras do projecto – a opção escolhida não é permitida na lista das regras, quando essa restrição está activa.
