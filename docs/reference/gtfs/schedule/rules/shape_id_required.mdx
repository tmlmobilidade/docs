## Campos que serão validados nesta regra

| Nome do Campo | Tipo | Presença    | Descrição              |
| ------------- | ---- | ----------- | ---------------------- |
| `shape_id`    | ID   | Obrigatório | Identifica um formato. |

## O que esta validação faz 

O campo `shape_id` é o identificador de cada linha, define um vértice da forma (latitude, longitude, sequência, etc.) e pertence a uma forma concreta identificada por `shape_id`. Sem `shape_id`, os pontos não podem ser agrupados num único traçado.

Esta validação exige que `shape_id` esteja preenchido em cada registo. 

---

### Passa

- `shape_id` preenchido na linha.

---

### Falha

- `shape_id` vazio ou ausente. _Correção:_ indicar o identificador da forma (`shape_id`) coerente com o conjunto de pontos do mesmo traçado.
