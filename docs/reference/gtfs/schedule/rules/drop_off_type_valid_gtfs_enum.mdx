## Campos que serão validados nesta regra

| Nome do Campo   | Tipo | Presença                  | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
| --------------- | ---- | ------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `drop_off_type` | Enum | Proibido Condicionalmente | Indica o método de entrega.<br/>**Opções válidas:**<ul><li>`0` ou `vazio` - Entrega agendada regularmente.</li><li>`1` - Sem entrega disponível.</li><li>`2` - É necessário ligar para a agência para agendar a entrega.</li><li>`3` - É necessário coordenar com o motorista para agendar a entrega.</li></ul>**Proibido Condicionalmente**:<ul><li>`0` **proibido** se `start_pickup_drop_off_window` ou `end_pickup_drop_off_window` estiverem definidos.</li><li>Opcional caso contrário.</li></ul> |



## O que esta validação faz

Esta validação confirma que `drop_off_type`, no ficheiro `stop_times.txt`, usa um dos valores GTFS permitidos: `0`, `1`, `2` ou `3`.

Também valida a regra condicional do GTFS: quando `start_pickup_drop_off_window` ou `end_pickup_drop_off_window` estão preenchidos, `drop_off_type=0` é proibido.


---

### Passa

- `drop_off_type` está vazio ou tem um valor dentro do enumerado GTFS: `0`, `1`, `2` ou `3`.
- `drop_off_type=0` só é usado quando `start_pickup_drop_off_window` e `end_pickup_drop_off_window` estão vazios.
- Com `start_pickup_drop_off_window` ou `end_pickup_drop_off_window` preenchido, `drop_off_type` usa um valor diferente de `0`, por exemplo `1`, `2` ou `3`.
- Se a regra tiver opções configuradas para o feed, `drop_off_type` está incluído nessas opções.


---

### Falha

- Valor inválido - `drop_off_type` tem um número fora do enumerado GTFS, ou seja, não é `0`, `1`, `2` nem `3`.
- Proibido com janelas - `drop_off_type=0` é usado quando `start_pickup_drop_off_window` ou `end_pickup_drop_off_window` estão preenchidos.
- Valor não admitido - `drop_off_type` é válido no GTFS, mas não está incluído nas opções configuradas para o feed.
- Ausência com obrigatoriedade ou recomendação - `drop_off_type` está vazio quando a regra está configurada para reportar presença obrigatória ou recomendada.
