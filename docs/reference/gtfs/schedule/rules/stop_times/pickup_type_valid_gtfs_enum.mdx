## Campos que serão utilizados nesta regra

| Nome do Campo | Tipo | Presença                  | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                          |
| ------------- | ---- | ------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `pickup_type` | Enum | Proibido Condicionalmente | Indica o método de recolha. <br/>**Opções válidas:**<ul><li>`0` ou `vazio` - Recolha programada regularmente.</li><li>`1` - Sem recolha disponível.</li><li>`2` - É necessário ligar para a agência para agendar a recolha.</li><li>`3` - É necessário coordenar com o motorista para agendar a recolha.</li></ul>**Proibido Condicionalmente**:<ul><li>`pickup_type=0` **proibido** se `start_pickup_drop_off_window` ou `end_pickup_drop_off_window` estiverem definidos.</li><li>`pickup_type=3` **proibido** se `start_pickup_drop_off_window` ou `end_pickup_drop_off_window` estiverem definidos.</li><li>Opcional caso contrário.</li></ul> |



## O que esta validação faz 

No `stop_times.txt`, o campo `pickup_type` indica como se faz o embarque na paragem deste ponto da viagem: regular, impossível, por marcação com a operadora ou a combinar com o motorista. Os códigos admitidos estão na referência GTFS do campo.

Esta validação restringe `pickup_type` aos valores 0 a 3 quando o campo está preenchido; proíbe `pickup_type` igual a 0 ou 3 na mesma linha em que `start_pickup_drop_off_window` ou `end_pickup_drop_off_window` têm valor (modelo de janela horária incompatível com “embarque regular programado” ou com “combinação direta com o motorista”, nos termos desses códigos); pode obrigar ou recomendar o preenchimento quando `pickup_type` está vazio, consoante a severidade; pode proibir qualquer valor se o campo estiver interdito; e pode limitar quais códigos são aceites para além do conjunto GTFS.

---

### Passa

- `pickup_type` com valor 0, 1, 2 ou 3, sem janela de início/fim preenchida quando o código é 0 ou 3 (ou sem janelas na linha).
- `pickup_type` 1 ou 2 com janelas horárias preenchidas, ou 0/3 só quando não há janelas com valor.
- Campo vazio quando a ausência não gera mensagem para esta regra (por exemplo, severidade ignorar ou situação proibida que dispensa o aviso de campo vazio).
- Código incluído na lista de opções admitidas, quando essa lista existe.

---

### Falha

- Valor inválido: `pickup_type` fora de 0–3. _Correção:_ usar só códigos previstos na referência.
- Proibido com janelas: há `start_pickup_drop_off_window` ou `end_pickup_drop_off_window` com valor e `pickup_type` é 0 ou 3. _Correção:_ mudar para 1 ou 2, ou rever janelas / modelo de serviço.
- Fora da lista permitida: código válido no GTFS mas não admitido pela regra de opções. _Correção:_ escolher um código permitido.
- Campo proibido com valor. _Correção:_ esvaziar `pickup_type`.
- Ausência sinalizada como obrigatório ou recomendado. _Correção:_ preencher `pickup_type` ou rever a severidade.
