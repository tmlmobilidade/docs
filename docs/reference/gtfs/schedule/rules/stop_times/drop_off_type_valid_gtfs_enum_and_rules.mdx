## Regras de validação do campo drop_off_type


### Campos que serão validados nesta regra

| Nome do Campo                  | Tipo    | Presença                     | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------------------------ | ------- | ---------------------------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `drop_off_type`                | Enum    | Proibido Condicionalmente    | Indica o método de entrega.<br/><br/>**Opções válidas:**<ul><li>`0` ou `vazio` - Entrega agendada regularmente.</li><li>`1` - Sem entrega disponível.</li><li>`2` - É necessário ligar para a agência para agendar a entrega.</li><li>`3` - É necessário coordenar com o motorista para agendar a entrega.</li></ul>**Proibido Condicionalmente**:<ul><li>`0` **proibido** se `start_pickup_drop_off_window` ou `end_pickup_drop_off_window` estiverem definidos.</li><li>Opcional caso contrário.</li></ul>                                   |
| `start_pickup_drop_off_window` | Horário | Condicionalmente Obrigatório | Horário em que o serviço on-demand fica disponível num local GeoJSON, grupo de locais ou paragem. <br/><br/>**Condicionalmente Obrigatório**:<ul><li>Obrigatório se `stop_times.location_group_id` ou `stop_times.location_id` estiver definido.</li><li>Obrigatório se `stop_times.location_group_id` ou `stop_times.location_id` estiver definido.</li><li>Obrigatório se `end_pickup_drop_off_window` estiver definido.</li><li>Proibido se `arrival_time` ou `departure_time` estiver definido.</li><li>Opcional caso contrário.</li></ul> |
| `end_pickup_drop_off_window`   | Horário | Condicionalmente Obrigatório | Horário em que o serviço on-demand termina num local GeoJSON, grupo de locais ou paragem. <br/><br/>**Condicionalmente Obrigatório**:<ul><li>Obrigatório se `stop_times.location_group_id` ou `stop_times.location_id` estiver definido.</li><li>Obrigatório se `start_pickup_drop_off_window` estiver definido.</li><li>Proibido se `arrival_time` ou `departure_time` estiver definido.</li><li>Opcional caso contrário.</li></ul>                                                                                                           |




### O que esta validação faz 

No ficheiro `stop_times.txt`, o campo `drop_off_type` define como é feita a descida do veículo nessa paragem da viagem.

O GTFS admite apenas códigos válidos para esse enumerado e cruza o valor com o resto da linha: quando existem janelas de pickup/drop-off (`start_pickup_drop_off_window` e/ou `end_pickup_drop_off_window` com valor), não é permitido `drop_off_type` = 0 (descida regular num serviço programado à paragem), porque esse modelo colide com o uso de janelas em vez de tempos fixos de paragem para esse efeito.

---

### Passa

- O valor é um dos códigos permitidos pelo enumerado, ou o campo está vazio (se for aceitável para o conjunto de dados, nos termos da mesma referência).
- Com janelas preenchidas na mesma linha, o tipo de descida não é 0; deve corresponder ao modo real de descida através de outro código admissível, ou o modelo da linha (janelas _versus_ paragem fixa) deve ser revisto para ficar coerente.

---

### Falha

- Valor inválido — número fora do conjunto definido para este campo. Correção: usar apenas os valores previstos na referência GTFS para `drop_off_type`.
- Proibido com janelas — existem janelas de pickup/drop-off com valor e o tipo de descida é 0. Correção: escolher outro código válido, adequado ao serviço, ou ajustar as janelas e o modelo de publicação de forma a não combinar 0 com janelas.

--- 

Se utilizar janelas, é preferível preencher sempre explicitamente um tipo de descida adequado, em vez de depender do vazio (no GTFS, equivalente ao modo “regular”), para evitar ambiguidade neste contexto.
