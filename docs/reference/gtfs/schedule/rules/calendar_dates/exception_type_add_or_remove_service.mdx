| `exception_type` | Enum | Obrigatório | Indica se o serviço está disponível na data especificada no campo de data.<br/>**Opções válidas:**<ul><li>`1` - O serviço foi adicionado para a data especificada.</li><li>`2` - O serviço foi removido para a data especificada.</li></ul>**Exemplo:** Suponha que uma rota tem um conjunto de viagens disponíveis em dias feriados e outro conjunto de viagens disponíveis em todos os outros dias. Para um feriado específico, o ficheiro `calendar_dates.txt` pode ser utilizado para adicionar o feriado ao `service_id` de feriado e para remover o feriado do horário de funcionamento regular. |
