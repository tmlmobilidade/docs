## Campos que serão validados nesta regra

| Nome do Campo        | Tipo | Presença    | Descrição                                                                                                               |
| -------------------- | ---- | ----------- | ----------------------------------------------------------------------------------------------------------------------- |
| `feed_publisher_url` | URL  | Obrigatório | URL do site da organização que publica o conjunto de dados. Pode ser o mesmo que um dos valores de `agency.agency_url`. |




## O que esta validação faz 

O campo `feed_publisher_url` exige o URL do Web site da organização que publica o conjunto de dados. Esta verificação garante que o endereço está preenchido e que tem forma de URL aceite pelas regras da aplicação.

---

### Passa

- O URL do publicador está definido e passa na validação de formato.

---

### Falha

- O campo está em falta ou está em branco.
- O texto não é um URL aceite pelo formato verificado.
