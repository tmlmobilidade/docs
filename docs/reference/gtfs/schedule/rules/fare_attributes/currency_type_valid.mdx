## Campos que serão validados nesta regra

| Nome do Campo   | Tipo            | Presença    | Descrição                            |
| --------------- | --------------- | ----------- | ------------------------------------ |
| `currency_type` | Código da moeda | Obrigatório | Moeda utilizada para pagar a tarifa. |




## O que esta validação faz 

No ficheiro `fare_attributes`, o campo `currency_type` indica em que moeda a tarifa é apresentada ou paga. É obrigatório e tem de corresponder a um código de três letras admitido pela aplicação, no mesmo género dos códigos de moeda normalizados (como os ISO 4217). Letras maiúsculas ou minúsculas no ficheiro tratam-se como equivalentes na verificação.

---

### Passa

- O código está preenchido e figura na lista de moedas válidas da aplicação.

---

### Falha

- O campo está em falta.
- O texto não é um código de moeda reconhecido (três letras permitidas na lista interna).
