## Campos que serão validados nesta regra

| Nome do Campo | Tipo | Presença    | Descrição                                                                                                                                                                                                                                                                                                                                                                                                                      |
| ------------- | ---- | ----------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `emission`    | Enum | obrigatório | Classe de emissões.<br/><br/>**Opções válidas:**<ul><li>`0` - Sem classificação de emissões (exceção).</li><li>`1` - EURO I.</li><li>`2` - EURO II.</li><li>`3` - EURO III.</li><li>`4` - EURO IV.</li><li>`5` - EURO V.</li><li>`6` - EURO VI.</li><li>`6` - EURO VI.</li></ul><br/>Este campo indica a norma de emissões do veículo. O valor **0** é usado em casos excecionais para veículos sem classificação de emissões. |



## O que esta validação faz 

No ficheiro `vehicles.txt`, o campo `emission` identifica a classe de emissões do veículo (poluentes), normalmente alinhada com a norma Euro ou outro esquema numérico definido no vosso dicionário de dados. Os valores válidos são códigos inteiros que mapeiam para estes níveis (no esquema habitual, por exemplo de Euro I a Euro VI, ƒ podem existir códigos extra para “sem classificação”, “não aplicável” ou extensões do feed, conforme a documentação interna).

---

### Passa

- Campo preenchido, código reconhecido no conjunto permitido pelo validador e, havendo lista restritiva nas regras, valor autorizado (ou regras que abrangem todas as opções válidas).

---

### Falha

- Campo em falta – não se indica a classe de emissão do veículo.
- Código inválido – o número não corresponde a nenhuma classe de emissão admitida (fora do domínio previsto).
- Incoerência com as regras  – o código é válido no dicionário geral mas não é permitido pela lista das regras, quando essa restrição está activa.
