| GTFS v30 (GO)                                                                    | Ficheiro obrigatório |

## Chave Primária

Este ficheiro não tem chave primária.

## Estrutura

| Coluna                |       Tipo       | GTFS Standard |     GTFS v30    | Descrição                                                                                                                                                                                                          |
| --------------------- | :--------------: | :-----------: | :-------------: | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `feed_start_date`     |       Data       |  Recomendado  | **Obrigatório** | Data a partir da qual o conteúdo do GTFS é válido, mesmo que o arquivo contenha datas anteriores na informação de calendários. Data inclusiva, ou seja, no dia indicado o conteúdo já deve ser considerado válido. |
| `feed_end_date`       |       Data       |  Recomendado  | **Obrigatório** | Data de fim de validade do conteúdo do GTFS, mesmo que o arquivo contenha datas posteriores na informação de calendários. Data inclusiva, ou seja, no dia indicado o conteúdo ainda é válido.                      |
| `feed_version`        |       Texto      |  Obrigatório  |     Opcional    | Identificador da versão do GTFS. Formato ao critério do operador mas recomendamos uma data ou um número incremental.                                                                                               |
| `feed_publisher_name` |       Texto      |  Obrigatório  |     Opcional    | Nome da organização que disponibiliza o GTFS.                                                                                                                                                                      |
| `feed_publisher_url`  |        URL       |  Obrigatório  |     Opcional    | URL do website da organização que disponibiliza o GTFS.                                                                                                                                                            |
| `feed_lang`           | Código de idioma |  Obrigatório  |     Opcional    | Idioma que deve ser utilizado para apresentar o conteúdo do GTFS, de acordo com a [base de dados da IANA](https://www.w3.org/International/articles/language-tags).                                                |
| `default_lang`        | Código de idioma |  Obrigatório  |     Opcional    | Define o idioma, de acordo com a [base de dados da IANA](https://www.w3.org/International/articles/language-tags), que deve ser utilizado quando o consumidor de dados não conhece o idioma do passageiro.         |
| `feed_contact_email`  |       Email      |    Opcional   |     Opcional    | Endereço de email que deve ser utilizado para comunicações referentes ao GTFS em si.                                                                                                                               |
| `feed_contact_url`    |        URL       |    Opcional   |     Opcional    | Website que deve ser utilizado para comunicações referentes ao GTFS em si.                                                                                                                                         |
