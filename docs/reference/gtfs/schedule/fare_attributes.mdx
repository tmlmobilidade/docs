---
title: fare_attributes
description: Identificação de tarifários
---
**Presença:** Opcional<br/>
**Chave primária:** `fare_id`
### Campos GTFS Standard

| Nome do Campo       | Tipo                                             | Presença                     | Descrição                                                                                                                                                                                                                                                                                                                                 |
| ------------------- | ------------------------------------------------ | ---------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `fare_id`           | ID único                                         | Obrigatório                  | Identifica uma classe tarifária.                                                                                                                                                                                                                                                                                                          |
| `price`             | Número decimal não negativo                      | Obrigatório                  | Preço da tarifa, na unidade especificada por `currency_type`.                                                                                                                                                                                                                                                                             |
| `currency_type`     | Código da moeda                                  | Obrigatório                  | Moeda utilizada para pagar a tarifa.                                                                                                                                                                                                                                                                                                      |
| `payment_method`    | Enum                                             | Obrigatório                  | Indica quando a tarifa deve ser paga. <br/>Opções válidas:<ul><li>`0` - Tarifa paga a bordo.</li><li>`1` - Tarifa deve ser paga antes do embarque.</li></ul>                                                                                                                                                                               |
| `transfers`         | Enum                                             | Obrigatório                  | Indica o número de transferências permitidas nesta tarifa. <br/>Opções válidas:<ul><li>`0` - Nenhuma transferência permitida nesta tarifa.</li><li>`1` - Os passageiros podem fazer uma transferência.</li><li>`2` - Os passageiros podem fazer duas transferências.</li><li>`empty` - São permitidas transferências ilimitadas.</li></ul> |
| `agency_id`         | ID estrangeiro que referencia `agency.agency_id` | Condicionalmente obrigatório | Identifica a agência relevante para uma tarifa. <br/><br/>**Condicionalmente obrigatório**:<ul><li>Obrigatório se várias agências estiverem definidas em `agency.txt`.</li><li>Recomendado caso contrário.</li></ul>                                                                                                                        |
| `transfer_duration` | Número inteiro não negativo                      | Opcional                     | Tempo em segundos antes do fim de uma transferência. <br/>Quando `transfers=0`, este campo pode ser utilizado para indicar a validade de um bilhete ou pode ser deixado em branco.                                                                                                                                                         |
