## Exemplo de ficheiro GTFS

Aqui está um ficheiro GTFS simples para a Linha Amarela do Metro de Lisboa. Para manter a clareza e evitar complexidade desnecessária, incluímos apenas as colunas necessárias e 4 horários.

Pode utilizar este ficheiro para explorar as relações entre os ficheiros e compreender a lógica subjacente dos ficheiros GTFS.

Isto irá ajudá-lo a familiarizar-se com a interação entre os vários ficheiros, como paragens, viagens e horários, e como trabalham em conjunto para formar um feed de transporte completo.

Ao examinar este ficheiro, obterá uma compreensão mais clara da estrutura de dados e da sua utilização prática em aplicações do mundo real.

## Como posso abrir/ler um GTFS?

Pode descompactar o ficheiro e abrir cada ficheiro em ferramentas como o Microsoft Excel ou o Google Sheets. No entanto, alguns destes ficheiros podem ser demasiado grandes, o que pode exceder os limites destes programas.

Nestes casos, é melhor utilizar ferramentas automatizadas concebidas para lidar com dados GTFS. Embora os ficheiros GTFS sejam legíveis por humanos, destinam-se ao processamento por sistemas automatizados para gerir e manipular eficientemente os dados neles armazenados.
