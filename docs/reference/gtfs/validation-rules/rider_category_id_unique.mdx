---
title: Identificador único da categoria de passageiro
description: Verifica se cada rider_category_id de rider_categories.txt está preenchido e não se repete no ficheiro.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `rider_category_id_unique` |
| Ficheiro | `rider_categories.txt` |
| Campo | `rider_category_id` |
| Tipo | ID único |
| Severidade | Obrigatório |

**Descrição do campo:** identifica uma categoria de passageiro.

Mais informação em [rider_categories.txt](/reference/gtfs/schedule/rider_categories).

## Como funciona

Quando a regra passa, cada categoria de passageiro tem um `rider_category_id` próprio, que não aparece noutra linha do ficheiro. A regra **não verifica o formato do identificador** nem se outros ficheiros o utilizam.

A regra avalia cada linha do `rider_categories.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O mesmo `rider_category_id` aparece em mais de uma linha do ficheiro? | ❌ Reporta o problema: identificador duplicado | ✅ Passa |

O problema é reportado em todas as linhas que repetem o identificador.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `adulto` (só numa linha) | ✅ Passa | Identificador único |
| `adulto` (em duas linhas) | ❌ Problema | Identificador repetido |
| (vazio) | ❌ Problema | Campo obrigatório sem valor |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Identificador duplicado | Duas ou mais categorias têm o mesmo `rider_category_id` | Atribuir um `rider_category_id` diferente a cada categoria em `rider_categories.txt` |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `rider_category_id` em `rider_categories.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `rider_category_id` em `rider_categories.txt` |
