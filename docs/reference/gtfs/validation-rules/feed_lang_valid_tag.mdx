title: Idioma principal do conjunto
description: Verifica se o idioma principal usa um código de duas letras reconhecido pelo validador.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_lang_valid_tag` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_lang` |
| Tipo | Código de idioma |
| Severidade | Opcional |

**Descrição do campo:** idioma predefinido do texto no conjunto. Ajuda as aplicações a escolher regras de maiúsculas e outras definições linguísticas. Para conteúdo original em vários idiomas, a especificação GTFS prevê `mul` e traduções em `translations.txt`.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Quando a regra passa, `feed_lang` respeita a configuração e coincide com um código ISO 639-1 de duas letras. A comparação não distingue maiúsculas de minúsculas. A regra **não aceita etiquetas regionais como `pt-PT` nem o código multilingue `mul`, apesar da descrição GTFS do campo**.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor, convertido para minúsculas, consta da lista ISO 639-1 de duas letras? | ✅ Passa | ❌ Reporta o problema: idioma inválido |

Os espaços não são removidos. Apenas a diferença entre maiúsculas e minúsculas é ignorada. Uma linha com todos os campos vazios é ignorada antes desta regra.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `pt` | ✅ Passa | Código de duas letras reconhecido |
| `PT` | ✅ Passa | Maiúsculas não obrigatórias |
| `mul` | ❌ Problema | Código de três letras não aceite |
| `pt` quando o campo é proibido | ❌ Problema | Campo preenchido indevidamente |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Código de idioma inválido | O valor não é um código ISO 639-1 de duas letras; etiquetas como `pt-PT` e `mul` não são aceites | Corrigir `feed_lang` em `feed_info.txt` para um código de duas letras reconhecido, por exemplo `pt` |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `feed_lang` em `feed_info.txt` com um código de idioma reconhecido |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `feed_lang` em `feed_info.txt` |
