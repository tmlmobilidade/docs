---
title: Nome do operador
description: Verifica se o nome do operador está preenchido e, quando configurado, consta da lista de nomes permitidos.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_name_present` |
| Ficheiro | `agency.txt` |
| Campo | `agency_name` |
| Tipo | Texto |
| Severidade | Obrigatório |

**Descrição do campo:** nome completo do operador de transporte.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

Quando a regra passa, o nome está presente quando exigido e respeita a lista configurada. A regra **não verifica a redação do nome nem remove espaços**.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | A configuração da regra tem uma lista de nomes permitidos? | Segue para o passo 4 | ✅ Passa |
| 4 | O nome está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: nome não permitido |

O valor é comparado tal como foi escrito. Um texto composto apenas por espaços não é tratado como vazio.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `Carris Metropolitana` | ✅ Passa | Nome presente |
| campo vazio | ❌ Problema | Falta um valor obrigatório |
| `Outro Operador` (lista permitida = `Carris Metropolitana`) | ❌ Problema | Fora da lista |
| `Carris Metropolitana` quando o campo é proibido | ❌ Problema | Campo preenchido indevidamente |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Nome não permitido | O nome não consta da lista configurada | Substituir `agency_name` em `agency.txt` por um nome permitido ou rever a lista na configuração da regra |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `agency_name` em `agency.txt` com o nome completo do operador |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `agency_name` em `agency.txt` |
