## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_lang_valid` |
| Ficheiro | `agency.txt` |
| Campo | `agency_lang` |
| Tipo | Código de idioma |
| Severidade | Opcional |

**Descrição do campo:** idioma principal utilizado pelo operador, que ajuda a apresentar os dados segundo as convenções desse idioma.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

O valor preenchido de `agency_lang` tem de cumprir o formato verificado por esta regra. A regra não verifica se os textos estão escritos nesse idioma nem aplica uma lista adicional da configuração da regra.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | A configuração da regra está desativada? | A verificação não é executada | Segue para o passo 2 |
| 2 | O campo está vazio? | Não reporta a ausência nesta regra | Segue para o passo 3 |
| 3 | O código consta da lista de idiomas reconhecidos? | ✅ Passa | ❌ Reporta o problema: formato inválido |

A comparação não distingue maiúsculas de minúsculas. Os espaços no início e no fim não são removidos.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `pt` | ✅ Passa | Idioma reconhecido |
| `not-a-language` | ❌ Problema | Código desconhecido |
| `pt-PT` | ❌ Problema | Código regional fora da lista |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Formato inválido | O valor não cumpre o formato verificado | Usar um código de idioma reconhecido em `agency_lang` em `agency.txt`. |
