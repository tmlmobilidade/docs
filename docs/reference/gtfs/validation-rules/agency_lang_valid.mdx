## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_lang_valid` |
| Ficheiro | `agency.txt` |
| Campo | `agency_lang` |
| Tipo | Código de idioma |
| Severidade | Opcional |

**Descrição do campo:** idioma principal do operador, que permite aplicar regras de apresentação específicas desse idioma.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

Um código preenchido tem de constar da lista de idiomas reconhecidos pelo validador. A regra não confirma o idioma dos textos nem aplica listas adicionais da configuração da regra.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | A configuração da regra manda ignorar esta verificação? | A verificação não é executada | Segue para o passo 2 |
| 2 | O campo está vazio? | Não reporta a ausência nesta regra | Segue para o passo 3 |
| 3 | O código consta da lista de idiomas reconhecidos? | ✅ Passa | ❌ Reporta o problema: código de idioma inválido |

A comparação não distingue maiúsculas de minúsculas. Os espaços no início e no fim não são removidos.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `pt` | ✅ Passa | Idioma reconhecido |
| `PT` | ✅ Passa | Maiúsculas aceites |
| `pt-PT` | ❌ Problema | Código regional fora da lista |
| `not-a-language` | ❌ Problema | Código desconhecido |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Código de idioma inválido | O código não consta da lista de idiomas reconhecidos | Usar um código reconhecido em `agency_lang` de `agency.txt`, por exemplo `pt`. |
