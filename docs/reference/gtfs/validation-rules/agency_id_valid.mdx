## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_id_valid` |
| Ficheiro | `agency.txt` |
| Campo | `agency_id` |
| Tipo | Identificador único |
| Severidade | Obrigatório |

**Descrição do campo:** identifica o operador ou a marca de transporte a que os dados pertencem.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

O texto preenchido de `agency_id` tem de constar da lista definida na configuração da regra, quando essa lista existe. A regra não verifica o formato nem a existência de referências.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | A configuração da regra está desativada? | A verificação não é executada | Segue para o passo 2 |
| 2 | O campo está vazio? | Não reporta a ausência nesta regra | Segue para o passo 3 |
| 3 | A configuração da regra omite a lista de valores permitidos? | ✅ Passa | Segue para o passo 4 |
| 4 | A lista aceita qualquer valor, através de `all_options`? | ✅ Passa | Segue para o passo 5 |
| 5 | O texto consta exatamente da lista? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

A comparação utiliza o texto original, incluindo espaços e maiúsculas. Uma lista vazia rejeita todos os valores preenchidos.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `A1`; lista: `A1` | ✅ Passa | Valor incluído |
| `A1`; lista: `OUTRO` | ❌ Problema | Valor fora da lista |
| `A1`; lista vazia | ❌ Problema | Nenhum valor permitido |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor não permitido | O texto não consta da lista definida na configuração da regra | Usar um valor permitido em `agency_id` em `agency.txt`. |
