## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_id_valid` |
| Ficheiro | `agency.txt` |
| Campo | `agency_id` |
| Tipo | Identificador único |
| Severidade | Condicional (obrigatório quando existem vários operadores; recomendado nos restantes casos) |

**Descrição do campo:** identifica o operador ou a marca de transporte representados na linha. O ficheiro pode incluir vários operadores.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

Um valor preenchido tem de constar da lista definida na configuração da regra, quando essa lista existe. A regra não verifica o formato nem exige o preenchimento.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | A configuração da regra manda ignorar esta verificação? | A verificação não é executada | Segue para o passo 2 |
| 2 | O campo está vazio? | Não reporta a ausência nesta regra | Segue para o passo 3 |
| 3 | A configuração da regra define uma lista de valores permitidos? | Segue para o passo 4 | ✅ Passa |
| 4 | A lista aceita qualquer valor? | ✅ Passa | Segue para o passo 5 |
| 5 | O texto consta exatamente da lista? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

A comparação utiliza o texto original, incluindo espaços e maiúsculas. Uma lista definida mas vazia rejeita todos os valores preenchidos.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `A1`; lista: `A1` | ✅ Passa | Valor incluído na lista |
| `A2`; lista: `A1` | ❌ Problema | Valor fora da lista |
| `A1`; lista vazia | ❌ Problema | Nenhum valor permitido |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor não permitido | O texto não consta da lista da configuração da regra | Usar em `agency_id` de `agency.txt` um valor permitido pela configuração da regra. |
