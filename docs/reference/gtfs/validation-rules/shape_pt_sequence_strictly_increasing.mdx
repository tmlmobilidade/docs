## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `shape_pt_sequence_strictly_increasing` |
| Ficheiro | `shapes.txt` |
| Campos | `shape_id`, `shape_pt_sequence` |
| Tipo | Identificador, Inteiro não negativo |
| Severidade | Obrigatório |

**Descrição dos campos:**

- `shape_id`: identifica o traçado.
- `shape_pt_sequence`: ordem pela qual os pontos se ligam para formar o traçado. Os valores devem aumentar, mas não precisam de ser consecutivos.

Mais informação em [shapes.txt](/reference/gtfs/schedule/shapes).

## Como funciona

A regra ordena numericamente os pontos e assinala sequências repetidas no mesmo traçado. Não exige linhas ordenadas no ficheiro nem números consecutivos.

A regra avalia cada grupo de pontos com o mesmo `shape_id` em `shapes.txt`, seguindo os passos abaixo por ordem.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | A sequência pode ser lida como inteiro em todos os pontos? | Segue para o passo 2 | Interrompe a comparação; corrigir primeiro o formato |
| 2 | Após ordenar, o número atual é maior que o anterior? | ✅ Passa este par | ❌ Reprova: sequência repetida |

Os espaços não são removidos. `01` e `1` representam a mesma sequência. Um único ponto não produz comparação. Esta regra não rejeita, por si só, sequências negativas distintas.

O resultado segue a configuração da regra: obrigatório reprova; recomendado passa com aviso; informativo passa com informação. O aviso antecipa uma futura exigência, mas só reprova quando a configuração passar a obrigatório. Salvo indicação contrária, os exemplos de reprovação pressupõem a configuração obrigatória.

## Como se relacionam

O campo `shape_id` agrupa os pontos. O campo `shape_pt_sequence` define a ordem das comparações.

## Exemplos

| shape_id | shape_pt_sequence | Resultado | Porquê |
|---|---|---|---|
| `A` | `20, 0, 10` (ordem no ficheiro) | ✅ Passa | Valores distintos após ordenar |
| `A` | `0, 10, 10` | ❌ Reprova | Sequência repetida |
| `A` | `0, 0` | ❌ Reprova | Zero repetido |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Sequência repetida | Dois pontos do mesmo traçado usam o mesmo número | Atribuir valores distintos a `shape_pt_sequence` em `shapes.txt`, respeitando o percurso dos pontos de cada `shape_id`. |
