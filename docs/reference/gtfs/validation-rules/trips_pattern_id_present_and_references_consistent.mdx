## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_pattern_id_present_and_references_consistent` |
| Ficheiro | `trips.txt` |
| Campo | `pattern_id` |
| Tipo | Identificador |
| Severidade | Obrigatório |

**Descrição do campo:** identifica o padrão a que pertence a viagem. Um padrão representa o desenvolvimento de uma linha num sentido.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

O campo tem de estar preenchido, salvo quando a configuração desativa a regra. Apesar do nome, esta validação não verifica referências nem consistência entre viagens; essas verificações pertencem a regras agrupadas.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda o campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra proíbe o campo? | ❌ Reporta o problema | ✅ Passa |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `1001_0_1` | ✅ Passa | Campo preenchido |
| Vazio | ❌ Problema | Campo obrigatório |
| `1001_0_1` (campo proibido) | ❌ Problema | A configuração proíbe o campo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda `pattern_id` | Preencher `pattern_id` em `trips.txt` |
| Campo preenchido quando não devia | A configuração da regra proíbe `pattern_id` | Remover `pattern_id` de `trips.txt` |
