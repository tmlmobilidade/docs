## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `fare_media_type_valid` |
| Ficheiro | `fare_media.txt` |
| Campo | `fare_media_type` |
| Tipo | Enumeração |
| Severidade | Obrigatório |

**Descrição do campo:** indica o tipo de suporte tarifário. O valor `0` representa a ausência de suporte, como um pagamento em numerário sem título físico. O valor `1` representa um título físico em papel. O valor `2` representa um cartão de transporte físico. O valor `3` representa um cartão bancário sem contacto cEMV usado na bilhética baseada em conta. O valor `4` representa uma aplicação móvel.

Mais informação em [fare_media.txt](/reference/gtfs/schedule/fare_media).

## Como funciona

Quando a regra passa, `fare_media_type` está presente quando exigido e tem um valor entre `0` e `4`. Se a configuração da regra limitar os tipos permitidos, o valor também pertence a essa lista. A regra **não verifica se o nome ou os produtos associados são adequados ao tipo**.

A regra avalia cada linha do `fare_media.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é `0`, `1`, `2`, `3` ou `4`? | Segue para o passo 4 | ❌ Reporta o problema: tipo inválido |
| 4 | A configuração da regra tem uma lista de tipos permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor está na lista, ou a lista aceita todos os valores? | ✅ Passa | ❌ Reporta o problema: tipo não permitido |

O valor é interpretado como número inteiro antes desta regra. Os espaços não são removidos antes dessa interpretação. Se o texto não puder ser interpretado como inteiro, a leitura reporta outro problema antes desta regra.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `2` | ✅ Passa | Cartão de transporte físico |
| `5` | ❌ Problema | Valor não previsto pelo GTFS |
| `4` com lista permitida `0`, `2` | ❌ Problema | Valor fora da lista |
| campo vazio | ❌ Problema | Falta um valor obrigatório |
| `2` quando o campo é proibido | ❌ Problema | Campo preenchido indevidamente |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Tipo inválido | O valor é diferente de `0`, `1`, `2`, `3` e `4` | Alterar `fare_media_type` em `fare_media.txt` para um valor entre `0` e `4` |
| Tipo não permitido | O valor é válido no GTFS, mas não consta da lista definida na configuração da regra | Alterar `fare_media_type` em `fare_media.txt` para um valor permitido ou rever a lista da configuração |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `fare_media_type` em `fare_media.txt` com um valor entre `0` e `4` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `fare_media_type` em `fare_media.txt` |
