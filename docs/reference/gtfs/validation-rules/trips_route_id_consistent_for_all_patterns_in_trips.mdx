---
title: Linha consistente no padrão
description: Verifica se todas as viagens do mesmo `pattern_id` usam um único `route_id`.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_route_id_consistent_for_all_patterns_in_trips` |
| Ficheiro | `trips.txt` |
| Campos | `pattern_id`, `route_id` |
| Tipo | Identificador |
| Severidade | Opcional |

**Descrição dos campos:**

- `pattern_id`: identifica o padrão que agrupa as viagens.
- `route_id`: identifica a linha da viagem.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Todas as viagens do mesmo padrão têm de usar o mesmo `route_id`. Valores vazios de `route_id` são ignorados. A regra não valida o formato nem a referência do valor.

A regra avalia cada grupo de viagens com o mesmo `pattern_id`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | Recolhe mais de um valor distinto de `route_id` no grupo? | Segue para o passo 2 | ✅ Passa |
| 2 | A configuração da regra desativa a validação? | ✅ Passa | ❌ Reporta o problema na primeira viagem do padrão |

## Como se relacionam

`pattern_id` define o grupo. `route_id` tem de ser consistente dentro desse grupo.

## Exemplos

| Valores no padrão | Resultado | Porquê |
|---|---|---|
| `R1, R1` | ✅ Passa | Uma única linha |
| `R1, R2` | ❌ Problema | Duas linhas distintas |
| `R1, vazio` | ✅ Passa | O vazio é ignorado |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valores diferentes no mesmo padrão | Viagens com o mesmo `pattern_id` usam vários valores de `route_id` | Corrigir `route_id` ou `pattern_id` nas linhas afetadas de `trips.txt` |
