`agency_email_valid_address`

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_email_valid_address` |
| Ficheiro | `agency.txt` |
| Campo | `agency_email` |
| Tipo | E-mail |
| Presença no GTFS | Opcional |

**Descrição do campo (GTFS):** endereço de e-mail monitorizado ativamente pelo departamento de apoio ao cliente do operador. Deve ser um ponto de contacto direto onde os passageiros podem falar com um representante do apoio ao cliente.

## Em resumo

Se o operador indicar um e-mail de apoio ao cliente, o valor tem de ser um endereço bem escrito. Se a configuração da sua agência tiver uma lista de e-mails permitidos, o endereço também tem de constar dessa lista. A regra **não confirma que a caixa de correio existe**, só que o formato está correto.

## Como funciona

A regra avalia cada linha do `agency.txt` e para no primeiro passo que decide o resultado.

| #   | Pergunta                                                          | Se sim                                                                                              | Se não                                     |
| --- | ----------------------------------------------------------------- | --------------------------------------------------------------------------------------------------- | ------------------------------------------ |
| 1   | O campo está vazio?                                               | Verifica se a sua agência exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2                       |
| 2   | A sua agência definiu que este campo **não deve ser preenchido**? | Reporta o problema                                                                                  | Segue para o passo 3                       |
| 3   | O texto é um endereço de e-mail válido?                           | Segue para o passo 4                                                                                | Reporta o problema: formato inválido       |
| 4   | A sua agência definiu uma lista de e-mails permitidos?            | Segue para o passo 5                                                                                | Passa                                      |
| 5   | O endereço está na lista? (ou a lista aceita qualquer valor)      | Passa                                                                                               | Reporta o problema: endereço não permitido |

Os espaços no início e no fim são ignorados.

## Exemplos

| Valor                                                    | Resultado | Porquê                            |
| -------------------------------------------------------- | --------- | --------------------------------- |
| `apoio@operador.pt`                                      | Passa     | Formato correto                   |
| `apoio-operador.pt`                                      | Problema  | Falta a `@`                       |
| `apoio@`                                                 | Problema  | Falta o domínio                   |
| `geral@outro.pt` (lista permitida = `apoio@operador.pt`) | Problema  | Formato válido, mas fora da lista |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Formato inválido | Erro de digitação, `@` em falta ou espaço no meio | Escrever o endereço completo, por exemplo `apoio@operador.pt` |
| Endereço não permitido | O e-mail é válido mas não está na lista da sua agência | Usar um e-mail da lista, ou pedir ao administrador que o adicione |
| Campo em falta | A sua agência exige ou recomenda este campo | Preencher com o e-mail de apoio ao cliente |
| Campo preenchido quando não devia | A sua agência definiu que este campo não deve ter valor | Remover o valor de `agency_email` |

## Nível do problema (severidade)

Cada agência define o nível com que esta regra reporta os problemas (por exemplo, erro ou aviso). Por isso o mesmo e-mail pode aparecer como erro numa agência e como aviso noutra.

Para saber o nível que se aplica à sua agência, consulte o relatório de validação, onde cada problema mostra o seu nível.

Especificação: [GTFS `agency.txt`](https://gtfs.org/schedule/reference/#agencytxt)
