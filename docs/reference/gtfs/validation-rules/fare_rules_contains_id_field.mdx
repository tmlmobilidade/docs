## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `fare_rules_contains_id_field` |
| Ficheiro | `fare_rules.txt` |
| Campo | `contains_id` |
| Tipo | Referência a `stops.zone_id` |
| Severidade | Opcional |

**Descrição do campo:** identifica uma zona que o percurso deve atravessar para a tarifa se aplicar.

Mais informação em [fare_rules.txt](/reference/gtfs/schedule/fare_rules).

## Como funciona

A regra assinala a ausência de `contains_id` segundo a configuração da regra. Um valor preenchido passa nesta verificação; o formato e as referências são avaliados por outras regras.

A regra avalia cada linha do `fare_rules.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | A configuração da regra está desativada? | A verificação não é executada | Segue para o passo 2 |
| 2 | O campo está preenchido? | ✅ Passa | Segue para o passo 3 |
| 3 | A configuração da regra exige o preenchimento? | ❌ Reporta o problema: campo obrigatório | Reporta a ausência como recomendação ou informação, segundo a configuração da regra |

O campo só é considerado vazio quando não contém texto. Os espaços, por si só, contam como preenchimento.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `A1` | ✅ Passa | Campo preenchido |
| Vazio; configuração da regra exige o campo | ❌ Problema | Preenchimento obrigatório |
| Vazio; configuração da regra recomenda o campo | ❌ Problema | Preenchimento recomendado |
| Vazio; configuração da regra é informativa | ❌ Problema | Ausência comunicada como informação |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo obrigatório em falta | A configuração da regra exige o preenchimento | Preencher `contains_id` em `fare_rules.txt`. |
| Campo recomendado em falta | A configuração da regra recomenda o preenchimento | Preencher `contains_id` em `fare_rules.txt`. |
| Campo informativo em falta | A configuração da regra comunica a ausência | Preencher `contains_id` em `fare_rules.txt`, se a informação estiver disponível. |
