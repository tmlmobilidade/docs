## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_direction_id_valid_enum` |
| Ficheiro | `trips.txt` |
| Campo | `direction_id` |
| Tipo | Enumeração |
| Severidade | Obrigatório |

**Descrição do campo:** indica um dos dois sentidos da viagem. O valor separa viagens por sentido, mas não deve ser usado no cálculo de percursos.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

O campo tem de estar preenchido com `0` ou `1`, salvo quando a configuração desativa a regra. Uma lista configurada pode restringir estes dois valores. A regra não atribui significado geográfico fixo a cada número.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda o campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra proíbe o campo? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é `0` ou `1`? | Segue para o passo 4 | ❌ Reporta o problema: valor inválido |
| 4 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor consta da lista, ou a lista aceita qualquer valor? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `0` | ✅ Passa | Valor previsto |
| Vazio | ❌ Problema | Campo obrigatório |
| `2` | ❌ Problema | Fora da enumeração |
| `0` (lista permitida = `1`) | ❌ Problema | Fora da lista configurada |


## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda `direction_id` | Preencher `direction_id` em `trips.txt` |
| Campo preenchido quando não devia | A configuração da regra proíbe `direction_id` | Remover `direction_id` de `trips.txt` |
| Valor inválido | O valor não é `0` ou `1` | Corrigir `direction_id` em `trips.txt` |
| Valor não permitido | O valor não consta da lista configurada | Usar um valor permitido em `direction_id` de `trips.txt`, ou ajustar a configuração da regra |
