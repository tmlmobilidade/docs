## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_info_feed_end_date_format` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_end_date` |
| Tipo | Data |
| Severidade | Opcional (recomendado) |

**Descrição do campo:** último dia do período em que o conjunto de dados fornece horários completos e fiáveis, incluindo esse dia. Quando ambas são indicadas, esta data não deve anteceder `feed_start_date`.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

O resultado depende da severidade definida na configuração da regra: obrigatório (`error`) reprova; recomendado (`warning`) passa com aviso; informativo (`info`) passa com informação. O aviso antecipa uma futura exigência, mas só reprova quando a configuração passar a obrigatório. Nos casos sem severidade explícita abaixo, a indicação de reprovação pressupõe a configuração obrigatória.

Quando esta regra é executada, o campo tem de conter uma data existente no formato `AAAAMMDD`. A regra não compara as datas inicial e final nem verifica os horários publicados.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O valor tem oito algarismos e representa uma data existente? | ✅ Passa | Segue para o passo 2 |
| 2 | A configuração da regra ignora esta verificação? | Termina sem reportar problemas | Reporta o problema de formato, de acordo com a configuração da regra |

Os espaços não são removidos. A regra considera os dias de cada mês e os anos bissextos. O valor vazio também é rejeitado quando a regra é executada. Os exemplos pressupõem que a regra é executada e que a configuração da regra permite reportar problemas.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `20240229` | ✅ Passa | Data existente num ano bissexto |
| `20250229` | ❌ Reprova | Dia inexistente nesse ano |
| `2026-01-01` | ❌ Reprova | Separadores não aceites |
| `20261301` | ❌ Reprova | Mês inexistente |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Data inválida | A configuração exige o formato e o valor não o cumpre | Corrigir `feed_end_date` em `feed_info.txt` para uma data existente com oito algarismos, como `20260101`. |
| Data válida recomendada | A configuração recomenda o formato e o valor não o cumpre | Corrigir `feed_end_date` em `feed_info.txt` para uma data existente com oito algarismos, como `20260101`. |
| Data válida esperada | A configuração informativa ou de campo proibido assinala um valor que não cumpre o formato | Corrigir `feed_end_date` em `feed_info.txt` para uma data existente com oito algarismos, como `20260101`. |
