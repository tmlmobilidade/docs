---
title: Nome curto da linha
description: Verifica se o line_short_name está preenchido sempre que a rota tem line_id e se é igual ao route_short_name.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `routes_line_short_name_present_when_line_id_present` |
| Ficheiro | `routes.txt` |
| Campo | `line_short_name` |
| Tipo | Texto |
| Severidade | Condicional (obrigatório quando existe `line_id`) |

**Descrição do campo:** nome curto da linha a que a rota pertence.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Quando a regra passa, as rotas com `line_id` têm `line_short_name` igual ao `route_short_name`. Nas rotas sem `line_id`, a regra não avalia nada.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `line_id` está vazio? | ✅ Passa (a regra não se aplica) | Segue para o passo 2 |
| 2 | O `line_short_name` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 3 |
| 3 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 4 |
| 4 | A rota tem `route_short_name` e este é diferente do `line_short_name`? | ❌ Reporta o problema: valores diferentes | ✅ Passa |

## Como se relacionam

A regra só se aplica quando `line_id` está preenchido. Nesse caso, `line_short_name` tem de existir e ser igual a `route_short_name`.

## Exemplos

| line_id | line_short_name | route_short_name | Resultado | Porquê |
|---|---|---|---|---|
| `1001` | `1001` | `1001` | ✅ Passa | Valores iguais |
| (vazio) | (vazio) | `1001` | ✅ Passa | Sem `line_id`, a regra não se aplica |
| `1001` | `1002` | `1001` | ❌ Problema | Difere de `route_short_name` |
| `1001` | (vazio) | `1001` | ❌ Problema | Falta `line_short_name` |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| `line_short_name` diferente de `route_short_name` | Os dois campos foram preenchidos com valores diferentes | Corrigir `line_short_name` ou `route_short_name` em `routes.txt` para ficarem iguais |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `line_short_name` em `routes.txt` com o nome curto da linha |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `line_short_name` em `routes.txt` |
