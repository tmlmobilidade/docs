title: Distância percorrida não negativa
description: Verifica se shape_dist_traveled está preenchido e não é negativo.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `shape_dist_traveled_non_negative_monotonic` |
| Ficheiro | `shapes.txt` |
| Campo | `shape_dist_traveled` |
| Tipo | Número decimal não negativo |
| Severidade | Obrigatório |

**Descrição do campo:** distância real percorrida ao longo da forma desde o primeiro ponto até ao ponto desta linha.

Mais informação em [shapes.txt](/reference/gtfs/schedule/shapes).

## Como funciona

Quando a regra passa, `shape_dist_traveled` está preenchido e não é negativo. Apesar do nome, a regra **não verifica aqui se os valores são crescentes**.

A regra avalia cada linha do `shapes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Aplica a configuração da regra | Segue para o passo 2 |
| 2 | A configuração proíbe o campo? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é negativo? | ❌ Reporta o problema | ✅ Passa |

O valor tem de poder ser lido como número decimal antes desta regra.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `0` | ✅ Passa | Zero não é negativo |
| `-0.1` | ❌ Problema | O valor é negativo |
| vazio | ❌ Problema | Falta um campo obrigatório |
| `10` com o campo proibido | ❌ Problema | A configuração proíbe o campo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor negativo | `shape_dist_traveled` é inferior a zero | Corrigir `shape_dist_traveled` em `shapes.txt` para zero ou mais |
| Campo em falta | A configuração exige ou recomenda `shape_dist_traveled` | Preencher `shape_dist_traveled` em `shapes.txt` |
| Campo preenchido quando não devia | A configuração proíbe `shape_dist_traveled` | Remover `shape_dist_traveled` de `shapes.txt` ou rever a configuração da regra |
