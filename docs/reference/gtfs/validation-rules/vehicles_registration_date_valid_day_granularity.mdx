title: Data de primeira matrícula
description: Verifica se registration_date contém uma data civil válida no formato AAAAMMDD.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `vehicles_registration_date_valid_day_granularity` |
| Ficheiro | `vehicles.txt` |
| Campo | `registration_date` |
| Tipo | Data |
| Severidade | Obrigatório |

**Descrição do campo:** data da primeira matrícula do veículo, em qualquer local. É frequentemente usada para determinar a idade do veículo e usa o formato numérico `AAAAMMDD`.

Mais informação em [vehicles.txt](/reference/gtfs/schedule/vehicles).

## Como funciona

O valor tem de ter oito algarismos e representar uma data existente no calendário. A regra não verifica se a data corresponde ao veículo nem se é anterior ao dia atual.

A regra avalia cada linha do `vehicles.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor tem o formato `AAAAMMDD` e representa uma data válida? | ✅ Passa | ❌ Reporta o problema: data inválida |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `20240131` | ✅ Passa | Data válida |
| `2024-01-31` | ❌ Problema | Formato incorreto |
| `20240230` | ❌ Problema | Dia inexistente |
| `20241301` | ❌ Problema | Mês inexistente |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda `registration_date` | Preencher `registration_date` em `vehicles.txt` no formato `AAAAMMDD` |
| Campo preenchido quando não devia | A configuração da regra proíbe `registration_date` | Remover o valor de `registration_date` em `vehicles.txt` |
| Data inválida | O valor tem outro formato ou não representa uma data existente | Corrigir `registration_date` em `vehicles.txt` para uma data válida no formato `AAAAMMDD` |
