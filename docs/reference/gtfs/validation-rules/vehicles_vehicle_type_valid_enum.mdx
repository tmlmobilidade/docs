title: Tipo de veículo
description: Verifica se vehicle_type usa um modo de transporte válido e, quando configurado, permitido.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `vehicles_vehicle_type_valid_enum` |
| Ficheiro | `vehicles.txt` |
| Campo | `vehicle_type` |
| Tipo | Enumeração |
| Severidade | Obrigatório |

**Descrição do campo:** modo de transporte do veículo. Usa os valores de `route_type`: `0` elétrico, `1` metro, `2` comboio, `3` autocarro, `4` barco, `5` elétrico por cabo, `6` transporte aéreo por cabo, `7` funicular, `11` trólei e `12` monocarril.

Mais informação em [vehicles.txt](/reference/gtfs/schedule/vehicles).

## Como funciona

O valor tem de pertencer à lista base de modos de transporte. Se a configuração da regra restringir essa lista, o valor também tem de ser permitido. A regra não compara o modo com as linhas ou viagens do veículo.

A regra avalia cada linha do `vehicles.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é `0`, `1`, `2`, `3`, `4`, `5`, `6`, `7`, `11` ou `12`? | Segue para o passo 4 | ❌ Reporta o problema: tipo inválido |
| 4 | A configuração da regra define uma lista de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor consta da lista, ou a lista aceita qualquer opção? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `3` | ✅ Passa | Autocarro válido |
| `8` | ❌ Problema | Fora da lista base |
| `1` (lista permitida = `3`, `4`) | ❌ Problema | Valor válido, mas não permitido |
| `4` (lista permitida = `3`, `4`) | ✅ Passa | Valor permitido |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda `vehicle_type` | Preencher `vehicle_type` em `vehicles.txt` com o modo de transporte |
| Campo preenchido quando não devia | A configuração da regra proíbe `vehicle_type` | Remover o valor de `vehicle_type` em `vehicles.txt` |
| Tipo inválido | O valor não pertence à lista base | Corrigir `vehicle_type` em `vehicles.txt` para um dos valores válidos |
| Valor não permitido | O valor é válido, mas não consta da lista configurada | Usar em `vehicle_type` de `vehicles.txt` um valor permitido ou ajustar a configuração da regra |
