---
title: Data inicial do período
description: Verifica se a data inicial do período de informação fiável usa o formato AAAAMMDD e representa uma data real.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_start_date_valid_yyyymmdd` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_start_date` |
| Tipo | Data |
| Severidade | Obrigatório |

**Descrição do campo:** início do período em que o conjunto fornece horários completos e fiáveis. O período termina no fim do dia indicado por `feed_end_date`. As datas fora do período podem conter informação futura não definitiva.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Quando a regra passa, `feed_start_date` respeita a configuração, tem oito algarismos e representa uma data real. A regra **não compara a data com `feed_end_date`, `calendar.txt` ou `calendar_dates.txt`**.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor tem o formato `AAAAMMDD` e representa uma data real? | ✅ Passa | ❌ Reporta o problema: data inválida |

Os espaços não são removidos. Uma linha com todos os campos vazios é ignorada antes desta regra.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `20240229` | ✅ Passa | Data válida de ano bissexto |
| `20230229` | ❌ Problema | Dia inexistente |
| `2024-01-01` | ❌ Problema | Formato incorreto |
| campo vazio | ❌ Problema | Falta uma data obrigatória |
| `20240101` quando o campo é proibido | ❌ Problema | Campo preenchido indevidamente |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Data inválida | O valor não tem oito algarismos ou não representa uma data real | Corrigir `feed_start_date` em `feed_info.txt` para uma data válida no formato `AAAAMMDD` |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `feed_start_date` em `feed_info.txt` com a data inicial no formato `AAAAMMDD` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `feed_start_date` em `feed_info.txt` |
