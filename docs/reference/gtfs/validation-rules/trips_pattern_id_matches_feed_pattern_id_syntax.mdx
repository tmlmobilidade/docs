## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_pattern_id_matches_feed_pattern_id_syntax` |
| Ficheiro | `trips.txt` |
| Campo | `pattern_id` |
| Tipo | Identificador |
| Severidade | Opcional |

**Descrição do campo:** identifica o padrão da viagem. Por predefinição, deve ter três partes separadas por sublinhados: até quatro carateres, um caráter e outro caráter.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Um valor preenchido tem de corresponder ao formato predefinido `XXXX_X_X` ou a pelo menos uma expressão configurada. A regra não verifica se o padrão existe noutro ficheiro. Expressões configuradas inválidas são ignoradas.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ✅ Passa | Segue para o passo 2 |
| 2 | A configuração da regra desativa a validação? | ✅ Passa | Segue para o passo 3 |
| 3 | Existem expressões de formato configuradas? | Compila as expressões válidas; se nenhuma for válida, usa `XXXX_X_X` | Usa `XXXX_X_X` |
| 4 | O valor corresponde a pelo menos um formato aceite? | ✅ Passa | ❌ Reporta o problema: formato inválido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `1001_0_6` | ✅ Passa | Corresponde a `XXXX_X_X` |
| `1001_0_1_1` | ❌ Problema | Tem partes a mais |
| `1001_0_ASC` com formato configurado para `ASC` ou `DESC` | ✅ Passa | Corresponde a uma expressão configurada |
| `1001_0_6` com formato configurado para `ASC` ou `DESC` | ❌ Problema | Não corresponde aos formatos configurados |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Formato inválido | `pattern_id` não corresponde ao formato predefinido nem às expressões configuradas | Corrigir `pattern_id` em `trips.txt` ou ajustar os formatos da configuração da regra |
