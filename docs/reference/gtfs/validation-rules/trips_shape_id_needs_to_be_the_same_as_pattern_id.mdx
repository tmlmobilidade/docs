---
title: Forma igual ao padrão
description: Verifica se `shape_id` é exatamente igual a `pattern_id`.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_shape_id_needs_to_be_the_same_as_pattern_id` |
| Ficheiro | `trips.txt` |
| Campos | `shape_id`, `pattern_id` |
| Tipo | Identificador |
| Severidade | Opcional (recomendado) |

**Descrição dos campos:**

- `shape_id`: identifica a forma geográfica da viagem.
- `pattern_id`: identifica o padrão da viagem.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Quando ambos existem, os dois valores têm de ser exatamente iguais. Se algum estiver vazio, a regra não compara nada. A regra não verifica se a forma existe em `shapes.txt`.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | `shape_id` ou `pattern_id` está vazio? | ✅ Passa | Segue para o passo 2 |
| 2 | A configuração da regra desativa a validação? | ✅ Passa | Segue para o passo 3 |
| 3 | Os dois valores são iguais? | ✅ Passa | ❌ Reporta o problema |

## Como se relacionam

A regra impõe uma associação direta: cada linha usa o mesmo texto em `shape_id` e `pattern_id`.

## Exemplos

| `shape_id` | `pattern_id` | Resultado | Porquê |
|---|---|---|---|
| `1001_0_1` | `1001_0_1` | ✅ Passa | Valores iguais |
| `FORMA_1` | `1001_0_1` | ❌ Problema | Valores diferentes |
| Vazio | `1001_0_1` | ✅ Passa | A regra não compara campos ausentes |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Forma diferente do padrão | `shape_id` e `pattern_id` têm valores diferentes | Alterar `shape_id` ou `pattern_id` em `trips.txt` para que sejam iguais |
