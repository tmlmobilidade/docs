title: "Disponibilidade do ficheiro do operador"
description: "Verifica a disponibilidade de agency.txt segundo a configuração da regra."
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_file_missing` |
| Ficheiro | `agency.txt` |
| Campo | Se aplica em todo o ficheiro |
| Tipo | Ficheiro |
| Severidade | Configurável |

## Como funciona

A regra verifica se `agency.txt` está disponível nos dados importados. Se a configuração da regra proibir o ficheiro, a sua presença origina um problema. A regra não valida o conteúdo das linhas.

A regra avalia a presença de `agency.txt` nos dados importados, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | A configuração da regra proíbe o ficheiro? | Segue para o passo 2 | Segue para o passo 3 |
| 2 | O ficheiro está disponível nos dados importados? | ❌ Reporta o problema: ficheiro proibido | ✅ Passa |
| 3 | O ficheiro está disponível nos dados importados? | ✅ Passa | Segue para o passo 4 |
| 4 | A configuração da regra manda ignorar a mensagem? | Não apresenta a mensagem, mas impede as regras dependentes de avançar | ❌ Reporta o problema: ficheiro em falta |

Um ficheiro disponível mas vazio passa nesta verificação, salvo se estiver proibido. Ignorar a mensagem não permite avançar nas regras dependentes quando o ficheiro falta.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `agency.txt` disponível | ✅ Passa | Ficheiro encontrado |
| `agency.txt` ausente | ❌ Problema | Ficheiro em falta |
| `agency.txt` disponível; a configuração da regra proíbe o ficheiro | ❌ Problema | Ficheiro proibido |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Ficheiro proibido | A configuração da regra proíbe o ficheiro | Remover `agency.txt` do conjunto de dados ou rever a configuração da regra. |
| Ficheiro em falta | O ficheiro não está disponível nos dados importados | Incluir `agency.txt` no conjunto de dados e voltar a importar. |
