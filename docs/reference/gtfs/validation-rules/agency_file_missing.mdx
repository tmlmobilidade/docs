---
title: "Presença do ficheiro de operadores"
description: "Verifica se agency.txt está disponível quando a configuração da regra assinala a sua ausência."
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_file_missing` |
| Ficheiro | `agency.txt` |
| Campo | Se aplica em todo o ficheiro |
| Tipo | Ficheiro |
| Severidade | Obrigatório |

## Como funciona

A regra verifica se o ficheiro de operadores está disponível após a importação. Não verifica o número de linhas, as colunas ou os valores do ficheiro.

A regra avalia a presença de `agency.txt` no conjunto de dados, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | A configuração da regra recomenda o ficheiro e este está ausente? | ❌ Reporta o problema: ficheiro recomendado em falta | Segue para o passo 2 |
| 2 | A configuração da regra assinala a ausência como informação e o ficheiro está ausente? | ❌ Reporta o problema: ficheiro em falta | Segue para o passo 3 |
| 3 | O ficheiro é obrigatório e está ausente? | ❌ Reporta o problema: ficheiro obrigatório em falta | ✅ Passa sem reportar ausência |

Sem configuração fornecida, o ficheiro é obrigatório. Com configuração, aplica-se a definição desta regra. Um ficheiro importado sem linhas não é considerado ausente. A proibição de um ficheiro presente é reportada por outra regra.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| Ficheiro presente e importado | ✅ Passa | Ficheiro disponível |
| Ficheiro ausente (obrigatório) | ❌ Problema | Falta o ficheiro exigido |
| Ficheiro ausente (recomendado) | ❌ Problema | Falta o ficheiro recomendado |
| Ficheiro ausente (informativo) | ❌ Problema | Ausência assinalada como informação |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Ficheiro recomendado em falta | A configuração da regra recomenda o ficheiro | Incluir `agency.txt` no conjunto de dados GTFS. |
| Ficheiro em falta | A configuração da regra assinala a ausência como informação | Incluir `agency.txt` no conjunto de dados GTFS. |
| Ficheiro obrigatório em falta | O ficheiro exigido não está disponível | Incluir `agency.txt` no conjunto de dados GTFS e confirmar que foi importado. |
