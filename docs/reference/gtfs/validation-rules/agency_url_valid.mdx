## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_url_valid` |
| Ficheiro | `agency.txt` |
| Campo | `agency_url` |
| Tipo | Endereço de página |
| Severidade | Obrigatório |

**Descrição do campo:** página do operador de transporte.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

Um endereço preenchido tem de usar `http` ou `https` e identificar um servidor. A regra não visita a página nem confirma que esta existe.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | A configuração da regra manda ignorar esta verificação? | A verificação não é executada | Segue para o passo 2 |
| 2 | O campo está vazio? | Não reporta a ausência nesta regra | Segue para o passo 3 |
| 3 | O texto fica vazio depois de ignorar os espaços exteriores? | ❌ Reporta o problema: formato inválido | Segue para o passo 4 |
| 4 | O texto contém espaços interiores ou outros carateres não aceites? | ❌ Reporta o problema: formato inválido | Segue para o passo 5 |
| 5 | Cada sinal `%` é seguido de dois símbolos entre `0` e `9`, `A` e `F` ou `a` e `f`? | Segue para o passo 6 | ❌ Reporta o problema: formato inválido |
| 6 | O texto pode ser interpretado como endereço de página? | Segue para o passo 7 | ❌ Reporta o problema: formato inválido |
| 7 | O protocolo é `http` ou `https`? | Segue para o passo 8 | ❌ Reporta o problema: formato inválido |
| 8 | Existe um servidor no endereço? | ✅ Passa | ❌ Reporta o problema: formato inválido |

Os espaços no início e no fim são ignorados na verificação do formato. Esta regra não aplica uma lista de endereços permitidos.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://operador.pt/tarifas` | ✅ Passa | Protocolo e servidor presentes |
| `operador.pt/tarifas` | ❌ Problema | Falta o protocolo |
| `https://operador.pt/a b` | ❌ Problema | Espaço no endereço |
| `ftp://operador.pt/tarifas` | ❌ Problema | Protocolo não aceite |
| `https://operador.pt/%ZZ` | ❌ Problema | Codificação com `%` inválida |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Formato inválido | O endereço está incompleto ou contém texto não aceite | Escrever um endereço completo com `http` ou `https` em `agency_url` de `agency.txt`. |
