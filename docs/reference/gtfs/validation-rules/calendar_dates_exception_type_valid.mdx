## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `calendar_dates_exception_type_valid` |
| Ficheiro | `calendar_dates.txt` |
| Campo | `exception_type` |
| Tipo | Valor de uma lista |
| Severidade | Obrigatório |

**Descrição do campo:** indica se o serviço é acrescentado ou retirado na data indicada em `date`.

Mais informação em [calendar_dates.txt](/reference/gtfs/schedule/calendar_dates).

## Como funciona

Verifica se o tipo de exceção representa o número inteiro 1 ou 2. A regra não verifica o preenchimento nem a existência do serviço ou da data.

A regra avalia cada linha do `calendar_dates.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | A configuração da regra está desativada? | A verificação não é executada | Segue para o passo 2 |
| 2 | O campo está vazio? | Não reporta a ausência nesta regra | Segue para o passo 3 |
| 3 | O valor representa um número inteiro igual a `1` ou `2`? | ✅ Passa | ❌ Reporta o problema: tipo de exceção inválido |

O valor é comparado como número inteiro; `01` equivale a `1`. Os espaços não são removidos.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `1` | ✅ Passa | Tipo de exceção aceite |
| `3` | ❌ Problema | Tipo fora do conjunto aceite |
| `abc` | ❌ Problema | Texto em vez de número inteiro |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Tipo de exceção inválido | O valor não representa um ou dois | Usar `1` para acrescentar serviço ou `2` para retirar serviço em `exception_type` de `calendar_dates.txt`. |
