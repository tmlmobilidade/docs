---
title: Número de telefone do operador
description: Verifica se o telefone indicado em agency.txt tem um formato aceite e, quando configurado, se consta da lista de números permitidos.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_phone_valid_phone_number` |
| Ficheiro | `agency.txt` |
| Campo | `agency_phone` |
| Tipo | Número de telefone |
| Severidade | Opcional |

**Descrição do campo:** número de telefone de voz do operador. Pode usar a apresentação habitual da área de serviço e incluir pontuação para agrupar os algarismos. Também pode incluir texto marcável, mas não outra informação descritiva.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

Se o operador indicar um telefone, o valor só pode conter algarismos, letras, espaços, parênteses, hífen e sinal de adição. Tem de incluir pelo menos sete algarismos. Quando existe uma lista de valores permitidos, o telefone também tem de constar dessa lista. A regra **não confirma que o número existe ou recebe chamadas**.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor usa apenas carateres aceites e contém pelo menos sete algarismos? | Segue para o passo 4 | ❌ Reporta o problema: número inválido |
| 4 | A configuração da regra tem uma lista de números permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: número não permitido |

Os espaços no início e no fim são ignorados ao verificar o formato. A comparação com a lista permitida usa o valor original completo.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `987-654-321` | ✅ Passa | Nove algarismos e pontuação aceite |
| `503-238-RIDE` | ❌ Problema | Apenas seis algarismos |
| `Apoio: 210123456` | ❌ Problema | Dois-pontos não aceite |
| `210123456` (lista permitida = `211234567`) | ❌ Problema | Fora da lista |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Número de telefone inválido | Existem carateres não aceites ou menos de sete algarismos | Corrigir `agency_phone` em `agency.txt` para incluir pelo menos sete algarismos e apenas carateres aceites |
| Número de telefone não permitido | O número tem formato válido mas não consta da lista configurada | Usar em `agency_phone` de `agency.txt` um número permitido ou rever a lista na configuração da regra |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `agency_phone` em `agency.txt` com o número de telefone do operador |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `agency_phone` em `agency.txt` |
