title: Precisão do horário
description: Verifica se `timepoint` usa 0 ou 1 e, quando configurado, um valor permitido.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `stop_times_timepoint_valid_gtfs_enum` |
| Ficheiro | `stop_times.txt` |
| Campo | `timepoint` |
| Tipo | Enumeração |
| Severidade | Opcional |

**Descrição do campo:** indica se as horas são aproximadas ou interpoladas, com `0`, ou exatas, com `1`.

Mais informação em [stop_times.txt](/reference/gtfs/schedule/stop_times).

## Como funciona

Quando existe, o valor tem de ser `0` ou `1`. Uma lista configurada pode restringir os valores. A regra não confirma se as horas são realmente exatas nem exige o campo quando existem horas.

A regra avalia cada linha do `stop_times.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração exige ou recomenda o campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração proíbe o campo? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é `0` ou `1`? | Segue para o passo 4 | ❌ Reporta o problema: valor inválido |
| 4 | Existe uma lista configurada de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor consta da lista, ou a lista aceita qualquer valor? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `1` | ✅ Passa | Hora exata |
| `2` | ❌ Problema | Fora da enumeração |
| `1` (lista permitida = `0`) | ❌ Problema | Fora da lista configurada |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração exige ou recomenda `timepoint` | Preencher `timepoint` em `stop_times.txt` |
| Campo preenchido quando não devia | A configuração proíbe `timepoint` | Remover `timepoint` de `stop_times.txt` |
| Valor inválido | O valor não é `0` nem `1` | Corrigir `timepoint` em `stop_times.txt` |
| Valor não permitido | O valor não consta da lista configurada | Usar um valor permitido em `timepoint` de `stop_times.txt`, ou ajustar a configuração |
