title: Identificador único do percurso
description: Verifica se pathway_id está preenchido e não se repete em pathways.txt.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `pathway_id_unique` |
| Ficheiro | `pathways.txt` |
| Campo | `pathway_id` |
| Tipo | Identificador único |
| Severidade | Obrigatório |

**Descrição do campo:** identificador interno do percurso. Tem de ser único no conjunto GTFS, mesmo quando vários percursos ligam os mesmos locais.

Mais informação em [pathways.txt](/reference/gtfs/schedule/pathways).

## Como funciona

Quando a regra passa, `pathway_id` está preenchido e aparece uma só vez em `pathways.txt`. A regra **não compara as origens, os destinos nem o modo dos percursos**.

A regra avalia cada linha do `pathways.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O mesmo `pathway_id` aparece mais do que uma vez? | ❌ Reporta o problema: identificador duplicado | ✅ Passa |

O valor é comparado exatamente como está escrito. Os espaços e as diferenças entre maiúsculas e minúsculas não são ignorados. Uma linha totalmente vazia é ignorada.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `P1` numa única linha | ✅ Passa | O identificador é único |
| `P1` em duas linhas | ❌ Problema | O identificador está duplicado |
| vazio | ❌ Problema | Falta um campo obrigatório |
| `P1` com o campo proibido | ❌ Problema | A configuração proíbe o campo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Identificador duplicado | Duas ou mais linhas usam o mesmo `pathway_id` | Atribuir um `pathway_id` diferente a cada percurso em `pathways.txt` |
| Campo em falta | A configuração da regra exige ou recomenda `pathway_id` | Preencher `pathway_id` em `pathways.txt` com um identificador único |
| Campo preenchido quando não devia | A configuração da regra proíbe `pathway_id` | Remover `pathway_id` de `pathways.txt` ou rever a configuração da regra |
