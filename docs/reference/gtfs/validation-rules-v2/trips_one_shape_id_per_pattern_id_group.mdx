---
title: Um único shape_id por pattern_id
description: Verifica se todas as viagens do mesmo pattern_id partilham o mesmo shape_id.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_one_shape_id_per_pattern_id_group` |
| Ficheiro | `trips.txt` |
| Campo | `shape_id` |
| Tipo | ID |
| Severidade | Configurável |

**Descrição do campo:** identifica a forma geoespacial que descreve o trajeto percorrido pelo veículo numa viagem. Todas as viagens que partilham o mesmo `pattern_id` têm de partilhar também o mesmo `shape_id`.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Todas as viagens agrupadas pelo mesmo `pattern_id` têm de ter um único valor de `shape_id`. A regra **não verifica qual dos valores está correto**, só que não há mais do que um valor dentro do mesmo grupo. Quando esta regra reporta um `pattern_id`, a regra `trips_one_pattern_id_per_shape_id_group` não repete o mesmo problema a partir do `shape_id` envolvido.

A regra avalia cada grupo de viagens com o mesmo `pattern_id` do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O grupo tem viagens com `shape_id` preenchido? | Segue para o passo 2 | ✅ Passa (nada a comparar) |
| 2 | As viagens do grupo têm mais do que um valor distinto de `shape_id`? | Segue para o passo 3 | ✅ Passa |
| 3 | A configuração da regra está definida como "ignorar" ou "não permitido"? | ✅ Passa (a regra não é aplicada) | ❌ Reporta o problema |

As viagens sem `shape_id` não contam para esta comparação.

## Exemplos

| pattern_id | shape_id das viagens do grupo | Resultado | Porquê |
|---|---|---|---|
| `P1` | `1001_0` em todas as viagens | ✅ Passa | Só há um valor de `shape_id` no grupo |
| `P1` | `1001_0` numa viagem, vazio noutra | ✅ Passa | As viagens sem `shape_id` não contam para a comparação |
| `P1` | `1001_0` e `1001_1` | ❌ Problema | O grupo tem dois valores de `shape_id` diferentes |
| `P1` | `1001_0`, `1002_0` e `1003_0` | ❌ Problema | O grupo tem três valores de `shape_id` diferentes |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Mais do que um `shape_id` no mesmo `pattern_id` | As viagens do mesmo `pattern_id` foram associadas a formas diferentes, por exemplo por erro de importação ou atualização parcial | Corrigir o campo `shape_id` em `trips.txt` para que todas as viagens do mesmo `pattern_id` tenham o mesmo valor |
