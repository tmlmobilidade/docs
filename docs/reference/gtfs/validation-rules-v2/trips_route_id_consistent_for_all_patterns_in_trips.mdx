---
title: Rota igual em todo o padrão
description: Verifica se todas as viagens com o mesmo pattern_id têm o mesmo route_id.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_route_id_consistent_for_all_patterns_in_trips` |
| Ficheiro | `trips.txt` |
| Campo | `route_id` |
| Tipo | Chave estrangeira (routes.route_id) |
| Severidade | Opcional (obrigatório para os Transportes Metropolitanos de Lisboa) |

**Descrição do campo:** identifica a rota da viagem.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Todas as viagens com o mesmo `pattern_id` têm de ter o mesmo `route_id`. A regra só avalia viagens com `pattern_id` preenchido. **Não verifica** se o valor existe noutros ficheiros. Só é reportado um problema por padrão, na primeira viagem do grupo.

A regra avalia cada grupo de viagens com o mesmo `pattern_id` no `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | Há mais do que um valor de `route_id` entre as viagens do grupo? | ❌ Reporta o problema: valores diferentes no mesmo padrão | ✅ Passa |

## Como se relacionam

Um padrão (`pattern_id`) agrupa as viagens que fazem o mesmo percurso no mesmo sentido. Por isso, o `route_id` não pode mudar entre viagens do mesmo `pattern_id`.

## Exemplos

| Viagens do mesmo `pattern_id` | Resultado | Porquê |
|---|---|---|
| `1001_0_1`: rota `1001` em todas | ✅ Passa | Rota única |
| `1001_0_1`: rotas `1001` e `1002` | ❌ Problema | Duas rotas no mesmo padrão |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Rotas diferentes no mesmo padrão | Uma viagem foi associada à rota errada, ou o `pattern_id` foi reutilizado | Corrigir `route_id` ou `pattern_id` das viagens indicadas no `trips.txt`, para que cada padrão pertença a uma só rota |
