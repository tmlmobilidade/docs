## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `level_name` |
| Ficheiro | `levels.txt` |
| Campo | `level_name` |
| Tipo | Texto |
| Severidade | Opcional |

**Descrição do campo:** nome do nível como o passageiro o vê dentro do edifício ou da estação. Por exemplo, `Cais`, `Átrio` ou `-1`.

Mais informação em [levels.txt](/reference/gtfs/schedule/levels).

## Como funciona

O `level_name` é opcional. Um campo vazio é aceite, salvo se a configuração da regra o exigir ou recomendar. A regra **não verifica o conteúdo do nome**. Aceita qualquer texto preenchido.

A regra avalia cada linha do `levels.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `level_name` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | ✅ Passa |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `Átrio` | ✅ Passa | Preenchido |
| *(vazio)* | ✅ Passa | Campo opcional |
| *(vazio)* com campo exigido na configuração | ❌ Problema | A configuração da regra exige o campo |
| `Átrio` com campo proibido na configuração | ❌ Problema | A configuração da regra proíbe o campo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `level_name` em `levels.txt` com o nome que os passageiros conhecem |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `level_name` em `levels.txt` |
