## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `route_type_valid_gtfs_enum` |
| Ficheiro | `routes.txt` |
| Campo | `route_type` |
| Tipo | Enumeração |
| Severidade | Obrigatório |

**Descrição do campo:** indica o tipo de transporte usado na rota. Os valores válidos são `0` (elétrico ou metro ligeiro), `1` (metro), `2` (comboio), `3` (autocarro), `4` (barco), `5` (elétrico de cabo), `6` (teleférico), `7` (funicular), `11` (troleicarro) e `12` (monocarril).

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Quando a regra passa, o `route_type` é um dos valores previstos e, se a configuração da regra tiver uma lista de valores permitidos, consta dessa lista.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é `0`, `1`, `2`, `3`, `4`, `5`, `6`, `7`, `11` ou `12`? | Segue para o passo 4 | ❌ Reporta o problema: valor inválido |
| 4 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `3` | ✅ Passa | Valor previsto (autocarro) |
| `8` | ❌ Problema | Valor não previsto |
| `3` (lista permitida = `1`, `2`) | ❌ Problema | Valor válido, mas fora da lista |
| (vazio) | ❌ Problema | Campo obrigatório sem valor |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor inválido | O valor não está entre `0`, `1`, `2`, `3`, `4`, `5`, `6`, `7`, `11` e `12` | Corrigir `route_type` em `routes.txt` para um valor previsto |
| Valor não permitido | O valor está fora da lista de valores permitidos da configuração da regra | Usar um valor da lista em `route_type` em `routes.txt`, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `route_type` em `routes.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `route_type` em `routes.txt` |
