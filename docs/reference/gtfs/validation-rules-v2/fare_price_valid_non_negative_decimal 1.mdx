---
title: Preço não negativo da tarifa
description: Verifica se o preço indicado em fare_attributes.txt está preenchido e não é negativo.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `fare_price_valid_non_negative_decimal` |
| Ficheiro | `fare_attributes.txt` |
| Campo | `price` |
| Tipo | Número decimal não negativo |
| Severidade | Obrigatório |

**Descrição do campo:** preço da tarifa, na unidade indicada por `currency_type`.

Mais informação em [fare_attributes.txt](/reference/gtfs/schedule/fare_attributes).

## Como funciona

Quando a regra passa, `price` está presente quando exigido e não é inferior a zero. A regra **não confirma se a moeda está correta nem se o valor é um número finito**. Valores especiais como `NaN` e `+Inf` não são inferiores a zero e passam esta verificação.

A regra avalia cada linha do `fare_attributes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O preço é inferior a zero? | ❌ Reporta o problema: preço negativo | ✅ Passa |

O valor é interpretado como número decimal antes desta regra. Os espaços não são removidos antes dessa interpretação.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `2.50` | ✅ Passa | Valor positivo |
| `0` | ✅ Passa | Zero é aceite |
| campo vazio | ❌ Problema | Falta um valor obrigatório |
| `-1.50` | ❌ Problema | Valor negativo |
| `2.50` quando o campo é proibido | ❌ Problema | Campo preenchido indevidamente |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Preço negativo | O valor é inferior a zero | Corrigir `price` em `fare_attributes.txt` para zero ou um valor positivo |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `price` em `fare_attributes.txt` com o preço da tarifa |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `price` em `fare_attributes.txt` |
