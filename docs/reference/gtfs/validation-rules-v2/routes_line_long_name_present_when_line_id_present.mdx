---
title: Nome longo da linha
description: Verifica se o campo line_long_name em routes.txt está preenchido sempre que a rota tem um line_id.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `routes_line_long_name_present_when_line_id_present` |
| Ficheiro | `routes.txt` |
| Campo | `line_long_name` |
| Tipo | Texto |
| Severidade | Condicional (obrigatório quando `line_id` está preenchido) |

**Descrição do campo:** nome longo da linha a que a rota pertence.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Se a rota tiver o campo `line_id` preenchido, o campo `line_long_name` também tem de ter um valor. Se `line_id` estiver vazio, a regra não verifica `line_long_name`. A regra só confirma a presença do texto, não o seu conteúdo.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo `line_id` está preenchido? | Segue para o passo 2 | ✅ Passa (o campo `line_long_name` não é verificado) |
| 2 | O campo `line_long_name` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 3 |
| 3 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | ✅ Passa |

## Exemplos

| `line_id` | `line_long_name` | Resultado | Porquê |
|---|---|---|---|
| (vazio) | (vazio) | ✅ Passa | `line_id` não está preenchido, o campo não é verificado |
| `100` | `Lisboa - Cascais` | ✅ Passa | Ambos os campos preenchidos |
| `100` | (vazio) | ❌ Problema | `line_id` preenchido mas falta `line_long_name` |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | `line_id` está preenchido, mas `line_long_name` está vazio, e a configuração da regra exige ou recomenda este campo | Preencher `line_long_name` em `routes.txt` com o nome longo da linha |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `line_long_name` em `routes.txt` |
