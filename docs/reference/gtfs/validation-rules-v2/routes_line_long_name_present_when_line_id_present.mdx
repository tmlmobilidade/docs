---
title: Nome longo da linha
description: Verifica se o line_long_name está preenchido sempre que a rota tem line_id.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `routes_line_long_name_present_when_line_id_present` |
| Ficheiro | `routes.txt` |
| Campo | `line_long_name` |
| Tipo | Texto |
| Severidade | Condicional (obrigatório quando existe `line_id`) |

**Descrição do campo:** nome longo da linha a que a rota pertence.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Quando a regra passa, as rotas com `line_id` têm o `line_long_name` preenchido. Nas rotas sem `line_id`, a regra não avalia nada. A regra **não verifica o conteúdo do texto**.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `line_id` está vazio? | ✅ Passa (a regra não se aplica) | Segue para o passo 2 |
| 2 | O `line_long_name` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 3 |
| 3 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | ✅ Passa |

## Como se relacionam

A regra só se aplica quando `line_id` está preenchido. Nesse caso, `line_long_name` tem de existir.

## Exemplos

| line_id | line_long_name | Resultado | Porquê |
|---|---|---|---|
| `1001` | `Lisboa - Porto` | ✅ Passa | Nome preenchido |
| (vazio) | (vazio) | ✅ Passa | Sem `line_id`, a regra não se aplica |
| `1001` | (vazio) | ❌ Problema | Falta `line_long_name` |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `line_long_name` em `routes.txt` com o nome longo da linha |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `line_long_name` em `routes.txt` |
