title: Data de fim do conjunto de dados
description: Verifica se a data de fim do período coberto pelo conjunto de dados está preenchida em feed_info.txt e é uma data real no formato AAAAMMDD.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_end_date_valid_yyyymmdd_not_before_start` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_end_date` |
| Tipo | Data |
| Severidade | Obrigatório |

**Descrição do campo:** último dia do período em que o conjunto de dados tem horários completos e fiáveis. O período vai do início do dia `feed_start_date` até ao fim do dia `feed_end_date`. O `feed_end_date` não pode ser anterior ao `feed_start_date`. Se o período se estender para lá das datas ativas de `calendar.txt` e `calendar_dates.txt`, o conjunto de dados afirma que não há serviço nesses dias.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Quando a regra passa, o `feed_end_date` tem uma data real escrita com 8 algarismos, no formato AAAAMMDD. A regra só é avaliada quando o `feed_start_date` passa na respetiva regra. A regra **não compara esta data com o `feed_start_date`**: uma data de fim anterior à de início não é reportada.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ❌ Reporta o problema: campo em falta | Segue para o passo 2 |
| 2 | O valor tem 8 carateres e é uma data real no formato AAAAMMDD? | ✅ Passa | ❌ Reporta o problema: data inválida |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `20261231` | ✅ Passa | Data real no formato AAAAMMDD |
| vazio | ❌ Problema | Campo obrigatório |
| `31/12/2026` | ❌ Problema | Formato errado |
| `20261301` | ❌ Problema | O mês 13 não existe |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Data inválida | Data com separadores, dia ou mês trocados ou dia que não existe | Escrever no `feed_end_date` do `feed_info.txt` a data com 8 algarismos, ano, mês e dia, por exemplo `20261231` |
| Campo em falta | O campo está vazio | Preencher o `feed_end_date` do `feed_info.txt` com o último dia coberto pelo conjunto de dados |
