## Novas regras da versão GTFS v30

Validações introduzidas na nova versão do GTFS.

| Regra                                               | Severidade | Descrição                                                                                                    |
| --------------------------------------------------- | :--------: | ------------------------------------------------------------------------------------------------------------ |
| `route_id_composed_of_short_name_and_sort_order`    | **Aviso**  | Verifica se o `route_id` corresponde à junção de `route_short_name` e `route_sort_order`, separados por `_`. |
| `trips_shape_id_matches_route_id_and_direction_id`  | **Aviso**  | Verifica se o `shape_id` corresponde à junção de `route_id` e `direction_id`, separados por `_`.             |
| `trips_shape_id_max_two_per_route`                  |  **Erro**  | Verifica se as viagens com o mesmo `route_id` utilizam, no máximo, dois valores distintos de `shape_id`.     |
| `trips_shape_id_consistent_per_route_direction`     | **Aviso**  | Verifica se as viagens com o mesmo `route_id` e `direction_id` utilizam o mesmo `shape_id`.                  |
| `trip_headsign_max_two_per_route`                   |  **Erro**  | Verifica se existem, no máximo, dois destinos distintos em `trip_headsign` para o mesmo `route_id`.          |
| `trip_headsign_consistent_per_route_direction`      |  **Erro**  | Verifica se as viagens com o mesmo `route_id` e `direction_id` apresentam o mesmo `trip_headsign`.           |
| `trips_pattern_id_needs_to_be_the_same_as_shape_id` |  **Erro**  | Verifica se o `pattern_id` de cada viagem é igual ao respetivo `shape_id`.                                   |


## Regras existentes com novos critérios de validação

Estas regra já existiam nas versões anteriores mas ganharam um novo critério de validação, mantendo o critério antigo.

| Regra                                                    | Severidade | Descrição do novo critério                                                                                                              |
| -------------------------------------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `vehicles_license_plate_format_per_market_rules`         | **Erro**   | Passa a aceitar identificadores marítimos MMSI com nove algarismos, começando por um algarismo entre `2` e `7`.                         |
| `shape_dist_traveled_delta_mismatches_haversine_segment` | **Aviso**  | Passa também a verificar segmentos cuja distância acumulada começa em zero ou não aumenta apesar de existir deslocação entre os pontos. |


## Regras com novos nível de severidade

Com a nova versão do GTFS tiverem sua severidade alterada,

| Regra                                                    | Severidade | Motivo                                                                                                                                  |
| -------------------------------------------------------- | ---------- | --------------------------------------------------------------------------------------------------------------------------------------- |
| `agency_id_unique`                                       | **Erro**   | Passa a aceitar identificadores marítimos MMSI com nove algarismos, começando por um algarismo entre `2` e `7`.                         |
| `shape_dist_traveled_delta_mismatches_haversine_segment` | **Aviso**  | Passa também a verificar segmentos cuja distância acumulada começa em zero ou não aumenta apesar de existir deslocação entre os pontos. |
