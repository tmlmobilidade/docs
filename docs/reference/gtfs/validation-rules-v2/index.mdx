## Novas regras da versão GTFS v30

| Regra         |   Severidade    | Descrição                                                                                                                                            |
| ------------- | :-------------: | ---------------------------------------------------------------------------------------------------------------------------------------------------- |
| `agency_id`   | **Obrigatório** | Representa o código único do operador de transporte. Um arquivo GTFS pode conter vários operadores, mas no GO só são aceites arquivos mono-operador. |
| `agency_name` | **Obrigatório** | Nome da marca do operador.                                                                                                                           |
