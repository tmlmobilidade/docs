## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_url_valid_url` |
| Ficheiro | `agency.txt` |
| Campo | `agency_url` |
| Tipo | URL |
| Severidade | Obrigatório |

**Descrição do campo (GTFS):** endereço da página web do operador de transporte. Mais informação em [agency.txt](/reference/gtfs/schedule/agency.mdx).

## Como funciona

Cada linha do `agency.txt` tem de ter um `agency_url` preenchido e bem escrito, começado por `http://` ou `https://`. Se a configuração da regra tiver uma lista de URL permitidos, o endereço também tem de constar dessa lista. A regra **não confirma que a página existe ou abre**, só que o formato está correto.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `agency_url` está vazio? | ❌ Reporta o problema: `agency_url` obrigatório | Segue para o passo 2 |
| 2 | O texto é um URL válido? (ver condições abaixo) | Segue para o passo 3 | ❌ Reporta o problema: formato inválido |
| 3 | A configuração da regra tem uma lista de URL permitidos? | Segue para o passo 4 | ✅ Passa |
| 4 | O URL está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: endereço não permitido |

Para ser válido, o URL tem de:

- começar por `http://` ou `https://`;
- ter um domínio a seguir, por exemplo `operador.pt`;
- não ter espaços nem os caracteres `"`, `'`, `<`, `>`, `{`, `}`, `|`, `\` e `^`;
- usar `%` só em códigos completos, isto é, `%` seguido de dois carateres hexadecimais, como `%20`.

Os espaços no início e no fim são ignorados.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://www.operador.pt` | ✅ Passa | Formato correto |
| `www.operador.pt` | ❌ Problema | Falta `http://` ou `https://` |
| `ftp://operador.pt` | ❌ Problema | Só são aceites `http` e `https` |
| `https://` | ❌ Problema | Falta o domínio |
| `https://outro.pt` (lista permitida = `https://www.operador.pt`) | ❌ Problema | Formato válido, mas fora da lista |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| `agency_url` obrigatório | A linha do operador não tem `agency_url` | Preencher `agency_url` em `agency.txt` com o endereço da página web do operador |
| Formato inválido | Falta `http://` ou `https://`, ou há espaços ou carateres não permitidos | Copiar o endereço completo a partir do browser, começado por `https://`, e substituir os espaços por `%20` em `agency_url` |
| Endereço não permitido | O URL é válido mas não está na lista de URL permitidos | Usar em `agency_url` um URL da lista, ou pedir ao administrador que o adicione |
