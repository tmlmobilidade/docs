title: Cor do texto da rota
description: Verifica se o route_text_color de routes.txt é uma cor hexadecimal de 6 dígitos e, quando configurado, se consta da lista de valores permitidos.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `route_text_color_valid_hex_contrast` |
| Ficheiro | `routes.txt` |
| Campo | `route_text_color` |
| Tipo | Cor |
| Severidade | Obrigatório |

**Descrição do campo:** cor a usar para o texto sobre o fundo `route_color`. A diferença entre as duas cores deve garantir contraste suficiente num ecrã a preto e branco.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Quando a regra passa, o `route_text_color` é uma cor de 6 dígitos hexadecimais e, se a configuração da regra tiver uma lista de valores permitidos, consta dessa lista. A regra **não compara esta cor com `route_color`**, por isso não verifica o contraste.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor tem exatamente 6 dígitos hexadecimais (`0` a `9` e `A` a `F`, maiúsculas ou minúsculas)? | Segue para o passo 4 | ❌ Reporta o problema: cor inválida |
| 4 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

O valor é escrito sem o símbolo `#`.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `FF0000` | ✅ Passa | 6 dígitos hexadecimais |
| `ff0000` | ✅ Passa | Minúsculas são aceites |
| `#FF0000` | ❌ Problema | O `#` não é permitido |
| `F00` | ❌ Problema | Só 3 dígitos |
| (vazio) | ❌ Problema | Campo obrigatório sem valor |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Cor inválida | O valor tem o símbolo `#`, tem menos ou mais de 6 dígitos ou tem carateres que não são hexadecimais | Escrever `route_text_color` em `routes.txt` com 6 dígitos hexadecimais, por exemplo `FF0000` |
| Valor não permitido | O valor está fora da lista de valores permitidos da configuração da regra | Usar um valor da lista em `route_text_color` em `routes.txt`, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `route_text_color` em `routes.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `route_text_color` em `routes.txt` |
