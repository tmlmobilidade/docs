## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_route_id_references_routes_table` |
| Ficheiro | `trips.txt` |
| Campo | `route_id` |
| Tipo | Chave estrangeira para `routes.route_id` |
| Severidade | Obrigatório |

**Descrição do campo:** identifica a rota a que a viagem pertence.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

A regra garante que cada viagem está associada a uma rota que existe mesmo em `routes.txt`. A regra **não verifica** se a rota está corretamente configurada, só se o `route_id` indicado existe.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo `route_id` está vazio? | ❌ Reporta o problema: campo em falta | Segue para o passo 2 |
| 2 | O valor de `route_id` existe em `routes.txt`? | ✅ Passa | ❌ Reporta o problema: rota não encontrada |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `R1` (existe em `routes.txt`) | ✅ Passa | O `route_id` corresponde a uma rota existente |
| (vazio) | ❌ Problema | O campo `route_id` é obrigatório |
| `R99` (não existe em `routes.txt`) | ❌ Problema | Não há nenhuma rota com este `route_id` |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | O campo `route_id` não foi preenchido em `trips.txt` | Preencher `route_id` com o identificador de uma rota existente |
| Rota não encontrada | O `route_id` indicado em `trips.txt` não existe em `routes.txt`, por exemplo por erro de digitação ou porque a rota foi removida | Corrigir o `route_id` em `trips.txt` para o identificador correto, ou adicionar a rota correspondente em `routes.txt` |
