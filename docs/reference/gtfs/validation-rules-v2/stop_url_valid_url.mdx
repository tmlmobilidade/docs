---
title: URL da paragem
description: Verifica o formato do URL da página da paragem e a lista configurada de valores permitidos.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `stop_url_valid_url` |
| Ficheiro | `stops.txt` |
| Campo | `stop_url` |
| Tipo | URL |
| Severidade | Opcional |

**Descrição do campo:** endereço de uma página web dedicada à localização. Deve ser diferente de `agency_url` e `route_url`.

Mais informação em [stops.txt](/reference/gtfs/schedule/stops).

## Como funciona

Quando existe, o endereço tem de usar `http` ou `https`, indicar um domínio e ter sintaxe válida. Uma lista configurada pode limitar os endereços aceites. A regra não confirma se a página existe ou responde.

A regra avalia cada linha do `stops.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração exige ou recomenda o campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração proíbe o campo? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é um URL válido com `http` ou `https`? | Segue para o passo 4 | ❌ Reporta o problema: URL inválido |
| 4 | Existe uma lista configurada de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O URL consta da lista, ou a lista aceita qualquer valor? | ✅ Passa | ❌ Reporta o problema: URL não permitido |

Os espaços no início e no fim são ignorados apenas na validação do formato. A comparação com a lista usa o valor original.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://operador.pt/paragens/100` | ✅ Passa | URL completo |
| `operador.pt/paragens/100` | ❌ Problema | Falta o protocolo |
| `https://outro.pt` (lista permitida = `https://operador.pt`) | ❌ Problema | Fora da lista configurada |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| URL inválido | Falta o protocolo, o domínio ou existe um caráter não permitido | Corrigir `stop_url` em `stops.txt` com um URL completo |
| URL não permitido | O URL não consta da lista configurada | Usar em `stop_url` de `stops.txt` um URL permitido, ou ajustar a configuração da regra |
| Campo em falta | A configuração da regra exige ou recomenda `stop_url` | Preencher `stop_url` em `stops.txt` |
| Campo preenchido quando não devia | A configuração da regra proíbe `stop_url` | Remover o valor de `stop_url` em `stops.txt` |
