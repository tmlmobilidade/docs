---
title: Página web da paragem
description: Verifica se o stop_url de stops.txt, quando preenchido, é um endereço web http ou https bem escrito.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `stop_url_valid_url` |
| Ficheiro | `stops.txt` |
| Campo | `stop_url` |
| Tipo | URL |
| Severidade | Opcional |

**Descrição do campo:** endereço da página web da paragem.

Mais informação em [stops.txt](/reference/gtfs/schedule/stops).

## Como funciona

Se o `stop_url` estiver preenchido, tem de ser um endereço web bem escrito, a começar por `http://` ou `https://`. Um campo vazio é aceite, salvo se a configuração da regra o exigir ou recomendar. A regra **não verifica se a página existe**.

A regra avalia cada linha do `stops.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `stop_url` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O texto é um endereço web válido, com `http` ou `https`, sem espaços nem carateres proibidos, e com nome de site? | Segue para o passo 4 | ❌ Reporta o problema: URL inválido |
| 4 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

Os espaços no início e no fim são ignorados na verificação do formato.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://www.operador.pt/paragem/123` | ✅ Passa | Formato correto |
| `www.operador.pt/paragem/123` | ❌ Problema | Falta `http://` ou `https://` |
| *(vazio)* | ✅ Passa | Campo opcional |
| *(vazio)* com campo exigido na configuração | ❌ Problema | A configuração da regra exige o campo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| URL inválido | Falta `http://` ou `https://`, há espaços ou carateres proibidos | Escrever o `stop_url` em `stops.txt` como endereço completo, por exemplo `https://www.operador.pt/paragem/123` |
| Valor não permitido | O valor não está na lista da configuração da regra | Usar um valor da lista permitida, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `stop_url` em `stops.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `stop_url` em `stops.txt` |
