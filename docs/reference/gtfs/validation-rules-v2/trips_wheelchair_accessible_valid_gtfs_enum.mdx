## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_wheelchair_accessible_valid_gtfs_enum` |
| Ficheiro | `trips.txt` |
| Campo | `wheelchair_accessible` |
| Tipo | Enumeração |
| Severidade | Opcional |

**Descrição do campo:** indica a acessibilidade em cadeira de rodas: `0` sem informação, `1` permite pelo menos uma pessoa em cadeira de rodas e `2` não permite.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Quando existe, o valor tem de ser `0`, `1` ou `2`. Uma lista configurada pode restringir estes valores. A implementação aceita sempre o campo vazio, mesmo quando a configuração o exige ou proíbe.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ✅ Passa | Segue para o passo 2 |
| 2 | A configuração da regra proíbe o campo? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é `0`, `1` ou `2`? | Segue para o passo 4 | ❌ Reporta o problema: valor inválido |
| 4 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor consta da lista, ou a lista aceita qualquer valor? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `1` | ✅ Passa | Valor previsto |

| `3` | ❌ Problema | Fora da enumeração |
| `1` (lista permitida = `2`) | ❌ Problema | Fora da lista configurada |
| Vazio, mesmo com campo proibido | ✅ Passa | A implementação aceita sempre a ausência |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo preenchido quando não devia | A configuração da regra proíbe `wheelchair_accessible` | Remover `wheelchair_accessible` de `trips.txt` |
| Valor inválido | O valor não é `0`, `1` ou `2` | Corrigir `wheelchair_accessible` em `trips.txt` |
| Valor não permitido | O valor não consta da lista configurada | Usar um valor permitido em `wheelchair_accessible` de `trips.txt`, ou ajustar a configuração da regra |
