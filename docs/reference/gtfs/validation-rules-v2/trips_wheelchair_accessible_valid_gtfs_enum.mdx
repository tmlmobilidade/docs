## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_wheelchair_accessible_valid_gtfs_enum` |
| Ficheiro | `trips.txt` |
| Campo | `wheelchair_accessible` |
| Tipo | Enumeração |
| Severidade | Opcional |

**Descrição do campo:** indica a acessibilidade para cadeiras de rodas. O valor `0` ou vazio significa que não há informação de acessibilidade para a viagem, `1` significa que o veículo usado nesta viagem pode acomodar pelo menos um passageiro em cadeira de rodas e `2` significa que não é possível acomodar passageiros em cadeira de rodas nesta viagem.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Um campo vazio passa sempre, mesmo que a configuração da regra exija ou recomende o preenchimento deste campo. Quando preenchido, o valor tem de ser `0`, `1` ou `2`. A proibição de preenchimento definida na configuração da regra só é aplicada quando o campo tem um valor.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ✅ Passa sempre | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é `0`, `1` ou `2`? | Segue para o passo 4 | ❌ Reporta o problema: valor inválido |
| 4 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor está na lista (ou a lista aceita qualquer valor)? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `1` | ✅ Passa | Veículo acomoda pelo menos um passageiro em cadeira de rodas |
| (vazio) | ✅ Passa | Sem informação de acessibilidade; este campo aceita sempre vazio |
| `9` | ❌ Problema | Valor fora do conjunto `0`, `1`, `2` |
| `2` (lista permitida da configuração = `0`, `1`) | ❌ Problema | Valor válido mas fora da lista permitida |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor inválido | O valor de `wheelchair_accessible` não é `0`, `1` nem `2` | Corrigir `wheelchair_accessible` em `trips.txt` para um destes valores |
| Valor não permitido | O valor é válido mas não consta da lista de valores permitidos pela configuração da regra | Usar um valor da lista permitida, ou pedir ao administrador que a atualize |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `wheelchair_accessible` em `trips.txt` |
