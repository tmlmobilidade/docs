title: Página web de quem publica os dados
description: Verifica se o feed_publisher_url de feed_info.txt, quando preenchido, é um endereço web http ou https bem escrito.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_publisher_url_valid_http_url` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_publisher_url` |
| Tipo | URL |
| Severidade | Opcional |

**Descrição do campo:** endereço do site da organização que publica o conjunto de dados. Pode ser igual a um dos `agency_url` de `agency.txt`.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Se o `feed_publisher_url` estiver preenchido, tem de ser um endereço web bem escrito, a começar por `http://` ou `https://`. Um campo vazio é aceite. A regra **não verifica se a página existe**, só o formato.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `feed_publisher_url` está vazio? | ✅ Passa | Segue para o passo 2 |
| 2 | O texto é um endereço web válido, com `http` ou `https`, sem espaços nem carateres proibidos, e com nome de site? | ✅ Passa | ❌ Reporta o problema: URL inválido |

Os espaços no início e no fim são ignorados.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://www.operador.pt` | ✅ Passa | Formato correto |
| *(vazio)* | ✅ Passa | Campo opcional |
| `www.operador.pt` | ❌ Problema | Falta `http://` ou `https://` |
| `ftp://operador.pt` | ❌ Problema | Só são aceites `http` e `https` |
| `https://operador .pt` | ❌ Problema | Tem um espaço |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| URL inválido | Falta `http://` ou `https://`, há espaços ou carateres proibidos | Escrever o `feed_publisher_url` em `feed_info.txt` como endereço completo, por exemplo `https://www.operador.pt` |
