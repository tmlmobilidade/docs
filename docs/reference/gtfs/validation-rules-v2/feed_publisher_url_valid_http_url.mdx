title: Página web da entidade publicadora
description: Verifica se o endereço da página web da entidade que publica o conjunto de dados, em feed_info.txt, é um URL http ou https bem escrito.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_publisher_url_valid_http_url` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_publisher_url` |
| Tipo | URL |
| Severidade | Opcional |

**Descrição do campo:** endereço da página web da organização que publica o conjunto de dados. Pode ser igual a um dos valores de `agency_url` em `agency.txt`.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Quando a regra passa, o `feed_publisher_url` é um endereço completo que começa por `http://` ou `https://` e indica um domínio. A regra **não confirma que a página existe** nem que abre, só que o endereço está bem escrito.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | O valor é um endereço `http` ou `https` completo e sem carateres proibidos? | ✅ Passa | ❌ Reporta o problema: URL inválido |

Os espaços no início e no fim são ignorados. Espaços no meio, aspas e os carateres `<`, `>`, `{`, `}`, `|`, `\` e `^` tornam o endereço inválido.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://www.operador.pt` | ✅ Passa | Endereço completo |
| `www.operador.pt` | ❌ Problema | Falta `https://` |
| `ftp://operador.pt` | ❌ Problema | Só `http` ou `https` |
| `https://operador.pt/dados abertos` | ❌ Problema | Espaço no meio |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| URL inválido | Falta `https://`, protocolo diferente de `http`/`https` ou carateres proibidos | Escrever no `feed_publisher_url` do `feed_info.txt` o endereço completo, por exemplo `https://www.operador.pt`, e trocar os espaços por `%20` |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `feed_publisher_url` do `feed_info.txt` com o endereço da página web da entidade publicadora |
