---
title: Máximo de duas formas por linha
description: Verifica se cada `route_id` usa, no máximo, dois valores distintos de `shape_id`.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_shape_id_max_two_per_route` |
| Ficheiro | `trips.txt` |
| Campos | `route_id`, `shape_id` |
| Tipo | Identificador, Identificador |
| Severidade | Condicional |

**Descrição dos campos:**

- `route_id`: identifica a linha que agrupa as viagens.
- `shape_id`: identifica a forma geográfica da viagem.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Uma linha pode usar zero, uma ou duas formas distintas. Com três ou mais formas, a regra reporta o problema. Valores vazios de `shape_id` são ignorados.  A regra não valida os valores individualmente.

A regra avalia cada grupo de viagens com o mesmo `route_id`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O grupo tem viagens? | Segue para o passo 2 | ✅ Passa |
| 2 | Existem mais de dois `shape_id` distintos e não vazios? | Segue para o passo 3 | ✅ Passa |
| 3 | A configuração da regra desativa a validação? | ✅ Passa | ❌ Reporta o problema na primeira viagem com forma |

## Como se relacionam

`route_id` define a linha. A regra conta todos os `shape_id` não vazios usados pelas viagens dessa linha, independentemente do sentido.

## Exemplos

| `route_id` | Formas | Resultado | Porquê |
|---|---|---|---|
| `R1` | `S1` | ✅ Passa | Uma forma |
| `R1` | `S1, S2` | ✅ Passa | Duas formas |
| `R1` | `S1, S2, S3` | ❌ Problema | Três formas distintas |
| `R1` | `S1, vazio` | ✅ Passa | O vazio é ignorado |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Mais de duas formas na linha | As viagens do mesmo `route_id` usam pelo menos três `shape_id` | Corrigir `shape_id` ou `route_id` nas linhas afetadas de `trips.txt` |
