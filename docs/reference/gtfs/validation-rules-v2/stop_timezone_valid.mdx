---
title: Fuso horário da paragem
description: Verifica se o stop_timezone de stops.txt, quando preenchido, é um fuso horário válido.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `stop_timezone_valid` |
| Ficheiro | `stops.txt` |
| Campo | `stop_timezone` |
| Tipo | Fuso horário |
| Severidade | Opcional |

**Descrição do campo:** fuso horário do local. Se o local tiver estação, herda o fuso da estação. As estações e paragens sem estação e sem `stop_timezone` usam o `agency_timezone` de `agency.txt`. As horas de `stop_times.txt` usam sempre o `agency_timezone`.

Mais informação em [stops.txt](/reference/gtfs/schedule/stops).

## Como funciona

Se o `stop_timezone` estiver preenchido, tem de ser um fuso horário reconhecido, por exemplo `Europe/Lisbon`. Um campo vazio é aceite, salvo se a configuração da regra o exigir ou recomendar. A regra **não verifica se o fuso faz sentido para a localização da paragem**.

A regra avalia cada linha do `stops.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `stop_timezone` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O `stop_timezone` é um fuso horário reconhecido, como `Europe/Lisbon`? | Segue para o passo 4 | ❌ Reporta o problema: fuso horário inválido |
| 4 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `Europe/Lisbon` | ✅ Passa | Fuso horário válido |
| `Lisboa` | ❌ Problema | Não é um fuso horário reconhecido |
| *(vazio)* | ✅ Passa | Campo opcional |
| *(vazio)* com campo exigido na configuração | ❌ Problema | A configuração da regra exige o campo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Fuso horário inválido | O valor é um nome de cidade, uma sigla ou tem erro de escrita | Escrever o `stop_timezone` em `stops.txt` no formato Continente/Cidade, por exemplo `Europe/Lisbon` |
| Valor não permitido | O valor não está na lista da configuração da regra | Usar um valor da lista permitida, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `stop_timezone` em `stops.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `stop_timezone` em `stops.txt` |
