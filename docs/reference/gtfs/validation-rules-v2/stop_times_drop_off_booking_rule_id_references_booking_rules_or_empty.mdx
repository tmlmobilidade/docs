---
title: Regra de reserva para desembarque
description: Verifica se `drop_off_booking_rule_id` referencia uma regra existente em booking_rules.txt.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `stop_times_drop_off_booking_rule_id_references_booking_rules_or_empty` |
| Ficheiros | `stop_times.txt`, `booking_rules.txt` |
| Campo | `drop_off_booking_rule_id` |
| Tipo | Identificador externo |
| Severidade | Opcional |

**Descrição do campo:** identifica a regra de reserva aplicável ao desembarque nesta paragem. É recomendada quando `drop_off_type=2`.

Mais informação em [stop_times.txt](/reference/gtfs/schedule/stop_times) e [booking_rules.txt](/reference/gtfs/schedule/booking_rules).

## Como funciona

Quando existe, o identificador tem de corresponder a um `booking_rule_id` de `booking_rules.txt`. A implementação não verifica a relação com o tipo de serviço nem aplica uma lista de valores permitidos.

A regra avalia cada linha do `stop_times.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração exige ou recomenda o campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração proíbe o campo? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O identificador existe em `booking_rules.txt`? | ✅ Passa | ❌ Reporta o problema: regra inexistente |


## Como se relacionam

`drop_off_booking_rule_id` de `stop_times.txt` referencia `booking_rule_id` de `booking_rules.txt`. A recomendação associada a `drop_off_type=2` não é imposta pela implementação.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `RES_1`, existente em `booking_rules.txt` | ✅ Passa | Referência encontrada |
| `RES_9`, inexistente | ❌ Problema | Referência inexistente |
| `RES_1` (campo proibido) | ❌ Problema | A configuração proíbe o campo |


## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração exige ou recomenda `drop_off_booking_rule_id` | Preencher `drop_off_booking_rule_id` em `stop_times.txt` |
| Campo preenchido quando não devia | A configuração proíbe `drop_off_booking_rule_id` | Remover `drop_off_booking_rule_id` de `stop_times.txt` |
| Regra inexistente | O identificador não existe em `booking_rules.txt` | Corrigir `drop_off_booking_rule_id` em `stop_times.txt` ou adicionar a regra a `booking_rules.txt` |
