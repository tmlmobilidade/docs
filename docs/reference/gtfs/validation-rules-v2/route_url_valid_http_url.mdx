---
title: Página web da linha
description: Verifica se o route_url de routes.txt, quando preenchido, é um endereço web http ou https bem escrito e diferente do agency_url.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `route_url_valid_http_url` |
| Ficheiros | `routes.txt`, `agency.txt` |
| Campo | `route_url` |
| Tipo | URL |
| Severidade | Opcional |

**Descrição do campo:** endereço de uma página web sobre a linha. Deve ser diferente do `agency_url` do operador.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes) e [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

Se o `route_url` estiver preenchido, tem de ser um endereço web bem escrito, a começar por `http://` ou `https://`, e não deve ser igual ao `agency_url` do operador da linha. Um campo vazio é aceite, salvo se a configuração da regra o exigir ou recomendar. A regra **não verifica se a página existe**.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `route_url` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O texto é um endereço web válido, com `http` ou `https`, sem espaços nem carateres proibidos, e com nome de site? | Segue para o passo 4 | ❌ Reporta o problema: URL inválido |
| 4 | A linha tem `agency_id` e o `route_url` é igual ao `agency_url` desse operador em `agency.txt`? | ❌ Reporta o problema, como aviso: igual ao `agency_url`. Segue para o passo 5 | Segue para o passo 5 |
| 5 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 6 | ✅ Passa |
| 6 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

Os espaços no início e no fim são ignorados na verificação do formato.

## Como se relacionam

O `agency_id` da linha liga-a a um operador de `agency.txt`. O `route_url` é comparado com o `agency_url` desse operador.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://www.operador.pt/linha32` | ✅ Passa | Formato correto |
| *(vazio)* | ✅ Passa | Campo opcional |
| `www.operador.pt/linha32` | ❌ Problema | Falta `http://` ou `https://` |
| Igual ao `agency_url` | ❌ Problema | Repete o site do operador (aviso) |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| URL inválido | Falta `http://` ou `https://`, há espaços ou carateres proibidos | Escrever o `route_url` em `routes.txt` como endereço completo, por exemplo `https://www.operador.pt/linha32` |
| Igual ao `agency_url` | O `route_url` repete o site do operador | Em `routes.txt`, indicar uma página específica da linha, ou deixar o `route_url` vazio |
| Valor não permitido | O valor não está na lista da configuração da regra | Usar um valor da lista permitida, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `route_url` em `routes.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `route_url` em `routes.txt` |
