title: URL da rota

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `route_url_valid_http_url` |
| Ficheiro | `routes.txt` |
| Campo | `route_url` |
| Tipo | URL |
| Severidade | Opcional |

**Descrição do campo:** URL de uma página na internet com informação sobre esta rota. Deve ser diferente do `agency_url` do operador, em `agency.txt`.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Se a rota tiver um `route_url`, o valor tem de ter o formato de um endereço web válido e não pode repetir o `agency_url` do operador. Se a configuração da regra tiver uma lista de URLs permitidos, o endereço também tem de constar dessa lista. A regra **não confirma que a página existe**, só que o formato está correto e que não repete o `agency_url`.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O texto é um URL válido, com `http://` ou `https://` e um anfitrião, sem espaços nem carateres inválidos? | Segue para o passo 4 | ❌ Reporta o problema: formato inválido |
| 4 | A rota tem um `agency_id` preenchido? | Segue para o passo 5 | Segue para o passo 7 |
| 5 | Há mais do que uma linha em `agency.txt` com esse `agency_id`? | ❌ Reporta o problema: não foi possível comparar com o `agency_url` | Segue para o passo 6 |
| 6 | O URL é igual ao `agency_url` do operador correspondente, em `agency.txt`? | ❌ Reporta o problema | Segue para o passo 7 |
| 7 | A configuração da regra tem uma lista de URLs permitidos? | Segue para o passo 8 | ✅ Passa |
| 8 | O URL está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: URL não permitido |

Os espaços no início e no fim do valor são ignorados.

## Como se relacionam

`route_url` é comparado com o `agency_url` do operador identificado pelo `agency_id` da rota, em `agency.txt`: os dois não podem ser iguais. Quando a rota não tem `agency_id` preenchido, esta comparação não é feita e a regra segue diretamente para a lista de valores permitidos.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://www.operador.pt/linha-10` (`agency_url` do operador é diferente) | ✅ Passa | URL válido e diferente do `agency_url` |
| `www.operador.pt/linha-10` | ❌ Problema | Falta o `http://` ou `https://` |
| `https://` | ❌ Problema | Falta o anfitrião |
| `https://www.operador.pt` (igual ao `agency_url` do operador) | ❌ Problema | Repete o `agency_url` do operador |
| `https://outro-site.pt/pagina` (fora da lista de URLs permitidos) | ❌ Problema | URL válido, mas fora da lista permitida |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `route_url` com o URL da página da rota, em `routes.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `route_url` em `routes.txt` |
| Formato inválido | Falta o esquema `http://`/`https://`, o anfitrião, ou o texto tem espaços ou carateres não permitidos | Corrigir `route_url` em `routes.txt` para um endereço completo, por exemplo `https://www.operador.pt/linha-10` |
| Não foi possível comparar com o `agency_url` | Há mais do que uma linha em `agency.txt` com o mesmo `agency_id` desta rota | Corrigir `agency.txt` para existir apenas uma linha por `agency_id` |
| Igual ao `agency_url` do operador | `route_url` tem exatamente o mesmo valor de `agency_url` em `agency.txt` | Definir em `route_url`, no `routes.txt`, um endereço específico desta rota, diferente do `agency_url` |
| URL não permitido | O endereço é válido mas não consta da lista de URLs permitidos na configuração da regra | Usar um URL da lista, ou pedir ao administrador que o adicione à configuração |
