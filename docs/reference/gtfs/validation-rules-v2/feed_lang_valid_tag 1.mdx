title: Idioma do conjunto de dados
description: Verifica se o idioma indicado em feed_info.txt é um código de idioma válido ou o valor mul.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_lang_valid_tag` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_lang` |
| Tipo | Código de idioma |
| Severidade | Obrigatório |

**Descrição do campo:** idioma principal usado nos textos do conjunto de dados. Ajuda quem consome os dados a escolher regras de maiúsculas e outras definições próprias do idioma. Quando os textos originais estão em vários idiomas, o valor deve ser `mul` e o `translations.txt` deve ter uma tradução para cada idioma usado. Se todos os textos estão no mesmo idioma, não se deve usar `mul`.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Quando a regra passa, o `feed_lang` está preenchido e é `mul` ou um código de idioma reconhecido. A regra **não verifica se os textos do conjunto de dados estão realmente nesse idioma**. Também não verifica se `mul` faz sentido nem se existem traduções.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ❌ Reporta o problema: campo obrigatório | Segue para o passo 2 |
| 2 | O valor é `mul`? | ✅ Aceita | Segue para o passo 3 |
| 3 | O valor é um código de idioma reconhecido? | ✅ Aceita | ❌ Reporta o problema: código de idioma inválido |

Só são reconhecidos códigos de duas letras, como `pt` ou `en`. Maiúsculas e minúsculas são tratadas da mesma forma. Códigos com região, como `pt-PT`, não são reconhecidos.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `pt` | ✅ Passa | Código de idioma reconhecido |
| `mul` | ✅ Passa | Valor especial para vários idiomas |
| `PT` | ✅ Passa | Maiúsculas são aceites |
| Vazio | ❌ Problema | O campo é obrigatório |
| `portugues` | ❌ Problema | Não é um código de idioma reconhecido |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| O campo `feed_lang` é obrigatório | O campo está vazio, ou a coluna não tem valor nesta linha | Preencher `feed_lang` no `feed_info.txt` com o código do idioma, por exemplo `pt` |
| O campo `feed_lang` não é um código de idioma válido | O valor tem erro de escrita, é o nome do idioma por extenso ou inclui região | Substituir `feed_lang` no `feed_info.txt` por um código de duas letras, por exemplo `pt`, ou por `mul` se os textos estiverem em vários idiomas |
