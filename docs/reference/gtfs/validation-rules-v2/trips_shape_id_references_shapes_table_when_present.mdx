## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_shape_id_references_shapes_table_when_present` |
| Ficheiro | `trips.txt` |
| Campo | `shape_id` |
| Tipo | Chave estrangeira para `shapes.shape_id` |
| Severidade | Obrigatório |

**Descrição do campo:** identifica o traçado geográfico que representa o percurso do veículo durante a viagem.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

A regra garante que cada viagem está associada a um traçado que existe em `shapes.txt`. A regra **não verifica** se o traçado corresponde de facto às paragens da viagem, só se o `shape_id` indicado existe.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo `shape_id` está vazio? | ❌ Reporta o problema: campo em falta | Segue para o passo 2 |
| 2 | O valor de `shape_id` existe em `shapes.txt`? | ✅ Passa | ❌ Reporta o problema: forma não encontrada |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `SHP1` (existe em `shapes.txt`) | ✅ Passa | O `shape_id` corresponde a uma forma existente |
| (vazio) | ❌ Problema | O campo `shape_id` é obrigatório |
| `SHP99` (não existe em `shapes.txt`) | ❌ Problema | Não há nenhuma forma com este `shape_id` |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | O campo `shape_id` não foi preenchido em `trips.txt` | Preencher `shape_id` com o identificador de uma forma existente |
| Forma não encontrada | O `shape_id` indicado em `trips.txt` não existe em `shapes.txt`, por exemplo por erro de digitação ou porque a forma foi removida | Corrigir o `shape_id` em `trips.txt` para o identificador correto, ou adicionar a forma correspondente em `shapes.txt` |
