---
title: Índice não negativo do piso
description: Verifica se level_index está preenchido e tem um valor numérico igual ou superior a zero.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `level_index_required` |
| Ficheiro | `levels.txt` |
| Campo | `level_index` |
| Tipo | Número decimal não negativo |
| Severidade | Obrigatório |

**Descrição do campo:** índice numérico que indica a posição relativa do piso. Um índice superior representa um piso acima de outro com índice inferior.

Mais informação em [levels.txt](/reference/gtfs/schedule/levels).

## Como funciona

Quando a regra passa, `level_index` está preenchido e tem um valor numérico igual ou superior a zero. A regra aceita valores decimais. A regra **não confirma se a ordem dos índices corresponde à disposição real dos pisos**.

A regra avalia cada linha do `levels.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é inferior a zero? | ❌ Reporta o problema: valor negativo | ✅ Passa |

O valor não é arredondado. Um valor que não possa ser lido como número é reportado pela validação de leitura de `levels.txt`, antes desta regra. Uma linha com todos os campos vazios é ignorada.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `0.5` | ✅ Passa | Os valores decimais não negativos são aceites |
| `-1` | ❌ Problema | O valor é negativo |
| vazio | ❌ Problema | Falta um campo obrigatório |
| `0` com o campo proibido | ❌ Problema | A configuração proíbe o campo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor negativo | `level_index` é inferior a zero | Corrigir `level_index` em `levels.txt` para um número igual ou superior a zero |
| Campo em falta | A configuração da regra exige ou recomenda `level_index` | Preencher `level_index` em `levels.txt` com um número igual ou superior a zero |
| Campo preenchido quando não devia | A configuração da regra proíbe `level_index` | Remover o valor de `level_index` em `levels.txt` ou rever a configuração da regra |
