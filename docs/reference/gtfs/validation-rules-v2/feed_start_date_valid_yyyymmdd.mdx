title: Data de início do conjunto de dados
description: Verifica se a data de início do período coberto pelo conjunto de dados está preenchida em feed_info.txt e é uma data real no formato AAAAMMDD.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_start_date_valid_yyyymmdd` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_start_date` |
| Tipo | Data |
| Severidade | Obrigatório |

**Descrição do campo:** primeiro dia do período em que o conjunto de dados tem horários completos e fiáveis. O período vai do início do dia `feed_start_date` até ao fim do dia `feed_end_date`. Se o período se estender para lá das datas ativas de `calendar.txt` e `calendar_dates.txt`, o conjunto de dados afirma que não há serviço nesses dias.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Quando a regra passa, o `feed_start_date` tem uma data real escrita com 8 algarismos, no formato AAAAMMDD. A regra **não compara esta data com o `feed_end_date`** nem com as datas de `calendar.txt` e `calendar_dates.txt`.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ❌ Reporta o problema: campo em falta | Segue para o passo 2 |
| 2 | O valor tem 8 carateres e é uma data real no formato AAAAMMDD? | ✅ Passa | ❌ Reporta o problema: data inválida |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `20260101` | ✅ Passa | Data real no formato AAAAMMDD |
| vazio | ❌ Problema | Campo obrigatório |
| `2026-01-01` | ❌ Problema | Tem hífenes |
| `20260230` | ❌ Problema | 30 de fevereiro não existe |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Data inválida | Data com separadores, dia ou mês trocados ou dia que não existe | Escrever no `feed_start_date` do `feed_info.txt` a data com 8 algarismos, ano, mês e dia, por exemplo `20260101` |
| Campo em falta | O campo está vazio | Preencher o `feed_start_date` do `feed_info.txt` com o primeiro dia coberto pelo conjunto de dados |
