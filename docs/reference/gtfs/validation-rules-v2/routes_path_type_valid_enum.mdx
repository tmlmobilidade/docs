title: Tipo de percurso da rota
description: Verifica se o path_type de routes.txt, quando configurado, consta da lista de valores permitidos.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `routes_path_type_valid_enum` |
| Ficheiro | `routes.txt` |
| Campo | `path_type` |
| Tipo | Enumeração |
| Severidade | Opcional |

**Descrição do campo:** campo específico da TML que indica o tipo de percurso da rota. Os valores previstos são `1` (primeiro tipo de percurso), `2` (segundo tipo de percurso) e `3` (terceiro tipo de percurso). É uma extensão da TML ao GTFS.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Quando a regra passa, o `path_type` está vazio ou, se a configuração da regra tiver uma lista de valores permitidos, consta dessa lista. A regra **não verifica se o valor é `1`, `2` ou `3`**. Só aplica a lista da configuração da regra.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 4 | ✅ Passa |
| 4 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `1` | ✅ Passa | Valor previsto |
| `3` (lista permitida = `1`, `2`, `3`) | ✅ Passa | Valor na lista |
| `2` (lista permitida = `1`) | ❌ Problema | Valor fora da lista |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor não permitido | O valor está fora da lista de valores permitidos da configuração da regra | Usar um valor da lista em `path_type` em `routes.txt`, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `path_type` em `routes.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `path_type` em `routes.txt` |
