## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `routes_path_type_valid_enum` |
| Ficheiro | `routes.txt` |
| Campo | `path_type` |
| Tipo | Enumeração (`1`, `2` ou `3`) |
| Severidade | Opcional |

**Descrição do campo:** campo específico da TML que indica o tipo de percurso de uma rota. Não faz parte da norma GTFS. Os valores possíveis são `1` (primeiro tipo de percurso), `2` (segundo tipo de percurso) e `3` (terceiro tipo de percurso).

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Quando o campo `path_type` está preenchido, o valor tem de constar da lista de valores permitidos definida na configuração da regra. A regra não verifica o significado do percurso, só se o valor está entre os permitidos.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo `path_type` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 4 | ✅ Passa |
| 4 | O valor está na lista (ou a lista aceita qualquer valor)? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| `path_type` | Resultado | Porquê |
|---|---|---|
| `1` (lista permitida = `1`, `2`, `3`) | ✅ Passa | Valor permitido |
| `9` (lista permitida = `1`, `2`, `3`) | ❌ Problema | Valor fora da lista permitida |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor não permitido | O valor preenchido não consta da lista de valores permitidos configurada para a regra | Preencher `path_type` em `routes.txt` com um valor permitido, por exemplo `1` |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `path_type` em `routes.txt` com um valor válido (`1`, `2` ou `3`) |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `path_type` em `routes.txt` |
