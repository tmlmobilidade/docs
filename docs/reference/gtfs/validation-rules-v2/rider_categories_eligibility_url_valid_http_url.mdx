title: Página de elegibilidade da categoria
description: Verifica se o eligibility_url de rider_categories.txt, quando preenchido, é um endereço web http ou https bem escrito.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `rider_categories_eligibility_url_valid_http_url` |
| Ficheiro | `rider_categories.txt` |
| Campo | `eligibility_url` |
| Tipo | URL |
| Severidade | Opcional |

**Descrição do campo:** endereço de uma página web, normalmente do operador, com informação detalhada sobre a categoria de passageiro ou os critérios para a ela pertencer.

Mais informação em [rider_categories.txt](/reference/gtfs/schedule/rider_categories).

## Como funciona

Se o `eligibility_url` estiver preenchido, tem de ser um endereço web bem escrito, a começar por `http://` ou `https://`. Um campo vazio é sempre aceite. A regra **não verifica se a página existe**, só o formato.

A regra avalia cada linha do `rider_categories.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `eligibility_url` está vazio? | ✅ Passa | Segue para o passo 2 |
| 2 | O texto é um endereço web válido, com `http` ou `https`, sem espaços nem carateres proibidos, e com nome de site? | ✅ Passa | ❌ Reporta o problema: URL inválido |

Os espaços no início e no fim são ignorados.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://www.operador.pt/jovem` | ✅ Passa | Formato correto |
| *(vazio)* | ✅ Passa | Campo opcional |
| `www.operador.pt/jovem` | ❌ Problema | Falta `http://` ou `https://` |
| `https://operador .pt` | ❌ Problema | Tem um espaço |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| URL inválido | Falta `http://` ou `https://`, há espaços ou carateres proibidos | Escrever o `eligibility_url` em `rider_categories.txt` como endereço completo, por exemplo `https://www.operador.pt/jovem` |
