## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `pathway_stair_count` |
| Ficheiro | `pathways.txt` |
| Campo | `stair_count` |
| Tipo | Número inteiro |
| Severidade | Opcional |

**Descrição do campo:** número de degraus do percurso.

Mais informação em [pathways.txt](/reference/gtfs/schedule/pathways).

## Como funciona

O `stair_count` é opcional. Um campo vazio é aceite, salvo se a configuração da regra o exigir ou recomendar. A regra **não verifica o valor**. Só verifica se está preenchido ou proibido. Um valor que não seja um número inteiro é tratado pela regra `pathways_values_parse`.

A regra avalia cada linha do `pathways.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `stair_count` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | ✅ Passa |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `24` | ✅ Passa | Preenchido |
| *(vazio)* | ✅ Passa | Campo opcional |
| *(vazio)* com campo exigido na configuração | ❌ Problema | A configuração da regra exige o campo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `stair_count` em `pathways.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `stair_count` em `pathways.txt` |
