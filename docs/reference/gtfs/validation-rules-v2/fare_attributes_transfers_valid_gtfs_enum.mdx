---
title: Número de transbordos permitidos
description: Verifica se o número de transbordos está vazio ou indica zero, um ou dois transbordos permitidos.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `fare_attributes_transfers_valid_gtfs_enum` |
| Ficheiro | `fare_attributes.txt` |
| Campo | `transfers` |
| Tipo | Enumeração |
| Severidade | Obrigatório |

**Descrição do campo:** indica o número de transbordos permitidos pela tarifa. O valor `0` não permite transbordos, `1` permite um e `2` permite dois. Um valor vazio permite transbordos ilimitados.

Mais informação em [fare_attributes.txt](/reference/gtfs/schedule/fare_attributes).

## Como funciona

Quando a regra passa, `transfers` está vazio ou tem o valor `0`, `1` ou `2`. Apesar da severidade indicada, a implementação atual aceita o campo vazio. A regra **não verifica a duração dos transbordos nem aplica a configuração de campo proibido**.

A regra avalia cada linha do `fare_attributes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ✅ Passa | Segue para o passo 2 |
| 2 | O valor é `0`, `1` ou `2`? | ✅ Passa | ❌ Reporta o problema: número de transbordos inválido |

O valor é interpretado como número inteiro antes desta regra. Os espaços não são removidos antes dessa interpretação.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `1` | ✅ Passa | Permite um transbordo |
| campo vazio | ✅ Passa | Permite transbordos ilimitados |
| `3` | ❌ Problema | Valor não previsto |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Número de transbordos inválido | O valor é diferente de `0`, `1` e `2` | Alterar `transfers` em `fare_attributes.txt` para `0`, `1`, `2` ou deixar o campo vazio |
