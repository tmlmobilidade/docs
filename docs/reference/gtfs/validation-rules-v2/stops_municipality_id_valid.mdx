title: Município da paragem
description: Verifica se o municipality_id de stops.txt, quando preenchido, cumpre a configuração da regra.

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `stops_municipality_id_valid` |
| Ficheiro | `stops.txt` |
| Campo | `municipality_id` |
| Tipo | ID |
| Severidade | Opcional |

**Descrição do campo:** identificador do município da paragem. Este campo é uma extensão da TML ao GTFS.

Mais informação em [stops.txt](/reference/gtfs/schedule/stops).

## Como funciona

O `municipality_id` é opcional. Um campo vazio é aceite, salvo se a configuração da regra o exigir ou recomendar. A regra **não verifica o conteúdo do texto**. Aceita qualquer texto preenchido.

A regra avalia cada linha do `stops.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `municipality_id` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 4 | ✅ Passa |
| 4 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `Exemplo` | ✅ Passa | Preenchido |
| *(vazio)* | ✅ Passa | Campo opcional |
| *(vazio)* com campo exigido na configuração | ❌ Problema | A configuração da regra exige o campo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|

| Valor não permitido | O valor não está na lista da configuração da regra | Usar um valor da lista permitida, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `municipality_id` em `stops.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `municipality_id` em `stops.txt` |
