---
title: Ficheiro de informação do conjunto de dados em falta
description: Verifica se o ficheiro feed_info.txt está presente quando a configuração da regra o exige ou recomenda, ou quando existem traduções em translations.txt.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_info_file_missing` |
| Ficheiros | `feed_info.txt`, `translations.txt` |
| Campo | Se aplica em todo o ficheiro |
| Tipo | Presença do ficheiro |
| Severidade | Condicional (obrigatório quando existe `translations.txt`, recomendado nos outros casos) |

## Como funciona

Quando a regra passa, o `feed_info.txt` existe ou a configuração da regra não o exige nem o recomenda. Se o conjunto de dados tem traduções, o ficheiro também tem de ter linhas. A regra **não verifica o conteúdo do `feed_info.txt`**. Só verifica se ele existe e, no caso das traduções, se tem linhas.

A regra avalia o ficheiro `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `feed_info.txt` existe no conjunto de dados? | Segue para o passo 4 | Segue para o passo 2 |
| 2 | A configuração da regra define o ficheiro como **obrigatório**? | ❌ Reporta o problema: ficheiro obrigatório | Segue para o passo 3 |
| 3 | A configuração da regra define o ficheiro como **recomendado**? | ❌ Reporta o problema: ficheiro recomendado | Segue para o passo 4 |
| 4 | O `translations.txt` tem pelo menos uma linha? | Segue para o passo 5 | ✅ Aceita |
| 5 | O `feed_info.txt` tem pelo menos uma linha? | ✅ Aceita | Segue para o passo 6 |
| 6 | A configuração da regra define o ficheiro como **obrigatório** ou **recomendado**? | ❌ Reporta o problema: ficheiro obrigatório por haver traduções | ✅ Aceita |

O problema é reportado uma só vez por ficheiro. Se a configuração da regra definir o ficheiro como **proibido** ou o ignorar, esta regra não reporta nada.

## Como se relacionam

O `translations.txt` traduz textos do conjunto de dados. Para isso, o `feed_info.txt` tem de indicar a língua do conjunto de dados. Por isso, se existem traduções, o `feed_info.txt` tem de estar presente e ter linhas.

## Exemplos

| Situação | Resultado | Porquê |
|---|---|---|
| `feed_info.txt` existe e tem linhas | ✅ Passa | O ficheiro está presente |
| Sem `feed_info.txt` nem `translations.txt`, e a configuração da regra não o exige | ✅ Passa | Ficheiro não exigido |
| Sem `feed_info.txt`, e a configuração da regra o recomenda | ❌ Problema | Falta um ficheiro recomendado |
| Sem `feed_info.txt`, e a configuração da regra o exige | ❌ Problema | Falta um ficheiro obrigatório |
| `translations.txt` com linhas e `feed_info.txt` sem linhas | ❌ Problema | Há traduções sem informação do conjunto de dados |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| O ficheiro `feed_info.txt` é obrigatório | O ficheiro não foi incluído no conjunto de dados | Adicionar o `feed_info.txt` ao conjunto de dados |
| O ficheiro `feed_info.txt` é recomendado | O ficheiro não foi incluído no conjunto de dados | Adicionar o `feed_info.txt` ao conjunto de dados. Se não se aplica, pedir à equipa responsável que ajuste a configuração da regra |
| `feed_info.txt` é obrigatório quando `translations.txt` está presente | O `translations.txt` tem linhas, mas o `feed_info.txt` falta ou está vazio | Adicionar o `feed_info.txt` com pelo menos uma linha, ou remover o `translations.txt` se as traduções não são necessárias |
