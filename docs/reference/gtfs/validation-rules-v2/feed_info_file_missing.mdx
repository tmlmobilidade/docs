---
title: Ficheiro feed_info.txt em falta
description: Verifica se o ficheiro feed_info.txt existe quando a configuração da regra o exige ou recomenda, ou quando o conjunto de dados tem traduções.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_info_file_missing` |
| Ficheiros | `feed_info.txt`, `translations.txt` |
| Campo | Se aplica em todo o ficheiro |
| Tipo | Ficheiro |
| Severidade | Condicional (obrigatório quando existe `translations.txt`) |

## Como funciona

Quando a regra passa, o `feed_info.txt` existe, ou a configuração da regra não o exige nem recomenda. A regra **não verifica o conteúdo do ficheiro**: os campos são avaliados pelas outras regras do `feed_info.txt`. Um `feed_info.txt` proibido pela configuração da regra é reportado por outra regra.

A regra avalia o conjunto de dados uma vez, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `feed_info.txt` existe? | Segue para o passo 3 | Segue para o passo 2 |
| 2 | A configuração da regra define o ficheiro como obrigatório ou recomendado? | ❌ Reporta o problema: ficheiro em falta | ✅ Passa |
| 3 | O `translations.txt` tem linhas e o `feed_info.txt` não tem nenhuma? | Segue para o passo 4 | ✅ Passa |
| 4 | A configuração da regra define o ficheiro como obrigatório ou recomendado? | ❌ Reporta o problema: ficheiro obrigatório com traduções | ✅ Passa |

O problema é reportado no máximo uma vez por conjunto de dados.

## Como se relacionam

O `feed_info.txt` indica o idioma predefinido dos textos. O `translations.txt` traduz esses textos para outros idiomas. Por isso, quando o `translations.txt` tem linhas, o `feed_info.txt` também tem de ter pelo menos uma linha.

## Exemplos

| `feed_info.txt` | `translations.txt` | Resultado | Porquê |
|---|---|---|---|
| Existe, com uma linha | Qualquer | ✅ Passa | Ficheiro presente |
| Não existe (configuração da regra não o exige) | Não existe | ✅ Passa | Ficheiro opcional |
| Não existe (configuração da regra exige o ficheiro) | Não existe | ❌ Problema | Ficheiro obrigatório em falta |
| Existe, sem linhas (configuração da regra recomenda o ficheiro) | Com linhas | ❌ Problema | Há traduções sem `feed_info.txt` preenchido |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Ficheiro obrigatório em falta | A configuração da regra exige o `feed_info.txt` e o ficheiro não foi incluído | Adicionar o `feed_info.txt` ao conjunto de dados, com pelo menos `feed_publisher_name`, `feed_publisher_url` e `feed_lang` |
| Ficheiro recomendado em falta | A configuração da regra recomenda o `feed_info.txt` e o ficheiro não foi incluído | Adicionar o `feed_info.txt` ao conjunto de dados |
| Ficheiro obrigatório com traduções | O `translations.txt` tem linhas, mas o `feed_info.txt` falta ou está vazio | Adicionar ao `feed_info.txt` uma linha com o `feed_lang` preenchido, ou remover o `translations.txt` |
