title: Idioma predefinido para o passageiro
description: Verifica se o idioma predefinido indicado em feed_info.txt é um código de idioma válido.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_info_default_lang_matches_feed_lang_when_present` |
| Ficheiro | `feed_info.txt` |
| Campo | `default_lang` |
| Tipo | Código de idioma |
| Severidade | Opcional |

**Descrição do campo:** idioma a usar quando a aplicação não conhece o idioma do passageiro. Muitas vezes é `en` (inglês).

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Quando a regra passa, o `default_lang` tem um código de idioma de duas letras reconhecido. A regra só é avaliada quando o `feed_lang` passa na respetiva regra. A regra **não compara o `default_lang` com o `feed_lang`** e não aceita o valor `mul` nem códigos com região, como `pt-PT`.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | O valor é um código de idioma de duas letras reconhecido? | ✅ Passa | ❌ Reporta o problema: código de idioma inválido |

Maiúsculas e minúsculas são equivalentes: `EN` e `en` são aceites da mesma forma.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `en` | ✅ Passa | Código de duas letras válido |
| `en-GB` | ❌ Problema | Código com região não aceite |
| `mul` | ❌ Problema | `mul` não é aceite neste campo |
| `inglês` | ❌ Problema | Nome do idioma em vez do código |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Código de idioma inválido | Nome do idioma por extenso, código com região ou `mul` | Escrever no `default_lang` do `feed_info.txt` um código de duas letras, por exemplo `en` |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `default_lang` do `feed_info.txt` com o código do idioma a mostrar por omissão |
