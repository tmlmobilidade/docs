description: Verifica se o feed_lang de feed_info.txt está preenchido com um código de idioma válido ou com mul.

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_lang_valid_tag` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_lang` |
| Tipo | Código de idioma |
| Severidade | Obrigatório |

**Descrição do campo:** idioma principal dos textos do conjunto de dados. Ajuda as aplicações a escolher regras de maiúsculas e outras definições próprias do idioma. Quando os textos originais estão em vários idiomas, usa-se `mul` e as traduções vão para o `translations.txt`.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Cada linha do `feed_info.txt` tem de ter um `feed_lang` preenchido com `mul` ou com um código de idioma de duas letras, como `pt`. A regra **não verifica se os textos do conjunto de dados estão mesmo nesse idioma**. Só verifica se o código existe.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `feed_lang` está vazio? | ❌ Reporta o problema: `feed_lang` obrigatório | Segue para o passo 2 |
| 2 | O `feed_lang` é `mul`? | ✅ Passa | Segue para o passo 3 |
| 3 | O `feed_lang` é um código de idioma de duas letras válido? | ✅ Passa | ❌ Reporta o problema: código de idioma inválido |

Maiúsculas e minúsculas são tratadas da mesma forma, exceto em `mul`, que tem de ser escrito em minúsculas.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `pt` | ✅ Passa | Código de idioma válido |
| `mul` | ✅ Passa | Vários idiomas |
| `português` | ❌ Problema | Nome do idioma, em vez do código |
| `pt-PT` | ❌ Problema | Só são aceites códigos de duas letras |
| *(vazio)* | ❌ Problema | Falta o idioma |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| `feed_lang` obrigatório | A linha não tem `feed_lang` | Preencher o `feed_lang` em `feed_info.txt`, por exemplo `pt` |
| Código de idioma inválido | O valor é um nome, um código com região ou um código que não existe | Escrever o `feed_lang` em `feed_info.txt` com um código de duas letras, por exemplo `pt`, ou `mul` para vários idiomas |
