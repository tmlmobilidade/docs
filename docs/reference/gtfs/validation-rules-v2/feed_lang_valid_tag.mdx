## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_lang_valid_tag` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_lang` |
| Tipo | Código de idioma |
| Severidade | Opcional |

**Descrição do campo:** idioma predefinido dos textos do conjunto de dados. Ajuda as aplicações a escolher regras de maiúsculas e outras definições próprias do idioma. Se os textos originais estiverem em vários idiomas, o campo deve ter o código `mul` e cada idioma deve ter traduções em `translations.txt`. Se todos os textos estiverem no mesmo idioma, não se deve usar `mul`.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Quando a regra passa, o `feed_lang` tem um código de idioma de duas letras reconhecido ou o valor `mul`. A regra só aceita códigos de duas letras: códigos com região, como `pt-PT`, não passam. A regra **não confirma que os textos estão escritos nesse idioma**.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | O valor é `mul`? | ✅ Passa | Segue para o passo 3 |
| 3 | O valor é um código de idioma de duas letras reconhecido? | ✅ Passa | ❌ Reporta o problema: código de idioma inválido |

Maiúsculas e minúsculas são equivalentes: `PT` e `pt` são aceites da mesma forma.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `pt` | ✅ Passa | Código de duas letras válido |
| `mul` | ✅ Passa | Conjunto de dados multilingue |
| `pt-PT` | ❌ Problema | Código com região não aceite |
| `português` | ❌ Problema | Nome do idioma em vez do código |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Código de idioma inválido | Nome do idioma escrito por extenso, código com região ou erro de digitação | Escrever no `feed_lang` do `feed_info.txt` o código de duas letras, por exemplo `pt`, ou `mul` se os textos estiverem em vários idiomas |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `feed_lang` do `feed_info.txt` com o código do idioma dos textos |
