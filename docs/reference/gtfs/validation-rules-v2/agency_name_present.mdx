---
title: Nome do operador
description: Verifica se o nome do operador está preenchido em agency.txt e, quando configurado, se consta da lista de nomes permitidos.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_name_present` |
| Ficheiro | `agency.txt` |
| Campo | `agency_name` |
| Tipo | Texto |
| Severidade | Obrigatório |

**Descrição do campo:** nome completo do operador de transportes.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

O `agency_name` tem sempre de estar preenchido, mesmo que a configuração da regra defina outra severidade para este campo. A regra **não verifica o conteúdo do nome**, só que existe.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ❌ Reporta o problema: campo em falta | Segue para o passo 2 |
| 2 | A configuração da regra tem uma lista de nomes permitidos? | Segue para o passo 3 | ✅ Passa |
| 3 | O nome está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: nome não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `Transportes Metropolitanos de Lisboa` | ✅ Passa | Nome preenchido |
| vazio | ❌ Problema | Campo obrigatório |
| `Outro Nome` (lista permitida = `Transportes Metropolitanos de Lisboa`) | ❌ Problema | Nome válido, mas fora da lista |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | O campo está vazio | Preencher o `agency_name` do `agency.txt` com o nome completo do operador |
| Nome não permitido | O nome está preenchido mas não está na lista de nomes permitidos | Usar um nome da lista, ou pedir ao administrador que o adicione |
