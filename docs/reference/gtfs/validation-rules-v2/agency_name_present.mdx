title: Nome da agência
description: Verifica se cada linha de agency.txt tem o nome completo da agência preenchido.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_name_present` |
| Ficheiro | `agency.txt` |
| Campo | `agency_name` |
| Tipo | Texto |
| Severidade | Obrigatório |

**Descrição do campo:** nome completo da agência de transporte, tal como deve aparecer aos passageiros.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

Quando esta regra passa, garante-se que todas as linhas de `agency.txt` têm um `agency_name` preenchido. A regra **não verifica** o conteúdo do texto, apenas que existe um valor.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ❌ Reporta o problema | Segue para o passo 2 |
| 2 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 3 | ✅ Passa |
| 3 | O valor está na lista (ou a lista aceita qualquer valor)? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `Metro de Lisboa` | ✅ Passa | Campo preenchido |
| (vazio) | ❌ Problema | Campo obrigatório em falta |
| `Metro de Lisboa` (lista permitida = `Carris`, `CP`) | ❌ Problema | Valor válido mas fora da lista |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A linha de `agency.txt` não tem valor em `agency_name` | Preencher `agency_name` com o nome completo da agência |
| Valor não permitido | A configuração da regra tem uma lista de nomes permitidos e este valor não consta dela | Usar um nome da lista, ou pedir ao administrador que o adicione |
