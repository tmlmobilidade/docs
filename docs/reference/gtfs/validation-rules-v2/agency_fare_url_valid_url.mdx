## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_fare_url_valid_url` |
| Ficheiro | `agency.txt` |
| Campo | `agency_fare_url` |
| Tipo | URL |
| Severidade | Opcional |

**Descrição do campo:** endereço de uma página onde o passageiro pode comprar bilhetes ou outros títulos de transporte do operador, ou uma página com informação sobre as tarifas do operador.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

Se o operador indicar uma página de tarifas, o valor tem de ser um endereço completo que começa por `http://` ou `https://` e indica um domínio. Se a configuração da regra tiver uma lista de endereços permitidos, o endereço também tem de constar dessa lista. A regra **não confirma que a página existe** nem que abre, só que o endereço está bem escrito.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é um endereço `http` ou `https` completo e sem carateres proibidos? | Segue para o passo 4 | ❌ Reporta o problema: URL inválido |
| 4 | A configuração da regra tem uma lista de endereços permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O endereço está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: endereço não permitido |

Os espaços no início e no fim são ignorados. Espaços no meio, aspas e os carateres `<`, `>`, `{`, `}`, `|`, `\` e `^` tornam o endereço inválido.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://www.operador.pt/bilhetes` | ✅ Passa | Endereço completo |
| `www.operador.pt/bilhetes` | ❌ Problema | Falta `https://` |
| `https://` | ❌ Problema | Falta o domínio |
| `https://outro.pt` (lista permitida = `https://www.operador.pt/bilhetes`) | ❌ Problema | Formato válido, mas fora da lista |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| URL inválido | Falta `https://`, falta o domínio ou há carateres proibidos | Escrever no `agency_fare_url` do `agency.txt` o endereço completo, por exemplo `https://www.operador.pt/bilhetes` |
| Endereço não permitido | O endereço é válido mas não está na lista de endereços permitidos | Usar um endereço da lista, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `agency_fare_url` do `agency.txt` com o endereço da página de tarifas |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `agency_fare_url` no `agency.txt` |
