## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_fare_url_valid_url` |
| Ficheiro | `agency.txt` |
| Campo | `agency_fare_url` |
| Tipo | URL |
| Severidade | Opcional |

**Descrição do campo:** página onde o passageiro pode comprar bilhetes ou outros títulos de transporte da agência, ou uma página com informação sobre os tarifários da agência.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

Se a agência indicar este URL, o valor tem de começar por `http://` ou `https://`, ter um domínio válido e não conter espaços nem carateres não permitidos. Se a configuração da regra tiver uma lista de URLs permitidos, o valor também tem de constar dessa lista. A regra **não confirma** que a página existe ou está acessível, só que o formato está correto.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O texto é um URL válido (começa por `http://` ou `https://`, tem domínio e não tem espaços nem carateres como `<`, `>`, `{`, `}`, `\|`)? | Segue para o passo 4 | ❌ Reporta o problema: formato inválido |
| 4 | A configuração da regra tem uma lista de URLs permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor está na lista (ou a lista aceita qualquer valor)? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://www.metro.pt/bilhetes` | ✅ Passa | Formato correto |
| `www.metro.pt/bilhetes` | ❌ Problema | Falta `http://` ou `https://` |
| `ftp://www.metro.pt/bilhetes` | ❌ Problema | Protocolo não permitido |
| `https://www.metro.pt/os nossos bilhetes` | ❌ Problema | Contém espaços |
| `https://outro.pt` (lista permitida = `https://www.metro.pt/bilhetes`) | ❌ Problema | Formato válido, mas fora da lista |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Formato inválido | Falta `http://` ou `https://`, o domínio está incompleto, ou o texto tem espaços ou carateres não permitidos | Escrever o URL completo, por exemplo `https://www.metro.pt/bilhetes` |
| Valor não permitido | O URL é válido mas não está na lista de URLs permitidos | Usar um URL da lista, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher com o URL da página de tarifários ou compra de bilhetes |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `agency_fare_url` |
