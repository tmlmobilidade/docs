---
title: Sentido consistente no padrão
description: Verifica se todas as viagens do mesmo `pattern_id` usam um único `direction_id`.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_direction_id_consistent_for_all_patterns_in_trips` |
| Ficheiro | `trips.txt` |
| Campos | `pattern_id`, `direction_id` |
| Tipo | Enumeração |
| Severidade | Opcional |

**Descrição dos campos:**

- `pattern_id`: identifica o padrão que agrupa as viagens.
- `direction_id`: identifica o sentido da viagem.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Todas as viagens do mesmo padrão têm de usar o mesmo `direction_id`. Valores vazios de `direction_id` são ignorados. A regra não valida o formato nem a referência do valor.

A regra avalia cada grupo de viagens com o mesmo `pattern_id`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | Recolhe mais de um valor distinto de `direction_id` no grupo? | Segue para o passo 2 | ✅ Passa |
| 2 | A configuração da regra desativa a validação? | ✅ Passa | ❌ Reporta o problema na primeira viagem do padrão |

## Como se relacionam

`pattern_id` define o grupo. `direction_id` tem de ser consistente dentro desse grupo.

## Exemplos

| Valores no padrão | Resultado | Porquê |
|---|---|---|
| `0, 0` | ✅ Passa | Um único sentido |
| `0, 1` | ❌ Problema | Dois sentidos distintos |
| `0, vazio` | ✅ Passa | O vazio é ignorado |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valores diferentes no mesmo padrão | Viagens com o mesmo `pattern_id` usam vários valores de `direction_id` | Corrigir `direction_id` ou `pattern_id` nas linhas afetadas de `trips.txt` |
