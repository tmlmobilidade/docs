---
title: shape_id igual ao pattern_id
description: Verifica se o shape_id de cada viagem é exatamente igual ao pattern_id da viagem.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_shape_id_needs_to_be_the_same_as_pattern_id` |
| Ficheiro | `trips.txt` |
| Campo | `shape_id` |
| Tipo | ID |
| Severidade | Opcional |

**Descrição do campo:** identifica a forma geoespacial que descreve o trajeto percorrido pelo veículo numa viagem. O valor de `shape_id` tem de ser igual ao `pattern_id` da viagem, para que a forma possa ser derivada diretamente do padrão.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Se a viagem tiver `shape_id` e `pattern_id` preenchidos, os dois valores têm de ser exatamente iguais. A regra **não verifica se o shape existe em `shapes.txt`** nem se o `pattern_id` é válido, só compara o texto dos dois campos.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | Os campos `shape_id` e `pattern_id` estão ambos preenchidos? | Segue para o passo 2 | ✅ Passa (os campos em falta são reportados pelas respetivas regras) |
| 2 | A configuração da regra está definida como "ignorar" ou "não permitido"? | ✅ Passa (a regra não é aplicada) | Segue para o passo 3 |
| 3 | O campo `shape_id` é exatamente igual ao campo `pattern_id`? | ✅ Passa | ❌ Reporta o problema |

## Como se relacionam

O `shape_id` tem de ser igual, carater a carater, ao `pattern_id` da mesma viagem. Um texto vazio só é aceite se o `pattern_id` também for um texto vazio.

## Exemplos

| shape_id | pattern_id | Resultado | Porquê |
|---|---|---|---|
| `1001_0` | `1001_0` | ✅ Passa | Os dois campos são iguais |
| `1001_1` | `1001_0` | ❌ Problema | Os dois campos têm texto diferente |
| (vazio) | `1001_0` | ❌ Problema | `shape_id` está vazio, `pattern_id` não |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| `shape_id` diferente de `pattern_id` | Os dois campos foram preenchidos com valores distintos, ou apenas um deles foi atualizado | Corrigir o campo `shape_id` em `trips.txt` para que fique igual ao `pattern_id` da mesma viagem |
