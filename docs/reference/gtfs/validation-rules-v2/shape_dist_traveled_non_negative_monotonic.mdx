title: Distância percorrida no percurso
description: Verifica se o shape_dist_traveled de shapes.txt, quando preenchido, não é negativo.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `shape_dist_traveled_non_negative_monotonic` |
| Ficheiro | `shapes.txt` |
| Campo | `shape_dist_traveled` |
| Tipo | Número decimal não negativo |
| Severidade | Opcional |

**Descrição do campo:** distância real percorrida ao longo do percurso, desde o primeiro ponto até ao ponto desta linha. Serve para mostrar no mapa a parte certa do percurso. Os valores têm de aumentar com o `shape_pt_sequence` e usar as mesmas unidades do `stop_times.txt`. É recomendado em linhas que cruzam ou repetem o mesmo trajeto.

Mais informação em [shapes.txt](/reference/gtfs/schedule/shapes).

## Como funciona

Se o `shape_dist_traveled` estiver preenchido, não pode ser negativo. Um campo vazio é aceite, salvo se a configuração da regra o exigir ou recomendar. Apesar do nome da regra, ela **não verifica se os valores aumentam**. Isso é verificado pela regra `shape_dist_traveled_non_decreasing_with_sequence`. Um valor que não seja um número é tratado pela regra `shapes_values_parse`.

A regra avalia cada linha do `shapes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `shape_dist_traveled` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O `shape_dist_traveled` é um número negativo? | ❌ Reporta o problema: valor inválido | ✅ Passa |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `6.831` | ✅ Passa | Número não negativo |
| `0` | ✅ Passa | Primeiro ponto do percurso |
| *(vazio)* | ✅ Passa | Campo opcional |
| `-2` | ❌ Problema | Valor negativo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor inválido | O `shape_dist_traveled` é um número negativo | Em `shapes.txt`, escrever o `shape_dist_traveled` com um número igual ou superior a `0` |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `shape_dist_traveled` em `shapes.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `shape_dist_traveled` em `shapes.txt` |
