## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `stop_times_stop_headsign_present` |
| Ficheiro | `stop_times.txt` |
| Campo | `stop_headsign` |
| Tipo | Texto |
| Severidade | Opcional |

**Descrição do campo:** texto que aparece na sinalética e identifica o destino da viagem para os passageiros. Substitui o `trip_headsign` quando o destino muda entre paragens. Um `stop_headsign` só vale para a sua linha do `stop_times.txt`, por isso tem de ser repetido em cada paragem onde se aplica.

Mais informação em [stop_times.txt](/reference/gtfs/schedule/stop_times).

## Como funciona

O `stop_headsign` é opcional. Um campo vazio é aceite, salvo se a configuração da regra o exigir ou recomendar. A regra **não verifica o conteúdo do texto**. Apesar do nome, não exige que o campo esteja preenchido por omissão.

A regra avalia cada linha do `stop_times.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `stop_headsign` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 4 | ✅ Passa |
| 4 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `Sacavém` | ✅ Passa | Preenchido |
| *(vazio)* | ✅ Passa | Campo opcional |
| *(vazio)* com campo exigido na configuração | ❌ Problema | A configuração da regra exige o campo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|

| Valor não permitido | O valor não está na lista da configuração da regra | Usar um valor da lista permitida, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `stop_headsign` em `stop_times.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `stop_headsign` em `stop_times.txt` |
