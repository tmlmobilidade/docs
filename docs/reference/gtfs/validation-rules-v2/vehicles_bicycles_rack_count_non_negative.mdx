---
title: Capacidade para bicicletas
description: Verifica se bicycles_capacity contém um número inteiro não negativo.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `vehicles_bicycles_rack_count_non_negative` |
| Ficheiro | `vehicles.txt` |
| Campo | `bicycles_capacity` |
| Tipo | Número inteiro não negativo |
| Severidade | Obrigatório |

**Descrição do campo:** número de lugares disponíveis para bicicletas não dobráveis. O valor `0` indica que o veículo não permite o transporte dessas bicicletas.

Mais informação em [vehicles.txt](/reference/gtfs/schedule/vehicles).

## Como funciona

O valor tem de ser um número inteiro igual ou superior a zero. A regra não confirma a existência, o estado ou a utilização dos suportes para bicicletas.

A regra avalia cada linha do `vehicles.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é igual ou superior a `0`? | ✅ Passa | ❌ Reporta o problema: capacidade negativa |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `0` | ✅ Passa | Sem lugares disponíveis |
| `4` | ✅ Passa | Capacidade não negativa |
| `-1` | ❌ Problema | Capacidade negativa |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda `bicycles_capacity` | Preencher `bicycles_capacity` em `vehicles.txt` com a capacidade para bicicletas |
| Campo preenchido quando não devia | A configuração da regra proíbe `bicycles_capacity` | Remover o valor de `bicycles_capacity` em `vehicles.txt` |
| Capacidade negativa | Foi introduzido um número inferior a zero | Corrigir `bicycles_capacity` em `vehicles.txt` para `0` ou um número inteiro positivo |
