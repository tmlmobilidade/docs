---
title: Operador da rota
description: Verifica se o agency_id de routes.txt, quando preenchido, existe em agency.txt.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `route_agency_id_references_agency_table` |
| Ficheiro | `routes.txt` |
| Campo | `agency_id` |
| Tipo | ID externo (agency.txt) |
| Severidade | Opcional |

**Descrição do campo:** operador responsável pela rota.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Quando a regra passa, o `agency_id` está vazio ou existe em `agency.txt`. A regra **não verifica se o operador está associado a outras rotas**.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O `agency_id` não existe em `agency.txt`? | ❌ Reporta o problema: operador não encontrado | ✅ Passa |

## Como se relacionam

Cada `agency_id` de `routes.txt` tem de existir em `agency.txt`.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `CM`  (existe em `agency.txt`) | ✅ Passa | Operador encontrado |
| `XX`  (não existe em `agency.txt`) | ❌ Problema | Operador desconhecido |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Operador não encontrado | O `agency_id` tem erro de escrita ou o operador não consta de `agency.txt` | Corrigir `agency_id` em `routes.txt` ou acrescentar o operador a `agency.txt` |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `agency_id` em `routes.txt`. A mensagem indica que o campo é obrigatório quando existe mais do que um operador em `agency.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `agency_id` em `routes.txt` |
