---
title: Sentido da viagem
description: Verifica se o valor de direction_id em trips.txt está preenchido e é 0 ou 1, e se, quando configurado, consta da lista de valores permitidos.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_direction_id_valid_enum` |
| Ficheiro | `trips.txt` |
| Campo | `direction_id` |
| Tipo | Enumeração |
| Severidade | Obrigatório |

**Descrição do campo:** indica o sentido de circulação da viagem. Não deve ser usado para calcular percursos; serve apenas para separar viagens por sentido ao publicar horários. `0` significa viagem num sentido (por exemplo, saída) e `1` significa viagem no sentido oposto (por exemplo, chegada).

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

O campo `direction_id` é sempre obrigatório: se estiver vazio, a regra reporta sempre o problema, independentemente da configuração da regra. A configuração só influencia o que acontece quando o valor está preenchido mas é inválido ou não está na lista de valores permitidos.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ❌ Reporta sempre o problema | Segue para o passo 2 |
| 2 | O valor é `0` ou `1`? | Segue para o passo 3 | ❌ Reporta o problema: valor inválido |
| 3 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 4 | ✅ Passa |
| 4 | O valor está na lista (ou a lista aceita qualquer valor)? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `0` | ✅ Passa | Sentido de ida, valor válido |
| (vazio) | ❌ Problema | Campo obrigatório, falta o valor |
| `3` | ❌ Problema | Valor fora do conjunto `0`, `1` |
| `1` (lista permitida da configuração = `0`) | ❌ Problema | Valor válido mas fora da lista permitida |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | `direction_id` está vazio em `trips.txt` | Preencher `direction_id` em `trips.txt` com `0` ou `1` |
| Valor inválido | O valor de `direction_id` não é `0` nem `1` | Corrigir `direction_id` em `trips.txt` para um destes valores |
| Valor não permitido | O valor é válido mas não consta da lista de valores permitidos pela configuração da regra | Usar um valor da lista permitida, ou pedir ao administrador que a atualize |
