title: Sentido da viagem

---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_direction_id_valid_enum` |
| Ficheiro | `trips.txt` |
| Campo | `direction_id` |
| Tipo | Enumeração |
| Severidade | Opcional |

**Descrição do campo:** indica o sentido de percurso da viagem. `0`: um sentido, por exemplo de ida. `1`: o sentido oposto, por exemplo de volta. Serve para separar viagens por sentido nos horários publicados e não deve ser usado no cálculo de percursos.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

O `direction_id` de cada viagem é vazio ou um dos valores `0` ou `1`, e respeita a configuração da regra. A regra **não confirma** que a informação corresponde à realidade do veículo.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é `0` ou `1`? | Segue para o passo 4 | ❌ Reporta o problema: valor inválido |
| 4 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `0` | ✅ Passa | Sentido válido |
| `1` | ✅ Passa | Sentido válido |
| `2` | ❌ Problema | Fora de `0` e `1` |
| `1` (lista permitida = `0`) | ❌ Problema | Válido, mas fora da lista |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor inválido | Foi escrito um valor fora de `0` ou `1` | Usar `0` ou `1` em `direction_id` no `trips.txt` |
| Valor não permitido | O valor é válido mas não consta da lista de valores permitidos da configuração da regra | Usar um valor da lista, ou pedir ao administrador que o acrescente |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `direction_id` no `trips.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `direction_id` no `trips.txt` |
