title: Ordem de apresentação da rota
description: Verifica se o route_sort_order de routes.txt, quando preenchido, é um número inteiro igual ou maior que zero.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `route_sort_order_non_negative_integer` |
| Ficheiro | `routes.txt` |
| Campo | `route_sort_order` |
| Tipo | Número inteiro não negativo |
| Severidade | Opcional |

**Descrição do campo:** ordena as rotas de forma ideal para apresentação aos passageiros. Rotas com valores mais baixos de `route_sort_order` devem aparecer primeiro.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Quando a regra passa, fica garantido que, se `route_sort_order` estiver preenchido, o valor é um número inteiro igual ou maior que zero. A regra **não verifica** se a ordem resultante faz sentido para os passageiros, só o formato do valor.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é um número negativo? | ❌ Reporta o problema: valor inválido | ✅ Passa |

## Exemplos

| route_sort_order | Resultado | Porquê |
|---|---|---|
| `0` | ✅ Passa | Número inteiro não negativo |
| `-1` | ❌ Problema | O valor é negativo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor inválido | `route_sort_order` está preenchido com um número negativo | Corrigir `route_sort_order` em `routes.txt` para um número inteiro igual ou maior que zero |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `route_sort_order` em `routes.txt` com um número inteiro igual ou maior que zero |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `route_sort_order` em `routes.txt` |
