title: Ordem de apresentação da rota
description: Verifica se o route_sort_order de routes.txt não é um número negativo.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `route_sort_order_non_negative_integer` |
| Ficheiro | `routes.txt` |
| Campo | `route_sort_order` |
| Tipo | Número inteiro não negativo |
| Severidade | Opcional |

**Descrição do campo:** ordena as rotas da forma mais adequada para apresentação aos clientes. As rotas com valores mais pequenos são mostradas primeiro.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Quando a regra passa, o `route_sort_order` é `0` ou um número positivo. A regra **não verifica se existem valores repetidos** nem se o texto é um número inteiro. A leitura do valor como número é feita antes das regras.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é menor do que `0`? | ❌ Reporta o problema: número negativo | ✅ Passa |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `10` | ✅ Passa | Número positivo |
| `0` | ✅ Passa | Zero é aceite |
| `-1` | ❌ Problema | Número negativo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Número negativo | O `route_sort_order` é menor do que `0` | Corrigir `route_sort_order` em `routes.txt` para `0` ou um número positivo |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `route_sort_order` em `routes.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `route_sort_order` em `routes.txt` |
