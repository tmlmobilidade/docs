title: Identificador único da viagem
description: Verifica se cada `trip_id` está preenchido e é único em trips.txt.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trip_id_unique` |
| Ficheiro | `trips.txt` |
| Campo | `trip_id` |
| Tipo | Identificador único |
| Severidade | Obrigatório |

**Descrição do campo:** identifica uma viagem.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Cada `trip_id` tem de estar preenchido e aparecer numa única linha de `trips.txt`, salvo quando a configuração desativa a regra. A regra não avalia o formato nem o comprimento do identificador.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda o campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra proíbe o campo? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O mesmo `trip_id` aparece em mais de uma linha? | ❌ Reporta o problema: identificador duplicado | ✅ Passa |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `V100` numa linha | ✅ Passa | Identificador único |
| Vazio | ❌ Problema | Campo obrigatório |
| `V100` em duas linhas | ❌ Problema | Identificador duplicado |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda `trip_id` | Preencher `trip_id` em `trips.txt` |
| Campo preenchido quando não devia | A configuração da regra proíbe `trip_id` | Remover `trip_id` de `trips.txt` |
| Identificador duplicado | Mais de uma linha usa o mesmo `trip_id` | Atribuir um `trip_id` diferente a cada viagem duplicada em `trips.txt` |
