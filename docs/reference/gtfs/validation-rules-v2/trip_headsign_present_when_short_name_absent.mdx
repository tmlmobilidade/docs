## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trip_headsign_present_when_short_name_absent` |
| Ficheiro | `trips.txt` |
| Campo | `trip_headsign` |
| Tipo | Texto |
| Severidade | Obrigatório |

**Descrição do campo:** texto que aparece na sinalética do veículo e identifica o destino da viagem para os passageiros. Ajuda a distinguir viagens dentro da mesma linha. Se o destino mudar ao longo da viagem, o valor pode ser substituído, para paragens específicas, pelo campo `stop_headsign` de `stop_times.txt`.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Apesar do nome da regra, o preenchimento de `trip_headsign` é validado de forma independente do campo `trip_short_name`: esta regra não verifica se `trip_short_name` está preenchido ou vazio. Também não confirma que o texto do destino está correto, só que o campo está preenchido de acordo com a configuração.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo não deve ser preenchido? | ❌ Reporta o problema | ✅ Passa |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `Aeroporto` | ✅ Passa | Campo preenchido |
| (vazio) | ❌ Problema | A configuração da regra exige ou recomenda o campo `trip_headsign` |
| `Aeroporto` (configuração define o campo como não permitido) | ❌ Problema | O campo está preenchido mas a configuração não permite o preenchimento |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda o preenchimento de `trip_headsign` | Preencher `trip_headsign` em `trips.txt` com o texto do destino da viagem |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `trip_headsign` em `trips.txt` |
