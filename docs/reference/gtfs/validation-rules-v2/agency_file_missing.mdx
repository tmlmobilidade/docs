---
title: Ficheiro do operador em falta
description: Verifica se o ficheiro agency.txt existe no conjunto de dados.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_file_missing` |
| Ficheiro | `agency.txt` |
| Campo | Se aplica em todo o ficheiro |
| Tipo | Ficheiro |
| Severidade | Opcional (obrigatório ou recomendado, se a configuração da regra o indicar) |

## Como funciona

Se a configuração da regra exigir ou recomendar o `agency.txt`, o conjunto de dados tem de o incluir. A regra **não verifica o conteúdo do ficheiro**, só se ele existe. O conteúdo é verificado pelas outras regras de `agency.txt`.

A regra avalia o conjunto de dados uma só vez, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O conjunto de dados inclui o `agency.txt`? | ✅ Passa | Segue para o passo 2 |
| 2 | A configuração da regra manda ignorar este ficheiro? | Não reporta | Segue para o passo 3 |
| 3 | A configuração da regra exige o ficheiro? | ❌ Reporta o problema: ficheiro obrigatório em falta | ❌ Reporta o problema: ficheiro recomendado em falta |

Sem configuração da regra, o `agency.txt` é sempre obrigatório.

O problema é reportado uma só vez por ficheiro.

## Exemplos

| Situação | Resultado | Porquê |
|---|---|---|
| Conjunto de dados com `agency.txt` | ✅ Passa | O ficheiro existe |
| Conjunto de dados sem `agency.txt`, ficheiro exigido (ou sem configuração) | ❌ Problema | Ficheiro obrigatório em falta |
| Conjunto de dados sem `agency.txt`, ficheiro recomendado | ❌ Problema | Ficheiro recomendado em falta |
| Conjunto de dados sem `agency.txt`, regra a ignorar | ✅ Passa | Nada a reportar |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Ficheiro obrigatório em falta | O conjunto de dados não inclui o `agency.txt`, ou o ficheiro tem outro nome | Adicionar ao conjunto de dados o ficheiro `agency.txt`, com este nome, e uma linha por operador |
| Ficheiro recomendado em falta | O conjunto de dados não inclui o `agency.txt` e a configuração da regra recomenda-o | Adicionar ao conjunto de dados o ficheiro `agency.txt`, com este nome, e uma linha por operador |
