## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_pattern_id_present_and_references_consistent` |
| Ficheiro | `trips.txt` |
| Campo | `pattern_id` |
| Tipo | Identificador |
| Severidade | Opcional (obrigatório para os Transportes Metropolitanos de Lisboa) |

**Descrição do campo:** identifica o padrão a que a viagem pertence. Os padrões correspondem ao desdobramento das rotas pelos sentidos. As viagens com o mesmo `pattern_id` têm de ter o mesmo `route_id`, `trip_headsign`, `direction_id`, `shape_id` e a mesma sequência de paragens.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

A regra confirma que a viagem tem `pattern_id`, quando a configuração da regra o exige ou recomenda. Apesar do nome, **não confirma** que o padrão existe noutro ficheiro nem que as viagens do padrão são coerentes. Isso é feito por outras regras. As viagens com `pattern_id` entram nessas regras de grupo.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `pattern_id` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | ✅ Passa |

## Exemplos

| `pattern_id` | Resultado | Porquê |
|---|---|---|
| `1001_0_1` | ✅ Passa | Campo preenchido |
| (vazio, campo exigido) | ❌ Problema | Campo em falta |
| (vazio, campo opcional) | ✅ Passa | Campo não exigido |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `pattern_id` no `trips.txt` |
