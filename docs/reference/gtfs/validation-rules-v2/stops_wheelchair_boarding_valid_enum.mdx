## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `stops_wheelchair_boarding_valid_enum` |
| Ficheiro | `stops.txt` |
| Campo | `wheelchair_boarding` |
| Tipo | Enumeração (`0`, `1` ou `2`) |
| Severidade | Opcional |

**Descrição do campo:** indica se é possível embarcar em cadeira de rodas no local. O significado depende do tipo de local (paragem sem estação, paragem numa estação ou entrada de estação). Nas paragens numa estação e nas entradas, `0` ou vazio herda o valor da estação.

- `0`: sem informação de acessibilidade, ou herda o valor da estação
- `1`: é possível embarcar em cadeira de rodas, ou existe um caminho acessível
- `2`: não é possível embarcar em cadeira de rodas, ou não existe caminho acessível

Mais informação em [stops.txt](/reference/gtfs/schedule/stops).

## Como funciona

O `wheelchair_boarding` é opcional. Um campo vazio é aceite, salvo se a configuração da regra o exigir ou recomendar. Se estiver preenchido, tem de ser `0`, `1` ou `2`.

A regra avalia cada linha do `stops.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `wheelchair_boarding` está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O `wheelchair_boarding` é `0`, `1` ou `2`? | Segue para o passo 4 | ❌ Reporta o problema: valor inválido |
| 4 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `1` | ✅ Passa | Acessível |
| `3` | ❌ Problema | Só são aceites `0`, `1` e `2` |
| *(vazio)* | ✅ Passa | Campo opcional |
| *(vazio)* com campo exigido na configuração | ❌ Problema | A configuração da regra exige o campo |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor inválido | O `wheelchair_boarding` é um número fora da lista de valores aceites | Corrigir o `wheelchair_boarding` em `stops.txt` para `0`, `1` ou `2` |
| Valor não permitido | O valor não está na lista da configuração da regra | Usar um valor da lista permitida, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `wheelchair_boarding` em `stops.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `wheelchair_boarding` em `stops.txt` |
