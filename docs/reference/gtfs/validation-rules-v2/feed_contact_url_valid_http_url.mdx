## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_contact_url_valid_http_url` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_contact_url` |
| Tipo | URL |
| Severidade | Opcional |

**Descrição do campo:** endereço de uma página de contactos, formulário, balcão de apoio ou outra ferramenta para comunicar sobre o conjunto de dados GTFS e as práticas de publicação. É um contacto técnico para as aplicações que usam os dados. O contacto de apoio ao cliente deve ficar em `agency.txt`. Recomenda-se preencher pelo menos um dos campos `feed_contact_url` ou `feed_contact_email`.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Se o conjunto de dados indicar uma página de contacto técnico, o valor tem de ser um endereço completo que começa por `http://` ou `https://` e indica um domínio. A regra **não confirma que a página existe** nem que abre, só que o endereço está bem escrito. A regra também não verifica se o `feed_contact_email` está preenchido.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | O valor é um endereço `http` ou `https` completo e sem carateres proibidos? | ✅ Passa | ❌ Reporta o problema: URL inválido |

Os espaços no início e no fim são ignorados. Espaços no meio, aspas e os carateres `<`, `>`, `{`, `}`, `|`, `\` e `^` tornam o endereço inválido.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `https://www.operador.pt/contactos` | ✅ Passa | Endereço completo |
| `operador.pt/contactos` | ❌ Problema | Falta `https://` |
| `https://` | ❌ Problema | Falta o domínio |
| `https://operador.pt/fale connosco` | ❌ Problema | Espaço no meio |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| URL inválido | Falta `https://`, falta o domínio ou há carateres proibidos | Escrever no `feed_contact_url` do `feed_info.txt` o endereço completo, por exemplo `https://www.operador.pt/contactos` |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `feed_contact_url` do `feed_info.txt` com o endereço da página de contacto técnico |
