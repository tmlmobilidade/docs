---
title: Ficheiro routes.txt em falta
description: Verifica se o ficheiro routes.txt existe no conjunto de dados.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `routes_file_missing` |
| Ficheiro | `routes.txt` |
| Campo | Se aplica em todo o ficheiro |
| Tipo | Presença de ficheiro |
| Severidade | Obrigatório |

## Como funciona

O `routes.txt` é obrigatório no GTFS. Se não existir no conjunto de dados, a regra reporta um problema. A regra **não verifica o conteúdo do ficheiro**, só se existe.

A regra avalia o conjunto de dados, seguindo o passo abaixo, que dá o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `routes.txt` não existe no conjunto de dados? | ❌ Reporta o problema: `routes.txt` em falta | ✅ Passa |

Sem ficheiro de configuração, o `routes.txt` é sempre obrigatório. Com configuração, a gravidade segue o que a configuração da regra define.

## Exemplos

| `routes.txt` no ZIP | Resultado | Porquê |
|---|---|---|
| Existe | ✅ Passa | O ficheiro está presente |
| Não existe | ❌ Problema | Falta o ficheiro obrigatório |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| `routes.txt` em falta | O ZIP não inclui o `routes.txt` | Adicionar o `routes.txt` ao ZIP, na raiz ou numa única pasta dentro do ZIP |
