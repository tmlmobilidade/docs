## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_version_valid_identifier` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_version` |
| Tipo | Texto |
| Severidade | Opcional |

**Descrição do campo:** texto que indica a versão atual do conjunto de dados GTFS. As aplicações que usam os dados podem mostrar este valor. Assim, quem publica os dados consegue confirmar se a versão mais recente já foi carregada.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Quando a regra passa, o `feed_version` tem texto, ou a configuração da regra não o exige. A regra **não verifica o formato da versão**: qualquer texto é aceite. Também não compara a versão com a de um envio anterior.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | ✅ Passa |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `2026.09.25` | ✅ Passa | Versão preenchida |
| `v3` | ✅ Passa | Qualquer texto é aceite |
| vazio (configuração da regra exige o campo) | ❌ Problema | Campo em falta |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher o `feed_version` do `feed_info.txt` com a versão do conjunto de dados, por exemplo a data de publicação `2026.09.25` |
