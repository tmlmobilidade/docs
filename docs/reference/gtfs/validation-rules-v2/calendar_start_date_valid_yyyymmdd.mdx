---
title: Data de início do serviço
description: Verifica se a data inicial do período de serviço em calendar.txt é uma data válida no formato AAAAMMDD.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `calendar_start_date_valid_yyyymmdd` |
| Ficheiro | `calendar.txt` |
| Campo | `start_date` |
| Tipo | Data |
| Severidade | Obrigatório |

**Descrição do campo:** primeiro dia de serviço do período definido pela linha.

Mais informação em [calendar.txt](/reference/gtfs/schedule/calendar).

## Como funciona

Quando a regra passa, `start_date` está presente quando exigido e representa uma data real no formato AAAAMMDD. A regra **não compara esta data com `end_date` nem verifica se existe serviço nos dias do período**.

A regra avalia cada linha do `calendar.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor tem oito algarismos e representa uma data real? | ✅ Passa | ❌ Reporta o problema: data inválida |

Os espaços não são removidos. O formato aceite é exatamente AAAAMMDD.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `20240101` | ✅ Passa | Data válida |
| campo vazio | ❌ Problema | Falta um valor obrigatório |
| `2024-01-01` | ❌ Problema | Formato incorreto |
| `20240230` | ❌ Problema | Dia inexistente |
| `20240101` quando o campo é proibido | ❌ Problema | Campo preenchido indevidamente |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Data inválida | O valor não tem oito algarismos ou não representa uma data real | Corrigir `start_date` em `calendar.txt` para uma data válida no formato AAAAMMDD |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `start_date` em `calendar.txt` com o primeiro dia de serviço |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `start_date` em `calendar.txt` |
