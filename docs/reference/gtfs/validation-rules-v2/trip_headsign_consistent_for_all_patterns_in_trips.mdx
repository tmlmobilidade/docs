---
title: Destino consistente no padrão
description: Verifica se todas as viagens do mesmo `pattern_id` usam o mesmo `trip_headsign`.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trip_headsign_consistent_for_all_patterns_in_trips` |
| Ficheiro | `trips.txt` |
| Campos | `pattern_id`, `trip_headsign` |
| Tipo | Texto |
| Severidade | Obrigatório |

**Descrição dos campos:**

- `pattern_id`: identifica o padrão que agrupa as viagens.
- `trip_headsign`: texto apresentado como destino da viagem.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Todas as viagens do mesmo padrão têm de usar o mesmo `trip_headsign`, incluindo a presença do campo. Valores vazios de `trip_headsign` são contados como um valor distinto. A regra não valida o formato nem a referência do valor.

A regra avalia cada grupo de viagens com o mesmo `pattern_id`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | Recolhe mais de um valor distinto de `trip_headsign` no grupo? | Segue para o passo 2 | ✅ Passa |
| 2 | A configuração da regra desativa a validação? | ✅ Passa | ❌ Reporta o problema na primeira viagem do padrão |

## Como se relacionam

`pattern_id` define o grupo. `trip_headsign` tem de ser consistente dentro desse grupo.

## Exemplos

| Valores no padrão | Resultado | Porquê |
|---|---|---|
| `Terminal, Terminal` | ✅ Passa | Um único destino |
| `Terminal, Centro` | ❌ Problema | Dois destinos distintos |
| `Terminal, vazio` | ❌ Problema | Presença inconsistente |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valores diferentes no mesmo padrão | Viagens com o mesmo `pattern_id` usam vários valores de `trip_headsign` | Corrigir `trip_headsign` ou `pattern_id` nas linhas afetadas de `trips.txt` |
