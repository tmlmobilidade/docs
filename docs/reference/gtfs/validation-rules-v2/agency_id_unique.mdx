---
title: Identificador da agência
description: Verifica se cada linha de agency.txt tem um agency_id preenchido e se esse valor não se repete no ficheiro.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_id_unique` |
| Ficheiro | `agency.txt` |
| Campo | `agency_id` |
| Tipo | Identificador único |
| Severidade | Obrigatório |

**Descrição do campo:** identificador único da agência (ou marca) de transporte dentro do conjunto de dados. É usado para associar rotas e outras entidades a esta agência.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

Quando esta regra passa, garante-se que todas as linhas de `agency.txt` têm um `agency_id` preenchido e que não há dois `agency_id` iguais no ficheiro. A regra **não confirma** que o valor é depois referenciado corretamente noutras tabelas, como `routes.txt`.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ❌ Reporta o problema | Segue para o passo 2 |
| 2 | Já existe outra linha com o mesmo `agency_id`? | Reporta o problema (duplicado) e segue para o passo 3 | Segue para o passo 3 |
| 3 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 4 | ✅ Passa |
| 4 | O valor está na lista (ou a lista aceita qualquer valor)? | ✅ Passa | ❌ Reporta o problema: valor não permitido |

O campo é comparado exatamente como está escrito: não há remoção de espaços nem alteração de maiúsculas/minúsculas.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `METRO` (não repetido no ficheiro) | ✅ Passa | Preenchido e único |
| (vazio) | ❌ Problema | Campo obrigatório em falta |
| `METRO` (também usado noutra linha) | ❌ Problema | Valor duplicado |
| `METRO` (lista permitida = `BUS`, `RAIL`) | ❌ Problema | Valor válido mas fora da lista |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A linha de `agency.txt` não tem valor em `agency_id` | Preencher `agency_id` com um identificador único para a agência |
| Valor duplicado | Duas ou mais linhas de `agency.txt` têm o mesmo `agency_id` | Atribuir um `agency_id` diferente a cada agência |
| Valor não permitido | A configuração da regra tem uma lista de `agency_id` permitidos e este valor não consta dela | Usar um `agency_id` da lista, ou pedir ao administrador que o adicione |
