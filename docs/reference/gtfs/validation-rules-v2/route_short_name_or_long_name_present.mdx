title: Nome curto da rota
description: Verifica se o route_short_name está preenchido, não é demasiado longo e, quando configurado, consta da lista de valores permitidos.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `route_short_name_or_long_name_present` |
| Ficheiro | `routes.txt` |
| Campo | `route_short_name` |
| Tipo | Texto |
| Severidade | Obrigatório |

**Descrição do campo:** nome curto da rota. É normalmente um identificador curto e abstrato, como `32`, `100X` ou `Verde`, que os passageiros usam para reconhecer a rota. Podem existir `route_short_name` e `route_long_name` na mesma rota.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

Quando a regra passa, o `route_short_name` está preenchido, tem no máximo 12 carateres e, se a configuração da regra tiver uma lista de valores permitidos, consta dessa lista. A regra **não confirma que existe pelo menos um dos dois nomes da rota**. Avalia só este campo.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O texto tem mais de 12 carateres? | ❌ Reporta o problema: nome demasiado longo. Segue para o passo 4 | Segue para o passo 4 |
| 4 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 5 | ✅ Passa |
| 5 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `32` | ✅ Passa | Nome curto preenchido |
| `LINHA-DE-LISBOA-1` | ❌ Problema | Mais de 12 carateres |
| `32` (lista permitida = `100X`) | ❌ Problema | Valor válido, mas fora da lista |
| (vazio) | ❌ Problema | Campo obrigatório sem valor |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Nome demasiado longo | O `route_short_name` tem mais de 12 carateres | Encurtar `route_short_name` em `routes.txt`. Passar o texto descritivo para `route_long_name` |
| Valor não permitido | O valor está fora da lista de valores permitidos da configuração da regra | Usar um valor da lista em `route_short_name` em `routes.txt`, ou pedir ao administrador que o adicione |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `route_short_name` em `routes.txt` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `route_short_name` em `routes.txt` |
