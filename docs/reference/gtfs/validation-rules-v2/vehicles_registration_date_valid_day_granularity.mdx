---
title: Data de matrícula
description: Verifica se a data da primeira matrícula está preenchida e é uma data válida no formato AAAAMMDD.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `vehicles_registration_date_valid_day_granularity` |
| Ficheiro | `vehicles.txt` |
| Campo | `registration_date` |
| Tipo | Data |
| Severidade | Obrigatório |

**Descrição do campo:** data da primeira matrícula.

Mais informação em [vehicles.txt](/reference/gtfs/schedule/vehicles).

## Como funciona

A data tem de estar no formato `AAAAMMDD` e existir no calendário. A regra **não verifica** se a data está no passado nem se é plausível.

A regra avalia cada linha do `vehicles.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | ❌ Reporta o problema: campo em falta | Segue para o passo 2 |
| 2 | O valor tem oito dígitos e é uma data que existe no calendário? | ✅ Passa | ❌ Reporta o problema: data inválida |

## Exemplos

| `registration_date` | Resultado | Porquê |
|---|---|---|
| `20190315` | ✅ Passa | Data válida |
| `2019-03-15` | ❌ Problema | Formato incorreto |
| `20190231` | ❌ Problema | O dia não existe |
| (vazio) | ❌ Problema | Campo em falta |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Campo em falta | A célula de `registration_date` está vazia | Preencher `registration_date` no `vehicles.txt` |
| Data inválida | Formato errado ou dia inexistente | Escrever `registration_date` no `vehicles.txt` no formato `AAAAMMDD`, por exemplo `20190315` |
