## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `feed_contact_email_valid_address` |
| Ficheiro | `feed_info.txt` |
| Campo | `feed_contact_email` |
| Tipo | E-mail |
| Severidade | Opcional |

**Descrição do campo:** endereço de correio eletrónico para questões sobre o conjunto GTFS e as práticas de publicação. É um contacto técnico para aplicações que consomem GTFS. O contacto de apoio ao cliente deve ser indicado em `agency.txt`. Recomenda-se o preenchimento de `feed_contact_email` ou `feed_contact_url`.

Mais informação em [feed_info.txt](/reference/gtfs/schedule/feed_info).

## Como funciona

Quando a regra passa, `feed_contact_email` respeita a configuração e tem a estrutura de um endereço de correio eletrónico. A regra **não confirma que a caixa de correio existe nem exige que pelo menos um dos dois contactos técnicos esteja preenchido**.

A regra avalia cada linha do `feed_info.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O texto pode ser interpretado como um endereço de correio eletrónico? | ✅ Passa | ❌ Reporta o problema: endereço inválido |

Os espaços no início e no fim são ignorados durante a verificação. Uma linha com todos os campos vazios é ignorada antes desta regra.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `dados@operador.pt` | ✅ Passa | Formato reconhecido |
| `dados@` | ❌ Problema | Falta o domínio |
| `dados@operador.pt` quando o campo é proibido | ❌ Problema | Campo preenchido indevidamente |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Endereço inválido | Erro de escrita ou domínio em falta | Corrigir `feed_contact_email` em `feed_info.txt` para um endereço completo, por exemplo `dados@operador.pt` |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `feed_contact_email` em `feed_info.txt` com o contacto técnico do conjunto |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `feed_contact_email` em `feed_info.txt` |
