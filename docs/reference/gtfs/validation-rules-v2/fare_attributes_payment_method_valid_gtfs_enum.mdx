---
title: Momento de pagamento da tarifa
description: Verifica se o método de pagamento indica pagamento a bordo ou antes do embarque.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `fare_attributes_payment_method_valid_gtfs_enum` |
| Ficheiro | `fare_attributes.txt` |
| Campo | `payment_method` |
| Tipo | Enumeração |
| Severidade | Obrigatório |

**Descrição do campo:** indica quando a tarifa tem de ser paga. O valor `0` indica pagamento a bordo. O valor `1` indica pagamento antes do embarque.

Mais informação em [fare_attributes.txt](/reference/gtfs/schedule/fare_attributes).

## Como funciona

Quando a regra passa, `payment_method` está presente quando exigido e tem o valor `0` ou `1`. A regra **não verifica o meio de pagamento nem a forma de validação do título**.

A regra avalia cada linha do `fare_attributes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O campo está vazio? | Verifica se a configuração da regra exige ou recomenda este campo. Se sim, reporta o problema. Se não, aceita | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O valor é `0` ou `1`? | ✅ Passa | ❌ Reporta o problema: método de pagamento inválido |

O valor é interpretado como número inteiro antes desta regra. Os espaços não são removidos antes dessa interpretação.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `0` | ✅ Passa | Pagamento a bordo |
| `1` | ✅ Passa | Pagamento antes do embarque |
| `2` | ❌ Problema | Valor não previsto |
| campo vazio | ❌ Problema | Falta um valor obrigatório |
| `0` quando o campo é proibido | ❌ Problema | Campo preenchido indevidamente |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Método de pagamento inválido | O valor é diferente de `0` e `1` | Alterar `payment_method` em `fare_attributes.txt` para `0` ou `1` |
| Campo em falta | A configuração da regra exige ou recomenda este campo | Preencher `payment_method` em `fare_attributes.txt` com `0` ou `1` |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `payment_method` em `fare_attributes.txt` |
