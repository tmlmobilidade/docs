## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `route_desc_per_severity_and_content_rules` |
| Ficheiro | `routes.txt` |
| Campos | `route_desc`, `route_short_name`, `route_long_name` |
| Tipo | Texto |
| Severidade | Condicional (obrigatório quando o `route_short_name` está vazio), Obrigatório, Obrigatório |

**Descrição dos campos:**

- `route_desc`: descrição da linha, com informação útil e de qualidade. Não deve repetir o `route_short_name` nem o `route_long_name`.
- `route_short_name`: nome curto da linha. Quando está vazio, o `route_desc` passa a ser obrigatório.
- `route_long_name`: nome completo da linha. O `route_desc` não deve ser igual a ele.

Mais informação em [routes.txt](/reference/gtfs/schedule/routes).

## Como funciona

O `route_desc` só é obrigatório quando o `route_short_name` está vazio. Quando está preenchido, não deve ser igual ao `route_short_name` nem ao `route_long_name`. Se a configuração da regra tiver uma lista de valores permitidos, o valor também tem de constar dessa lista. A regra **não verifica a qualidade do texto**.

A regra avalia cada linha do `routes.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `route_desc` está vazio? | Se o `route_short_name` também está vazio, ❌ reporta o problema: `route_desc` obrigatório. Se não, ✅ passa | Segue para o passo 2 |
| 2 | A configuração da regra define que este campo **não deve ser preenchido**? | ❌ Reporta o problema | Segue para o passo 3 |
| 3 | O `route_desc` é igual ao `route_short_name`? | ❌ Reporta o problema, como aviso: descrição repetida. Segue para o passo 4 | Segue para o passo 4 |
| 4 | O `route_desc` é igual ao `route_long_name`? | ❌ Reporta o problema, como aviso: descrição repetida. Segue para o passo 5 | Segue para o passo 5 |
| 5 | A configuração da regra tem uma lista de valores permitidos? | Segue para o passo 6 | ✅ Passa |
| 6 | O valor está na lista? (ou a lista aceita qualquer valor) | ✅ Passa | ❌ Reporta o problema: valor não permitido |

## Como se relacionam

O `route_short_name` decide se o `route_desc` é obrigatório. O `route_short_name` e o `route_long_name` são comparados com o `route_desc` para evitar repetições.

## Exemplos

| `route_desc` | `route_short_name` | Resultado | Porquê |
|---|---|---|---|
| Liga Prior Velho a Sacavém | `32` | ✅ Passa | Descrição própria |
| *(vazio)* | `32` | ✅ Passa | Campo opcional |
| *(vazio)* | *(vazio)* | ❌ Problema | Falta o nome curto e a descrição |
| `32` | `32` | ❌ Problema | Repete o nome curto (aviso) |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| `route_desc` obrigatório | O `route_short_name` e o `route_desc` estão vazios | Preencher o `route_short_name` ou o `route_desc` em `routes.txt` |
| Descrição repetida | O `route_desc` é igual ao `route_short_name` ou ao `route_long_name` | Em `routes.txt`, escrever no `route_desc` um texto diferente dos nomes, ou deixá-lo vazio |
| Valor não permitido | O valor não está na lista da configuração da regra | Usar um valor da lista permitida, ou pedir ao administrador que o adicione |
| Campo preenchido quando não devia | A configuração da regra define que este campo não deve ter valor | Remover o valor de `route_desc` em `routes.txt` |
