---
title: Leitura dos valores de trips.txt
description: Verifica se os campos numéricos de trips.txt (direction_id, wheelchair_accessible, bikes_allowed) têm um número inteiro.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `trips_values_parse` |
| Ficheiro | `trips.txt` |
| Campos | `direction_id`, `wheelchair_accessible`, `bikes_allowed` |
| Tipo | Inteiro |
| Severidade | Opcional |

**Descrição dos campos:**

- `direction_id`: sentido de percurso da viagem.
- `wheelchair_accessible`: acessibilidade da viagem para cadeiras de rodas.
- `bikes_allowed`: indica se as bicicletas são permitidas na viagem.

Mais informação em [trips.txt](/reference/gtfs/schedule/trips).

## Como funciona

Cada um destes campos tem de estar vazio ou ter um número inteiro. Os restantes campos de `trips.txt` são texto e não podem falhar nesta leitura. A regra **não verifica** se o número é um valor permitido. Isso é feito pelas regras de cada campo.

A regra avalia cada linha do `trips.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O valor de algum dos três campos não é um número inteiro? | ❌ Reporta o problema: valor não numérico | ✅ Passa |

Quando uma linha falha esta leitura, essa viagem **não é avaliada por nenhuma outra regra** do `trips.txt`. Convém corrigir primeiro estes problemas.

## Exemplos

| Valor | Resultado | Porquê |
|---|---|---|
| `1` | ✅ Passa | Número inteiro |
| (vazio) | ✅ Passa | Campo vazio |
| `a` | ❌ Problema | Não é um número |
| `1.5` | ❌ Problema | Não é um número inteiro |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Valor não numérico | Texto ou decimal num campo que só aceita números inteiros | Corrigir o campo indicado no `trips.txt` para um número inteiro, por exemplo `0`, `1` ou `2` |
