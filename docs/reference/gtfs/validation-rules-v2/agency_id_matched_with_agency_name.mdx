---
title: Correspondência entre identificador e nome do operador
description: Verifica se o par agency_id e agency_name de cada linha de agency.txt corresponde a uma lista de correspondências definida na configuração da regra.
---

## Propriedades da regra

| Propriedade | Valor |
|---|---|
| Rule ID | `agency_id_matched_with_agency_name` |
| Ficheiro | `agency.txt` |
| Campos | `agency_id`, `agency_name` |
| Tipo | Texto |
| Severidade | Opcional (só atua quando a configuração da regra tem uma lista de correspondências) |

**Descrição dos campos:**

- `agency_id`: identifica uma marca de transporte, muitas vezes sinónimo do próprio operador.
- `agency_name`: nome completo do operador de transportes.

Mais informação em [agency.txt](/reference/gtfs/schedule/agency).

## Como funciona

Esta regra não verifica se `agency_id` ou `agency_name` existem — isso é feito pelas regras `agency_id_unique` e `agency_name_present`. Verifica apenas se, quando a configuração da regra tem uma lista de pares `agency_id`/`agency_name` esperados, o par desta linha corresponde a um deles. Sem essa lista configurada, a regra **não reporta nada**.

A regra avalia cada linha do `agency.txt`, seguindo os passos abaixo por ordem, até um deles dar o resultado.

| # | Pergunta | Se sim | Se não |
|---|---|---|---|
| 1 | O `agency_id` ou o `agency_name` desta linha estão vazios? | ✅ Passa (nada a comparar) | Segue para o passo 2 |
| 2 | A configuração da regra manda ignorar ou proibir este campo? | ✅ Passa (não avalia a correspondência) | Segue para o passo 3 |
| 3 | A configuração da regra tem uma lista de pares `agency_id`/`agency_name` esperados? | Segue para o passo 4 | ✅ Passa |
| 4 | O par desta linha corresponde a um dos pares da lista? | ✅ Passa | ❌ Reporta o problema: correspondência inválida |

## Como se relacionam

A configuração da regra define uma lista de pares esperados, por exemplo `TML` deve vir sempre com o nome `Transportes Metropolitanos de Lisboa`. Cada linha de `agency.txt` é comparada contra essa lista pelo `agency_id`: se o `agency_id` aparece na lista, o `agency_name` dessa linha tem de ser exatamente o nome esperado.

## Exemplos

| `agency_id` | `agency_name` | Resultado | Porquê |
|---|---|---|---|
| `TML` | `Transportes Metropolitanos de Lisboa` | ✅ Passa | Corresponde ao par configurado |
| `TML` | `TML Transportes` | ❌ Problema | O nome não corresponde ao esperado para este `agency_id` |
| vazio | `Transportes Metropolitanos de Lisboa` | ✅ Passa | Sem `agency_id`, a regra não compara |
| `TML` | `Transportes Metropolitanos de Lisboa` (sem lista configurada) | ✅ Passa | Sem lista, a regra não reporta nada |

## Como corrigir

| Problema | Causa provável | O que fazer |
|---|---|---|
| Correspondência inválida | O `agency_name` desta linha não é o nome configurado para este `agency_id` | Corrigir o `agency_name` no `agency.txt` para o nome esperado, ou atualizar a lista de correspondências na configuração da regra |
