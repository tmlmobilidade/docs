## Resumo

GTFS significa General Transit Feed Specification. É um standard internacional que define como aplicações de planeamento (ex. Google Maps, Transit, CityMapper) devem interpretar redes de transportes públicos, como horários e percursos. A especificação foi criada pelo Google, mas é agora mantida e orientada pela equipa da [Mobility Data](https://mobilitydata.org), de forma aberta e partilhada.

O standard define dois grupos: o GTFS Schedule, onde estão mapeadas todas as paragens, percursos e horários *planeados* de uma determinada agência; e o GTFS Real Time, que funciona como uma camada em cima do GTFS Schedule para ajustar as informações à realidade do momento (ex. horários mudam pois houve um acidente na ponte).

O GTFS Schedule não é mais do que uma série de tabelas (ex. ficheiros Excel) agrupados num arquivo `.zip`. Cada tabela é um ficheiro separado

contendo vários ficheiros, cada um representando uma tabela (semelhante a uma folha de Excel) onde cada coluna é separada por uma vírgula “,”.

Quem produz um GTFS são as agências de transporte público, e quase todas 

Cada ficheiro tem um nome específico e um conjunto obrigatório de colunas que correspondem aos dados de outros ficheiros, formando uma estrutura relacional.

Embora não seja uma base de dados tradicional, funciona como um conjunto de dados tabulares em formato de texto, permitindo uma fácil integração com plataformas digitais.

## Ferramentas úteis

Abaixo, uma pequena coleção de ferramentas que utilizamos diariamente para validar e inspecionar os dados do GTFS.

### Validação

- [**Validador Oficial do GTFS**](https://gtfs-validator.mobilitydata.org) — Esta ferramenta verifica se o ficheiro GTFS de horários segue todas as práticas obrigatórias e recomendadas. Para ficheiros maiores, é necessário o [aplicação instalada](https://github.com/MobilityData/gtfs-validator?tab=readme-ov-file#using-the-desktop-app).
- [**NAP France**](https://transport.data.gouv.fr/validation) — Esta excelente ferramenta valida um feed GTFS de forma semelhante ao validador oficial, mas apresenta os erros visualmente num mapa, facilitando a identificação e a compreensão dos problemas. É particularmente útil para interpretar os erros e avisos de validação que possa encontrar, ajudando a identificar e a resolver rapidamente problemas nos seus dados.

### Inspecionar

- [**Vyčius GTFS Inspector**](https://realtime.vycius.lt/) — Utilize esta ferramenta para inspecionar os feeds GTFS em tempo real para alertas de serviço e posições de veículos. Experimente com os nossos endpoints!
