## O que é um GTFS?

O GTFS (General Transit Feed Specification) é o standard global para as agências de transportes públicos publicarem horários para utilização em aplicações digitais, como o Google Maps.

Essencialmente, trata-se de um ficheiro `.zip` contendo vários ficheiros, cada um representando uma tabela (semelhante a uma folha de Excel) onde cada coluna é separada por uma vírgula “,”.

Cada ficheiro tem um nome específico e um conjunto obrigatório de colunas que correspondem aos dados de outros ficheiros, formando uma estrutura relacional.

Embora não seja uma base de dados tradicional, funciona como um conjunto de dados tabulares em formato de texto, permitindo uma fácil integração com plataformas digitais.

A especificação foi inicialmente lançada pela Google, mas é agora mantida e orientada pela equipa da [Mobility Data](https://mobilitydata.org). Pode consultar a documentação oficial pode ser vista [aqui](https://gtfs.org/).

## Como posso abrir/ler um GTFS?

Pode descompactar o ficheiro e abrir cada ficheiro em ferramentas como o Microsoft Excel ou o Google Sheets. No entanto, alguns destes ficheiros podem ser demasiado grandes, o que pode exceder os limites destes programas.

Nestes casos, é melhor utilizar ferramentas automatizadas concebidas para lidar com dados GTFS. Embora os ficheiros GTFS sejam legíveis por humanos, destinam-se ao processamento por sistemas automatizados para gerir e manipular eficientemente os dados neles armazenados.

## GTFS em Tempo Real

O padrão GTFS consiste, na realidade, em duas partes. O **GTFS de Horários** é o ficheiro `.zip` que contém todos os dados **programados** para uma determinada rede de transportes públicos.

Isto inclui informações como rotas, paragens e horários. Quando tem acesso a estes dados programados, pode sobrepor informações em tempo real dos veículos.

Esta combinação de dados programados e em tempo real é o que permite a aplicações como o [Citymapper](https://citymapper.com/) e outras exibir veículos num mapa e calcular estimativas precisas de chegada para a sua paragem.

Os dados programados fornecem a base, enquanto as atualizações em tempo real garantem que os utilizadores têm as informações mais atuais disponíveis.

A parte **em tempo real** do GTFS requer uma compreensão mais profunda de como os dados estão relacionados, bem como conhecimento do sistema para manter um fluxo de informação em constante atualização.

O GTFS em tempo real utiliza o formato [protobuf](https://protobuf.dev) para trocar dados, que não é legível por humanos. Como resultado, trabalhar com o GTFS em tempo real requer normalmente alguma experiência em programação para processar, descodificar e manipular os dados de forma eficaz.

A complexidade de trabalhar com o GTFS Realtime decorre da necessidade de gerir atualizações em tempo real, como as posições dos veículos e o estado das viagens, que exigem atualizações contínuas e integração com os dados horários. Compreender como estas atualizações se relacionam com os dados estáticos de horários do GTFS é crucial para a construção de sistemas que possam fornecer informações de transporte público em tempo real.

## Ferramentas úteis

Abaixo, uma pequena coleção de ferramentas que utilizamos diariamente para validar e inspecionar os dados do GTFS.

### Validação

- [**Validador Oficial do GTFS**](https://gtfs-validator.mobilitydata.org) — Esta ferramenta verifica se o ficheiro GTFS de horários segue todas as práticas obrigatórias e recomendadas. Para ficheiros maiores, é necessário o [aplicação instalada](https://github.com/MobilityData/gtfs-validator?tab=readme-ov-file#using-the-desktop-app).
- [**NAP France**](https://transport.data.gouv.fr/validation) — Esta excelente ferramenta valida um feed GTFS de forma semelhante ao validador oficial, mas apresenta os erros visualmente num mapa, facilitando a identificação e a compreensão dos problemas. É particularmente útil para interpretar os erros e avisos de validação que possa encontrar, ajudando a identificar e a resolver rapidamente problemas nos seus dados.

### Inspecionar

- [**Vyčius GTFS Inspector**](https://realtime.vycius.lt/) — Utilize esta ferramenta para inspecionar os feeds GTFS em tempo real para alertas de serviço e posições de veículos. Experimente com os nossos endpoints!
