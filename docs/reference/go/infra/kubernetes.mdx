## Visão Geral

O cluster Kubernetes do GO corre no **Oracle Kubernetes Engine (OKE)**.

A infraestrutura é declarada em Terraform e organizada em dois módulos principais:

- **`oke`** — Cluster OKE
- **`node_pool`** — Pool de workers

## Workloads

### Namespace

Nesta fase da criação do cluster apenas existe o namespace para o POC - `go-poc`.

### Gateway

O `gateway` é o serviço a ser utilizado como poc para a criação e demo do cluster de k8s.

As duas réplicas são agendadas preferencialmente em nós distintos (anti-affinity) para garantir disponibilidade durante actualizações. Os probes de liveness e readiness verificam o endpoint `/health`.
