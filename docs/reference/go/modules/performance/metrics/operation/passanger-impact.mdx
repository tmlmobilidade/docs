# Métrica: `demand_affected_by_failed_circulations_by_day`

## Descrição

A métrica **`demand_affected_by_failed_circulations_by_day`** estima o número de passageiros potencialmente afetados por falhas de circulação, agregado por **agency_id** e por **dia operacional**.

O cálculo é feito da seguinte forma:

1. São identificadas as circulações com falha.
    
2. Para cada circulação falhada (definida por `pattern_id` + `patternHour`), é calculada a **mediana de passageiros observados nos 30 dias anteriores**.
    
3. Para cada dia operacional, soma-se a mediana estimada de todas as circulações falhadas desse dia.
    
4. O resultado é armazenado por agency_id, contendo todos os dias no campo `data`.

| `properties.agency_id` | String   | Identificador da área de operação (ex: `"44"`).                    |
