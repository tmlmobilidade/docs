---
title: Causas e Efeitos
description: Conjunto de causas e efeitos disponíveis na plataforma
---

A plataforma define um conjunto de **causas** (`cause`) e **efeitos** (`effect`) que estendem a especificação [[service-alerts.mdx|GTFS RT]] base, adicionando causas específicas para a realidade operacional.

### Causas Disponíveis

As causas dividem-se em duas categorias:

**Causas da especificação GTFS-RT** - Presentes directamente na especificação oficial.

| Causa | Descrição |
|-------|-----------|
| `ACCIDENT` | Acidente |
| `CONSTRUCTION` | Obras |
| `DEMONSTRATION` | Manifestação |
| `MEDICAL_EMERGENCY` | Emergência Médica |
| `POLICE_ACTIVITY` | Atividade Policial |
| `STRIKE` | Greve |
| `TECHNICAL_ISSUE` | Problema Técnico |
| `WEATHER` | Mau tempo |

**Causas personalizadas** - Extensões específicas para a realidade operacional não contem no [[service-alerts.mdx|GTFS RT]].

| Causa | Descrição |
|-------|-----------|
| `ABUSIVE_PARKING` | Estacionamento Abusivo |
| `DRIVER_ABSENCE` | Condutor Ausente |
| `DRIVER_ISSUE` | Problema com Condutor |
| `HIGH_PASSENGER_LOAD` | Elevado Volume de Passageiros |
| `NETWORK_UPDATE` | Alteração na Rede |
| `PUBLIC_DISORDER` | Desordem Pública |
| `ROAD_ISSUE` | Problema na Estrada |

### Efeitos Disponíveis

**Efeitos da especificação GTFS-RT:** `ACCESSIBILITY_ISSUE`, `ADDITIONAL_SERVICE`, `DETOUR`, `MODIFIED_SERVICE`, `NO_SERVICE`, `REDUCED_SERVICE`, `SIGNIFICANT_DELAYS`, `STOP_MOVED`

**Efeitos personalizados:** `REALTIME_INFO_ISSUE`, `ON_BOARD_SALE_ISSUE`
