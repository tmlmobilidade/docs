---
title: Causas e Efeitos
description: Conjunto de causas e efeitos disponíveis na plataforma
---

A plataforma define um conjunto de **causas** (`cause`) e **efeitos** (`effect`) que estendem a especificação [[service-alerts.mdx|GTFS RT]] base, adicionando causas específicas para a realidade operacional.

### Causas Disponíveis

As causas dividem-se em duas categorias:

#### Standard
Presentes directamente na especificação oficial.

| Causa | Descrição |
|-------|-----------|
| `ACCIDENT` | Acidente |
| `CONSTRUCTION` | Obras |
| `DEMONSTRATION` | Manifestação (não relacionada com a rede de transportes)|
| `MEDICAL_EMERGENCY` | Emergência médica |
| `POLICE_ACTIVITY` | Atividade policial (ex: loqueio de via, operação STOP) |
| `STRIKE` | Greve dos transportes públicos|
| `TECHNICAL_ISSUE` | Problema técnico |
| `WEATHER` | Mau tempo |

#### Extenção
Extensões específicas para a realidade operacional não contem no [[service-alerts.mdx|GTFS RT]].

| Causa | Descrição |
|-------|-----------|
| `ABUSIVE_PARKING` | Estacionamento abusivo |
| `DRIVER_ABSENCE` | Condutor ausente |
| `DRIVER_ISSUE` | Problema com o condutor |
| `HIGH_PASSENGER_LOAD` | Elevado volume de passageiros |
| `NETWORK_UPDATE` | Alteração na rede de transportes |
| `PUBLIC_DISORDER` | Desacatos dentro do veículo |
| `ROAD_ISSUE` | Problema na via |

### Efeitos Disponíveis

#### Standard
Presentes directamente na especificação oficial.

| Efeito | Descrição |
|-------|-----------|
| `ACCESSIBILITY_ISSUE` | Problema de acessibilidade |
| `ADDITIONAL_SERVICE` | Serviço adicional |
| `DETOUR` | Desvio |
| `MODIFIED_SERVICE` | Alteração no serviço |
| `NO_SERVICE` | Serviço cancelado |
| `REDUCED_SERVICE` | Encurtamento do serviço |
| `SIGNIFICANT_DELAYS` | Atrasos significativos |
| `STOP_MOVED` | Paragem deslocada |

#### Extenção
Extensões específicas para a realidade operacional não contem no [[service-alerts.mdx|GTFS RT]].

| Efeito | Descrição |
|-------|-----------|
| `REALTIME_INFO_ISSUE` | Problema de Informação em Tempo Real |
| `ON_BOARD_SALE_ISSUE` | Problema de Venda a Bordo |
