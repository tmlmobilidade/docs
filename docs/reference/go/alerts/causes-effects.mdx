---
title: Causas e Efeitos
description: Conjunto de causas e efeitos disponíveis na plataforma
---

A plataforma define um conjunto de **causas** (`cause`) e **efeitos** (`effect`) que estendem a especificação GTFS-RT base, adicionando causas específicas para a realidade operacional.

### Causas Disponíveis

As causas dividem-se em duas categorias:

**Causas da especificação GTFS-RT** 

| Causa | Descrição |
|-------|-----------|
| `ACCIDENT` | Acidente |
| `CONSTRUCTION` | Obras |
| `DEMONSTRATION` | Manifestação |
| `MEDICAL_EMERGENCY` | Emergência Médica |
| `POLICE_ACTIVITY` | Atividade Policial |
| `STRIKE` | Greve |
| `TECHNICAL_ISSUE` | Problema Técnico |
| `WEATHER` | Mau tempo |

**Causas personalizadas** — extensões específicas da plataforma, mapeadas para `UNKNOWN_CAUSE` no feed GTFS-RT mas com informação detalhada no título/descrição: `ABUSIVE_PARKING`, `DRIVER_ABSENCE`, `DRIVER_ISSUE`, `HIGH_PASSENGER_LOAD`, `NETWORK_UPDATE`, `PUBLIC_DISORDER`, `ROAD_ISSUE`, `TRAFFIC_JAM`, `VEHICLE_ISSUE`

### Efeitos Disponíveis

**Efeitos da especificação GTFS-RT:** `ACCESSIBILITY_ISSUE`, `ADDITIONAL_SERVICE`, `DETOUR`, `MODIFIED_SERVICE`, `NO_SERVICE`, `REDUCED_SERVICE`, `SIGNIFICANT_DELAYS`, `STOP_MOVED`

**Efeitos personalizados:** `REALTIME_INFO_ISSUE`, `ON_BOARD_SALE_ISSUE`
