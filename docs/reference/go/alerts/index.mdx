## Visão Geral

A plataforma funciona como uma camada de gestão interna de alertas que, após publicação, são convertidos automaticamente no formato "[[service-alerts.mdx|GTFS RT]]" para consumo por aplicações de passageiros, painéis de informação e sistemas de terceiros. [[hello-2]]
