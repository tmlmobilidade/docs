---
title: Referências
description: As Referências determinão que linhas, paragens, viagens ou agencias vão ser afetadas.
---

As referências são a nossa forma de identificar quais as (entidades)[https://gtfs.org/documentation/realtime/reference/#message-entityselector] que vão ser afetadas pelo alerta.

Seguindo a especificação oficial, as referências podem ser:

- `agency` - O alerta afecta toda a operação de um operador.
- `lines` - O alerta afecta linhas específicas.
- `stops` - O alerta afecta paragens específicas.
- `trips` - O alerta afecta viagens específicas.

No GO, com as referências, podemos ainda identificar com ainda mais granularidade, as entidades que vão ser afetadas.

Por exemplo, um alerta que afecta uma linha específica, em apenas determinadas paragens.

No caso abaixo vemos que este alerta afeta duas linhas, a `1001` e a `1002`. Mas na linha `1001` apenas irá afetar as paragens `030001` e `030010`, enquanto que a paragem `1002` será afetada em todas a 

```json
{
  "reference_type": "lines",
  references: [
	  {
		  "parent_id": "1001",
		  "child_ids": ["030001", "030010"]
	  },
	  {
		  "parent_id": "1002",
		  "child_ids": []
	  }
  ]
}
```
