---
title: Relações Causa e Efeitos
description: Matriz completa de combinações válidas entre causa, efeito e tipo de referência para validação semântica dos alertas.
---

Nem todas as combinações de causa, efeito e tipo de referência são válidas. A plataforma impõe regras de validação que garantem coerência semântica. Por exemplo, `DRIVER_ABSENCE` só pode afectar `Viagens` viagens específicas), enquanto `CONSTRUCTION` pode afectar linhas, paragens e viagens.

A tabela seguinte apresenta a matriz completa de relações válidas.

### ABUSIVE_PARKING

| Efeito                | Referências permitidas |
| --------------------- | ---------------------- |
| `ACCESSIBILITY_ISSUE` | Viagens, Linhas, Paragens    |
| `DETOUR`              | Viagens, Linhas, Paragens    |
| `NO_SERVICE`          | Viagens, Linhas, Paragens    |
| `REDUCED_SERVICE`     | Viagens, Linhas, Paragens    |
| `SIGNIFICANT_DELAYS`  | Viagens, Linhas, Paragens    |
