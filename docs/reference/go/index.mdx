## O que é o GO?

O GO é um conjunto de aplicações web que pretende responder às principais necessidades operacionais de equipas que gerem redes de transporte público. No diagrama está resumido o principal fluxo de informação que permite desenhar, operar e analisar transportes públicos em escala e num modelo de melhoria contínua.

## Usa o que precisas

O GO foi desenvolvido para responder às necessidades da operação da Carris Metropolitana, mas de uma forma que se aplica a qualquer operador de transporte público. A sua construção é modular, o que significa que podes usar só os módulos que precisas, ou então começar a implementar fluxos num módulo e gradualmente ir expandindo para os outros.

Por exemplo, se quiseres utilizar o GO para ver as circulações em tempo real não precisas de ter o módulo de oferta. Se queres só uma forma simples de desenhar linhas e construir horários, não precisas do módulo dos alertas.

[Fala connosco](/reference/team) se tiveres interesse na plataforma. Podemos importar os dados da tua operação de transportes (se tiveres) para mostrar como funciona. Se não tiveres dados também está tudo bem :)
